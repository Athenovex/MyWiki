# 지식 스키마

`10_위키`(Canonical Note)와 `20_출처`(Source Note)의 Properties(YAML Frontmatter) 규격을 정의한다. 이 문서를 사용자 요청 없이 임의로 변경하지 않는다.

## Canonical Note Properties (`10_위키`)

```yaml
---
id:
type:
status: canonical
aliases:
domains:
related:
sources:
created:
updated:
---
```

### `id`
영구 고유 ID. 파일명이 바뀌어도 유지한다. 소문자, 하이픈 사용.
예: `id: kb-mcp`, `id: kb-n8n`
기존 ID를 재사용하지 않는다. 새 ID는 `kb-` 접두사 + 개념의 영문 슬러그.

### `type`
허용값 (임의 추가 금지, 필요시 `80_검토`에 제안):
```
concept | tool | technology | method | person | organization | product | standard | event
```

### `status`
- `canonical` — 현재 대표 문서
- `deprecated` — 다른 문서에 병합되어 더 이상 대표 문서가 아님 (`merged_into` 필수, `90_보관`으로 이동)

### `aliases`
동일 개념의 약어·정식명칭·한국어명·영어명·다른 표기. 배열.
```yaml
aliases: ["Model Context Protocol", "모델 컨텍스트 프로토콜"]
```

### `domains`
허용값 (임의 추가 금지, 필요시 `80_검토`에 제안), 복수 가능:
```
AI | automation | development | content | productivity | business | marketing | real-estate
```

### `related`
직접적인 지식 관계가 있는 다른 Canonical Note. Obsidian 내부 링크 배열.
```yaml
related: ["[[Tool Calling]]", "[[AI Agent]]"]
```
같은 domain이라는 이유만으로 연결하지 않는다 — 의미 있는 관계만.

### `sources`
이 지식의 근거가 된 Source Note. 배열.
```yaml
sources: ["[[AI Agent Report]]", "[[Anthropic MCP Documentation]]"]
```

### `merged_into` (status: deprecated일 때만)
```yaml
merged_into: "[[MCP]]"
```

### `created` / `updated`
`YYYY-MM-DD`. `updated`는 지식 내용이 실제로 바뀐 날짜만 갱신한다 (단순 오탈자·포맷 수정은 갱신하지 않음).

## Source Note Properties (`20_출처`)

```yaml
---
type: source
source_type:
status:
file:
url:
site:
author:
published:
collected:
processed:
target_notes:
---
```

파일 형식에 따라 필요 없는 필드는 비우거나 생략 가능.

### `source_type`
허용값 (임의 추가 금지):
```
web | pdf | document | presentation | spreadsheet | image | video | audio | book | paper | text | dataset | other
```
jpg/png/screenshot 등은 모두 `image`로 통일. 세부 형식은 파일 확장자로 판단한다.

### `status`
```
inbox      — 아직 처리 전
processed  — 위키 반영 완료
review     — 80_검토로 이동됨
```

### `file`
원본 파일 경로 (파일 기반 자료).
```yaml
file: "[[_원본/AI Agent Report.pdf]]"
```

### `url` / `site` / `author` / `published`
웹 자료 메타데이터. 파일 기반 자료는 저자·발행일이 있으면 기록.

### `collected`
자료를 수집한 날짜. `YYYY-MM-DD`.

### `processed`
`true` / `false`. 위키 반영 완료 여부.

### `target_notes`
이 Source가 반영된 Canonical Note 목록.
```yaml
target_notes: ["[[MCP]]", "[[Tool Calling]]"]
```
