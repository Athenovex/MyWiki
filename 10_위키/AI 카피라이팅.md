# AI 카피라이팅

> AI에게 브랜드 전담 카피라이터 페르소나를 부여해 매체별 광고 문구를 자동 생성하는 방법. 결과물을 그대로 쓰지 않고 여러 후보 중 사람이 고르고 다듬는 "초안 공장"으로 활용한다.

> 아래 페르소나 프롬프트("무드컵" 브랜드 설정 전문), 매체별 카피 예시, A/B 테스트 결과(클릭률 수치 포함)는 [[AI마케팅_이커머스_전문가과정]] 원본 슬라이드(p.37-43)에 실제로 등장하는 문구·수치를 그대로 인용한 것이다. "무드컵"은 원본이 실습용으로 쓰는 20~30대 여성 대상 감성 텀블러 브랜드이며, "손에 딱 맞는 그립감"·"파스텔 컬러"라는 강점도 원본에 명시된 내용이다. 다만 AIDA/PAS 공식을 무드컵에 실제로 적용한 완성 카피, Before/After 비교 문구는 원본이 프레임워크 정의만 제시하고 완성된 예시를 싣지 않아 사용법을 보여주기 위해 편집자가 작성했다 — 해당 부분은 문단 안에 별도로 표시했다.

## 페르소나 구성 5요소

카피 생성 프롬프트를 매번 새로 쓰지 않고, 아래 5가지 요소를 하나의 "페르소나 프롬프트"로 고정해두면 AI가 매번 같은 브랜드 정체성을 유지한 채 카피를 뽑아낸다. 각 요소가 빠지면 결과물이 업종 평균으로 되돌아가는 경향이 있다.

1. **역할(Role)**: "너는 우리 브랜드 5년차 전담 카피라이터야"처럼, 막연한 "카피라이터"가 아니라 특정 브랜드에 소속된 경력자로 지정한다.
2. **브랜드 정보(Context)**: 제품 특징, 타깃 고객, 경쟁사 대비 강점(차별점)을 함께 제공해야 "이 제품만의" 카피가 나온다. 이 정보가 없으면 AI는 검증 없이 업종 평균적인 문구만 생성하기 쉽다.
3. **말투(Tone)**: 친근함↔전문성, 발랄함↔차분함, 존댓말↔반말, 간결↔상세 같은 축으로 톤앤매너를 한 줄로 규정한다.
4. **규칙(Rules)**: "과장 금지, 이모지 2개 이하, 3문장 이내"처럼 결과물의 품질·형식을 제한하는 제약조건.
5. **예시(Examples)**: 원하는 스타일의 실제 카피 2~3개를 미리 보여줘 기준점을 제공한다. [[프롬프트 엔지니어링#3. 퓨샷 (Few-Shot)|퓨샷 기법]]과 같은 원리.

원본 슬라이드에 실린 완성된 페르소나 프롬프트(그대로 인용, p.37):

```
[역할] 너는 우리 브랜드 '무드컵'의 5년 차 전담 카피라이터야.

[브랜드] 무드컵은 20~30대 여성을 위한 감성 텀블러 브랜드. 강점은 '손에 딱 맞는 그립감'과 '파스텔 컬러'. 경쟁사보다 디자인이 감성적이야.

[말투] 친근하고 발랄한 반말. 이모지는 2개 이하. 문장은 짧게.

[규칙] 과장·허위 금지. 한 카피는 3문장 이내. 마지막에 행동유도 한 줄.

[예시] "오늘의 기분, 컵에 담아봐 ☕", "손에 감기는 이 느낌, 써보면 안다"

→ 이제부터 이 설정으로 카피를 써줘. 준비됐으면 '네'라고만 답해.
```

## 매체별 카피 차별화

같은 제품이라도 노출되는 매체마다 사용자의 검색 의도·체류 시간·소비 방식이 다르므로, 하나의 카피를 재활용하지 않고 매체별로 길이·톤·강조점을 바꿔야 한다.

원본 슬라이드가 무드컵을 예로 들어 제시한 매체별 카피(p.40, 그대로 인용):

| 매체 | 특징 | 카피 예시 |
|---|---|---|
| 네이버 검색광고 | 검색 의도 직격, 키워드+혜택을 짧고 명확히 | "무선 텀블러 세척 간편 40%할인" |
| 인스타그램 | 감성·비주얼 중심, 짧고 분위기 있게 | "오늘의 기분을 담다" |
| 상세페이지 | 구매 직전 설득, 기능·후기·보장을 상세히(스크롤하며 확신을 쌓는 방식으로만 설명되고, 원본에 완성된 카피 문구는 없음) | — |
| 스레드/트위터 | 대화체·가벼운 재치, 링크·해시태그 최소 | "이 그립감 실화냐" |

## 카피 공식: AIDA & PAS

두 공식 모두 "짧은 시간에 낯선 사람을 행동시키는" 목적은 같지만, 접근 순서가 다르다. AIDA는 긍정적 욕구를 쌓아 올리는 흐름이고, PAS는 문제의 불편함을 먼저 자극한 뒤 해결책을 제시하는 흐름이다.

- **AIDA**: Attention(시선을 끈다) → Interest(흥미를 붙든다) → Desire(갖고 싶게) → Action(행동시킨다)
- **PAS**: Problem(문제를 짚는다) → Agitate(아픔을 키운다) → Solution(해결책을 제시)

원본은 두 공식의 정의만 제시하고 무드컵에 실제로 적용한 완성 카피는 싣지 않는다. 아래는 공식의 쓰임을 보여주기 위해 편집자가 작성한 적용 예시다(편집자 작성, 원본 문구 아님):

```
[A] 하루 종일 미지근한 커피, 이제 그만.
[I] 무드컵은 손에 감기는 그립감으로 매번 다시 손이 갑니다.
[D] 오늘도 파스텔 컬러 중 내 취향 하나를 골라보세요.
[A] 지금 주문하면 각인 서비스 무료.
```

```
[P] 텀블러 샀는데 손에 안 맞아 자꾸 흘리지 않나요?
[A] 그립감 안 맞는 텀블러는 매번 신경 쓰이고, 결국 안 쓰게 됩니다.
[S] 무드컵은 '손에 딱 맞는 그립감'을 강점으로 설계한 텀블러입니다.
```

## 카피 심리 법칙

사람은 논리보다 감정·본능에 먼저 반응하므로, 정보를 나열하기보다 아래 법칙 중 하나를 카피의 축으로 삼으면 설득력이 올라간다. 아래 정의와 인용구는 원본 슬라이드 그대로다(p.45).

- **손실 회피**: "얻는 것"보다 "잃는 것"에 더 민감. "놓치면 후회" 같은 문구로 "지금 안 사면 손해"라는 프레임을 만든다.
- **사회적 증거**: 남들이 많이 사면 나도 산다. "1만 명이 선택"처럼 숫자로 다수의 선택을 보여준다.
- **희소성**: 적을수록 갖고 싶다. "한정 수량", "오늘까지"로 지금 행동해야 할 이유를 만든다.
- **구체성**: 막연함보다 숫자·디테일이 믿음을 준다. 원본이 든 예시는 "'좋은 제품'보다 '3초 만에 뜨거워지는'이 힘 있다" — 이 예시 자체는 텀블러가 아닌 다른 제품(가열 기구류로 추정)을 든 것으로, 원본에도 무드컵과 무관하게 일반 원칙 설명용으로 등장한다.

## 좋은 카피 판별 기준

혜택이 보이는가, 구체적인가, 타깃 언어인가, 행동을 부르는가, 과장은 없는가, 읽기 쉬운가 — 원본 슬라이드(p.42)가 제시하는 6가지 판별 기준 그대로다. 하나라도 "아니오"면 다시 다듬는다.

## 검색되는 상품명 짓기 (SEO)

원본 슬라이드(p.51)가 실제로 대비시킨 예시:

```
검색이 안 되는 이름: "프리미엄 스페셜 에디션" — 멋있지만 아무도 검색 안 함, 고객이 쓰는 말과 동떨어짐
검색이 잘 되는 이름: "스텐 보온 텀블러 500ml 무선" — 고객이 실제로 검색하는 단어, 핵심 특징·용도가 담김
```

AI에게 "고객이 이 제품을 검색할 때 쓰는 키워드 20개"를 물어 상품명·설명에 녹이는 방식을 원본은 제안한다.

## A/B 테스트

두 버전을 동시에 노출하고 반응(클릭률 등)이 좋은 쪽을 채택하는 검증 방법이다. 카피는 "감"으로 결정하는 것이 아니라 실제 반응 데이터로 확정해야 하며, 작은 문구 차이가 매출을 바꿀 수 있으므로 확신이 서지 않는 카피일수록 A/B 테스트를 거치는 편이 안전하다.

원본 슬라이드에 실제로 실린 A/B 테스트 결과(p.43, 그대로 인용):

```
A안: "오늘의 기분, 컵에 담아봐"       → 클릭률 2.1%
B안(승): "손에 감기는 이 느낌, 써보면 안다" → 클릭률 3.4%
```

두 카피 모두 위 페르소나 프롬프트의 [예시]에 등장한 문구이며, 실제 슬라이드에서 이 중 어느 쪽이 더 반응이 좋았는지를 클릭률 수치로 직접 보여준다.
