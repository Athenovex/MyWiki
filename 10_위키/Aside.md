# Aside

> AI 에이전트가 내장된 웹 브라우저. 사용자가 로그인해둔 사이트에 직접 들어가 클릭·입력·완료까지 대신 수행한다 — "답변만 하는 AI"가 아니라 "내 자리에 앉아서 대신 일하는 AI"에 비유된다.

## 개요

한국인 3명이 만들어 와이콤비네이터(YC) 투자를 받았으며, 브라우저 에이전트 벤치마크 3개에서 OpenAI·Anthropic의 에이전트를 앞선 것으로 소개된다. 기존 AI 챗봇과의 핵심 차이는 로그인이 필요한 사이트에서도 API 연동 없이 사람처럼 직접 사용한다는 점이다. 현재 macOS 전용이며(Windows 버전 출시 예정), 자체 AI 모델을 팔지 않고 사용자의 ChatGPT 또는 Claude 구독·API 키를 가져다 쓴다.

| 구분 | 기존 AI 챗봇 | Aside |
|---|---|---|
| 로그인 필요한 사이트 | 로그인 화면에서 멈춤 | 내 로그인 상태 그대로 작업 |
| 작업 방식 | 답변만 해줌 | 직접 클릭·입력·완료까지 수행 |
| 연동 설정 | API 연동 필요 | 연동 없음, 사람처럼 사이트 사용 |
| 데이터 | 서버로 전송 | 내 컴퓨터에 로컬 저장 |

## 설치와 설정

1. `aside.com`에서 macOS용 앱 설치
2. 첫 실행 시 Chrome의 로그인 상태·북마크 가져오기 (Aside 활용의 핵심 단계)
3. ChatGPT 또는 Claude 계정을 연결하거나 API 키 직접 등록

## 핵심 기능

- **로그인된 사이트에서 직접 작업**: 메일, 블로그, 쇼핑몰 관리자, 대시보드 등 API가 없는 서비스(네이버 블로그 등)에서도 작동
- **메모리(Dreaming)**: 브라우징 기록이 자동으로 기억이 되어 "어제 보던 그 상품들 다시 비교해줘"가 통하고, 관리자 페이지의 깊은 메뉴 경로도 기억시킬 수 있음
- **에이전트 전용 비밀번호 관리자**: AI가 로그인은 하되 비밀번호는 직접 보지 못하는 구조. 자동입력(autofill)으로만 처리, 자격 증명 사용 기록이 로그로 남음
- **민감 작업 승인 대기**: 결제·게시물 발행·메시지 전송은 AI가 임의로 실행하지 않고 반드시 사용자 확인을 거침
- **루틴(예약 실행)**: 매일 아침 대시보드 확인처럼 반복 작업을 스케줄로 등록

## 실전 활용 예시

| 분야 | 명령어 예시 |
|---|---|
| 블로그 운영 | "이 글을 네이버 블로그에 임시저장하고 태그 후보 5개 추천해줘" |
| 쇼핑몰 관리 | "쇼핑몰 관리자에서 '여름' 카테고리 상품 전부 10% 할인가로 수정해줘" |
| 시장 조사 | "경쟁사 5곳 요금제를 전부 확인해서 표로 비교해줘, 스크린샷도 같이" |
| 공공 사이트 업무 | "홈택스에서 이번 달 발행된 세금계산서 목록 조회해서 정리해줘" |
| 반복 루틴 | "매일 아침 9시에 내 애널리틱스 핵심 지표 확인해서 요약해줘" |

## 활용 원칙

1. **글쓰기가 아니라 "운영"을 맡긴다** — 발행·수정·확인·수집처럼 시간이 드는 반복 운영 작업에서 진가가 나온다
2. **초안과 반복은 AI, 최종 결정은 사람** — 발행 버튼과 결제 버튼은 직접 누른다
3. **처음엔 지켜보고, 익숙해지면 맡긴다** — AI가 작업하는 화면을 지켜보며 실수 패턴을 파악한 뒤 신뢰가 쌓인 작업부터 완전히 위임한다
