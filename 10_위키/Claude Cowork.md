# Claude Cowork

> [[Claude]] 데스크톱 앱의 탭 중 하나로, 코딩 없이 버튼 몇 번으로 내 컴퓨터의 파일·작업을 Claude에게 맡기는 기능. 터미널 명령어를 쓰는 [[Claude Code]]와 달리 진입장벽이 낮다.

## 개요

일반 Claude 채팅은 질문에 답만 하지만, Cowork는 지정된 폴더에 직접 접근해 파일을 열고 수정하고 새로 만든다 — "답해주는 AI"가 아니라 "일해주는 AI"다. 로컬 파일을 읽고 쓰려면 데스크톱 앱이 필요하며(웹·모바일 버전은 베타로 로컬 폴더 연결 불가), Pro 이상 유료 플랜이 필요하다.

## 시작하기

1. 앱 설치 후 Pro 이상 계정으로 로그인
2. 입력창 왼쪽 아래에서 "Cowork" 선택
3. 접근을 허용할 폴더를 연결 — **바탕화면 전체나 문서 전체가 아니라 좁은 범위(전용 폴더)로 제한**하는 것이 안전
4. 자연어로 작업 지시

## "나를 아는 AI 직원" 만들기 — 파일 3개 패턴

작업 폴더 안에 `회사정보/` 폴더를 만들고, 아래 3개 파일을 Cowork에게 인터뷰시켜 채우면 매번 처음부터 설명하지 않아도 되는 "직원"이 된다.

| 파일 | 내용 | 만드는 법 |
|---|---|---|
| `about-me.md` | 하는 일, 결과물, 일할 때 중요하게 여기는 것, 소통 방식 | 객관식 질문 약 15개로 Cowork가 직접 인터뷰 (`AskUserQuestion` 활용) |
| `voice-style.md` | 자주 쓰는 표현, 문장 길이, 톤, 피해야 할 표현 | **직접 쓴 글 3개 이상**(인스타 캡션, 블로그, 메일 등 — AI가 다듬은 글 제외)을 제공해 실제 말투를 분석시킴 |
| `my-company.md` | 사업 정보, 수익 모델, 이번 주 우선순위, 진행 중 프로젝트 | 기존 자료(사업계획서, 노션 등)를 먼저 읽힌 뒤 빠진 부분만 질문으로 보완 |

이후 모든 요청은 다음 공식 하나로 충분하다: *"나는 [작업]을 하고 싶고, [완성된 결과물]은 이런 거야. 회사정보 폴더를 먼저 읽고, 바로 시작하지 말고 질문부터 해줘."*

## 스킬 설치

Cowork용 스킬은 `.skill` 파일을 채팅창에 끌어와서 카드로 뜨면 **"Save skill"**을 누르는 것으로 끝난다 (자세한 스킬 개념은 [[Claude 에이전트 스킬]] 참고).

## 예약 작업 (Scheduled)

왼쪽 사이드바의 **Scheduled**에서 "New task" → "Create with Claude"(대화형 설정) 또는 "Set up manually"(직접 설정)로 등록한다.

- ⚠️ **예약 작업은 로컬 폴더를 읽지 못한다.** 원격으로 실행되기 때문에 커넥터(Gmail·캘린더 등)와 클로드 계정에 저장된 파일로만 작동하며, 참고 자료는 프롬프트에 직접 적어야 한다
- ⚠️ 메일은 "초안" 작성까지만 가능하고 **직접 발송은 안 된다** (Anthropic의 의도된 정책) — 프롬프트에도 "발송해줘"가 아니라 "초안을 써줘"라고 요청해야 함
- 잘 맞는 자동화: 브리핑·요약·리포트·파일 정리·리서치. 맞지 않는 자동화: 메일/메시지 대신 발송, 자동 응답

## 활용 사례: 메타 광고팀 스킬

`.skill` 파일 하나 설치만으로 메타(페이스북·인스타) 광고 대행 업무를 명령어 5개로 대체하는 사례.

| 명령어 | 기능 |
|---|---|
| `/spy` | 경쟁사 광고의 후킹·CTA·오퍼·집행 기간 분석 |
| `/competitive-ads-extractor` | 경쟁사 3~5곳 비교, 아무도 안 쓰는 빈틈(각도) 발견 |
| `/bulk-creative` | 브랜드 톤에 맞는 광고 카피 대량 생성 |
| `/ads-score` | 후킹·카피·CTA·감정·오퍼·비주얼 6가지 기준으로 광고 채점 |
| `/ads meta` | 광고 계정을 50개 항목으로 점검해 0~100점 건강검진 |

메타 광고 계정을 연결하면 데이터를 자동으로 가져오고, 연결하지 않아도 캡처나 텍스트를 붙여넣으면 동일하게 분석된다.

## 활용 사례: 네이버 뉴스 API 자동 브리핑

네이버 검색 API(뉴스) + Cowork + Notion을 조합해 매일 아침 키워드 뉴스 요약이 자동으로 쌓이게 만드는 사례. 네이버 클라우드 API HUB에서 뉴스 검색 API를 신청하면 무료로 하루 25,000건(월 77만 5천 건) 한도가 주어진다.

1. **열쇠 발급**: 네이버 클라우드 API HUB에서 검색 API 신청 → Client ID·Client Secret 발급
2. **첫 실행 테스트**: 발급받은 키와 원하는 키워드를 Cowork에 주고 "이 키로 '[키워드]' 최신 뉴스 10건을 모아서 제목·언론사·링크로 정리해줘"라고 요청 — 호출 코드는 Cowork가 직접 작성
3. **예약 작업으로 승격**: "방금 그 뉴스 수집을 예약 작업으로 만들어줘. 매일 아침 8시, 키워드는 [키워드]. 결과는 노션 '데일리 뉴스' 페이지에 날짜별로 쌓아줘"
4. **브리핑 규칙 추가**: 단순 기사 목록 대신 "겹치는 기사는 하나로 묶고, 기사마다 세 줄 요약을 붙여줘. 중요한 순서대로 정렬하고, 맨 위에 '오늘의 한 줄 총평'을 달아줘"처럼 정리 규칙을 얹으면 다시 읽지 않아도 되는 브리핑이 된다

키워드만 바꾸면 경쟁사 동향 감시, 브랜드 언급 모니터링, 투자 종목 뉴스 등으로 동일한 틀을 재사용할 수 있다. Notion 커넥터는 읽기·쓰기를 모두 지원해 날짜별 아카이브가 자동으로 누적된다.
