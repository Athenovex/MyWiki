# Claude Design

> [[Claude]]의 UI 디자인 생성 기능. PRD·유저플로우 같은 기획 문서와 실제 피그마(Figma) 디자인 시스템을 입력받아, 그 스타일 그대로 와이어프레임과 하이파이(고해상도) 디자인 시안을 만들어준다.

## 개요

디자인 시스템 없이 Claude Design에 곧바로 화면을 만들어달라고 하면 흔히 "AI가 만든 티"가 나는 밋밋하고 촌스러운("밤티") 결과물이 나온다. 검증된 디자인 시스템(컴포넌트·색상·타이포그래피 규칙이 담긴 피그마 파일)을 먼저 업로드해두면, 이후 생성되는 모든 화면이 그 스타일을 일관되게 따른다는 것이 핵심 활용법이다.

## 디자인 시스템 적용 워크플로우

1. **디자인 시스템 확보**: 피그마 커뮤니티에서 검증된 디자인 시스템 파일을 찾는다 (추천: Wanted Design System, Wix Design System, Vapor Design System). 피그마에서 열고 `File → Save Local Copy`로 `.fig` 파일을 로컬에 저장
2. **Claude Design에 업로드**: 디자인 시스템 탭에서 `Create` 클릭 → `.fig` 파일을 드래그 앤 드롭하면 해당 스타일의 디자인 시스템이 생성됨
3. **기획 문서 준비**: Claude 채팅에서 PRD(제품요구사항정의서)와 유저플로우를 작성 요청. 유저플로우는 바로 복사해 쓸 수 있도록 **Mermaid 다이어그램** 형식으로 요청하면 편리하다
4. **와이어프레임 생성**: Claude Design에서 와이어프레임을 선택하고, PRD+유저플로우를 넣어 화면 구조를 생성 — 이때 업로드한 디자인 시스템(예: Wanted Design System)이 선택되어 있는지 확인
5. **하이파이 시안 생성**: 와이어프레임이 만족스러우면 "하이파이 시안을 그려달라"고 요청하면 완성된 고해상도 디자인이 나온다

## 매니페스트와의 연계 워크플로우

기획 전용 도구 [[매니페스트]]에서 PRD·기능명세서·유저플로우·와이어프레임을 먼저 제작한 뒤, 이를 그대로 Claude Design에 옮겨와 디자인을 진행하는 방식.

1. 매니페스트에서 PRD·기능명세서는 마크다운(.md)으로, 와이어프레임은 피그마로 내보내기 후 `Save Local Copy`로 다운로드
2. 내보낸 문서 전부를 Claude Design에 첨부 — PRD·기능명세서로 "무엇을·왜" 만드는지, 유저플로우·와이어프레임으로 "어떤 화면·흐름"인지를 한 번에 전달
3. (권장) 디자인 시스템을 먼저 적용해두면 통일감 있는 결과물이 나옴
4. 와이어프레임을 토대로 화면 디자인을 생성하고, 채팅으로 반복 수정

기획 문서를 통째로 넘기면 처음부터 다시 설명할 필요 없이 기획 맥락(목적·기능·플로우·화면구조)이 그대로 디자인 단계로 이어진다.
