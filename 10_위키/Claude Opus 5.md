# Claude Opus 5

> 2026년 7월 24일 Anthropic이 공개한 플래그십 모델. [[Fable]]에 가까운 지능을 절반 비용으로 제공하도록 설계됐으며, Claude Max 요금제의 기본 모델이자 Claude Pro에서 쓸 수 있는 가장 강력한 모델이다.

## 개요

직전 모델 Opus 4.8 대비 성능은 2배 이상이면서 가격은 동일하다(입력 100만 토큰당 5달러, 출력 25달러). Fast 모드는 기본 속도의 약 2.5배로 실행되지만 요금도 2배다. Claude.ai · Claude API(`claude-opus-5`) · [[Claude Code]] · [[Claude Cowork]] 어디서나 쓸 수 있다.

## 벤치마크 성적표 (공식 발표 기준)

| 벤치마크 | 결과 |
|---|---|
| 코딩 (Frontier-Bench v0.1) | 전 모델 1위, Opus 4.8의 2배 이상 성능을 더 낮은 비용으로 (43.3% vs 21.1%) |
| 처음 보는 문제 (ARC-AGI 3) | 2위 모델의 3배 점수 (30.2%) |
| 컴퓨터 조작 (OSWorld 2.0) | 모든 비용 구간에서 1위, Fable 5 최고 기록을 약 1/3 비용으로 추월 (70.6%) |
| 업무 자동화 (Zapier AutomationBench) | 같은 비용에서 2위 모델의 약 1.5배 통과율 (26.0%) |
| 안전성 (자동 행동 감사) | '어긋난 행동' 점수 2.3 — 최근 모델 중 최저(가장 안전) |

자기 결과물을 검증하고 성공할 때까지 반복하는 능력이 강화되어, 도면 없이 픽셀만으로 3D 부품을 복원하거나 오픈소스 패키지의 근본 원인 버그를 스스로 찾아 고친 사례가 공식 발표에 소개됐다.

## 추론 강도(Effort) 사용법

추론 강도는 답변 길이가 아니라 **모델이 속으로 얼마나 생각할지**를 조절하는 손잡이다.

| 항목 | 내용 |
|---|---|
| 단계 | 낮음 · 중간 · 높음 · 아주 높음 · 최대 (5단계) |
| 기본값 | 높음 |
| 권장 시작점 | 높음으로 시작해 직접 돌려보고 조정 |
| 비용·속도 조절 | 낮음·중간을 주로 활용 |
| 컨텍스트 | 최대 100만 토큰 기억, 한 번에 출력 가능한 답은 최대 12.8만 토큰 |

이전 모델에서 효과 있던 방식과 달리, Opus 5는 지시를 더 얹을수록 좋아지지 않고 스스로 하는 일이 늘어난 만큼 같은 지시를 겹치면 토큰만 낭비된다. 이전 모델용 프롬프트를 그대로 옮기지 말고 강도를 처음부터 다시 맞추는 것이 공식 권장 사항이다.

## 지워야 할 지시문

공식 프롬프트 가이드가 강조하는 것은 "이렇게 쓰라"가 아니라 "이건 빼라"다. 다음 3가지는 예전 모델에서는 품질을 높였지만 Opus 5에서는 비용만 늘리고 효과가 없거나 오히려 나빠진다.

- "다시 확인해봐" 류의 재확인 요구
- "검증 단계를 넣어라" 류의 과잉 검증 지시
- 검증용 보조 Claude를 별도로 두는 방식

대신 "심각한 것만 보고해"처럼 코드 검토 범위를 좁히는 지시로 대체하는 것이 권장된다.

## 개발자용 신기능

- **대화 중 도구 변경(베타)**: 대화 도중 도구를 바꿔도 프롬프트 캐시가 유지됨
- **자동 폴백(베타)**: 안전 분류기에 걸린 요청은 다른 모델(기본적으로 Opus 4.8)이 자동으로 이어받음
