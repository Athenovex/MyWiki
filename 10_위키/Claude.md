# Claude

> Anthropic이 개발한 AI 어시스턴트 제품군. 웹·앱 채팅뿐 아니라 [[Claude Code]](터미널 에이전트), [[Claude Cowork]](코딩 없는 자동화) 등 여러 실행 환경으로 제공된다.

## 개요

Claude는 하나의 챗봇이 아니라 사용 목적에 따라 갈라지는 제품군이다. 클로드 데스크톱 앱을 기준으로 상단에 **Chat / Cowork / Code** 3개 탭이 있고, 어떤 탭을 쓰느냐에 따라 "질문에 답하는 AI"에서 "내 컴�퓨터 파일을 직접 다루는 AI"까지 역할이 달라진다.

## 제품 구성 (3탭 비교)

| 탭 | 언제 쓰나 | 특징 |
|---|---|---|
| 💬 Chat | 간단한 질문, 브라우저 대화 | 답변만 함, 로컬 파일 접근 불가 |
| 🤝 [[Claude Cowork\|Cowork]] | 코딩 없이 파일 작업·자동화를 맡길 때 | 버튼 기반, 폴더 연결 필요 |
| ⚡ [[Claude Code\|Code]] | 실제 코드 작업, 명령어·스킬·앱 연결 | 터미널/에이전트 기반, 자유도 가장 높음 |

## 웹/앱 핵심 기능

| 기능 | 설명 |
|---|---|
| 확장 사고 (Extended Thinking) | 입력창 옆 토글로 깊은 추론 모드 활성화 |
| 프로젝트 (Projects) | 관련 대화·자료를 폴더 단위로 묶어 맥락 유지 |
| 프로젝트 지침 (Instructions) | 프로젝트별 답변 규칙을 매번 설명하지 않고 고정 |
| 스타일 (Styles) | 사용자의 말투를 학습시켜 그 목소리로 글을 쓰게 함 |
| 아티팩트 (Artifacts) | 코드·문서·앱을 채팅 옆 캔버스에서 실시간 생성·수정 |
| 커넥터 (Connectors) | Gmail·캘린더·드라이브 등 외부 앱을 연결해 직접 열람 |
| 웹 검색 | 최신 정보가 필요할 때 자동 검색 |
| 파일 업로드 분석 | PDF·엑셀·이미지를 업로드해 분석 요청 |
| 음성 모드 (모바일) | 마이크로 음성 대화 |
