# Claude

> Anthropic이 개발한 AI 어시스턴트 제품군. 웹·앱 채팅뿐 아니라 Code(터미널 에이전트), Cowork(코딩 없는 자동화), Design(UI 생성) 등 여러 실행 환경과, Fable·Opus 5 같은 모델 라인업, 그리고 설치형 지침서인 에이전트 스킬까지 하나의 제품군으로 묶인다.

## 개요

Claude는 하나의 챗봇이 아니라 사용 목적에 따라 갈라지는 제품군이다. 클로드 데스크톱 앱을 기준으로 상단에 **Chat / Cowork / Code** 3개 탭이 있고, 어떤 탭을 쓰느냐에 따라 "질문에 답하는 AI"에서 "내 컴퓨터 파일을 직접 다루는 AI"까지 역할이 달라진다.

### 제품 구성 (3탭 비교)

| 탭 | 언제 쓰나 | 특징 |
|---|---|---|
| 💬 Chat | 간단한 질문, 브라우저 대화 | 답변만 함, 로컬 파일 접근 불가 |
| 🤝 Cowork | 코딩 없이 파일 작업·자동화를 맡길 때 | 버튼 기반, 폴더 연결 필요 |
| ⚡ Code | 실제 코드 작업, 명령어·스킬·앱 연결 | 터미널/에이전트 기반, 자유도 가장 높음 |

### 웹/앱 핵심 기능

| 기능 | 설명 |
|---|---|
| 확장 사고 (Extended Thinking) | 입력창 옆 토글로 깊은 추론 모드 활성화 |
| 프로젝트 (Projects) | 관련 대화·자료를 폴더 단위로 묶어 맥락 유지 |
| 프로젝트 지침 (Instructions) | 프로젝트별 답변 규칙을 매번 설명하지 않고 고정 |
| 스타일 (Styles) | 사용자의 말투를 학습시켜 그 목소리로 글을 쓰게 함 |
| 아티팩트 (Artifacts) | 코드·문서·앱을 채팅 옆 캔버스에서 실시간 생성·수정 |
| 커넥터 (Connectors) | Gmail·캘린더·드라이브 등 외부 앱을 연결해 직접 열람 |
| 웹 검색 | 최신 정보가 필요할 때 자동 검색 |
| 파일 업로드 분석 | PDF·엑셀·이미지를 업로드해 분석 요청 |
| 음성 모드 (모바일) | 마이크로 음성 대화 |

## Claude Code

> 터미널 또는 Claude 데스크톱 앱의 **Code 탭**에서 동작하는 코딩 에이전트. 파일을 읽고, 코드를 수정하고, 명령을 실행하는 등 실제 작업을 대신 수행한다. 예전엔 터미널 명령어가 필요했지만 데스크톱 앱의 Code 탭으로 코딩 지식 없이도 쓸 수 있게 됐다.

### 개요

Claude Code는 "저장소 전체를 읽고 버그 수정·리팩토링·문서화·테스트 작성까지 맡기는" 기본 엔진이다. Code 탭에서 **Local**을 선택해 작업 폴더를 지정하면 그 폴더 안에서만 파일 읽기·쓰기가 허용된다. 기본은 **Manual 모드**로, 파일을 바꾸기 전 미리 보여주고 **Accept(수락)**를 눌러야 적용된다.

### `.claude` 폴더 구조

`.claude` 폴더는 "클로드에게 주는 신입사원 매뉴얼"에 비유된다. 안에 담기는 요소는 크게 세 종류다.

**1) 설명서 — 프로젝트가 뭔지 알려주는 문서**

| 파일 | 역할 |
|---|---|
| `CLAUDE.md` | 프로젝트 정보·작업 규칙을 담은 핵심 매뉴얼. `.claude` 폴더에서 가장 중요한 파일 |
| `CLAUDE.local.md` | 팀에는 안 보이는 개인 전용 메모 버전 |
| `.gitignore` | 팀과 공유하지 말아야 할 파일 목록 (개발 표준, Claude 전용은 아님) |
| `.mcp.json` | Notion·GitHub·DB 등 외부 앱과의 연결 설정 |
| `.worktreeinclude` | 여러 작업방(worktree)을 열 때 함께 챙길 파일 목록 (고급) |

**2) 규칙·권한 — 뭘 해도 되는지 정하는 것**

| 파일 | 역할 |
|---|---|
| `settings.json` | 위험한 작업은 막고 안전한 작업은 매번 묻지 않고 통과시키는 권한 규칙. `CLAUDE.md`가 "부탁"이라면 이건 "강제 규칙" |
| `settings.local.json` | 팀 설정은 그대로 두고 개인 환경만 조정하는 버전 |

**3) 도구·기능 — 자주 쓰는 작업을 저장해두는 도구상자**

| 폴더 | 역할 |
|---|---|
| `rules/` | `CLAUDE.md`가 길어질 때 주제별(테스트, API 설계 등)로 나눠 특정 작업 시에만 켜지는 규칙 |
| `skills/` | 작업 레시피 모음. 폴더 하나 = 스킬 하나(`SKILL.md` + 참고 파일). 아래 [에이전트 스킬](#에이전트-스킬-agent-skills) 참고 |
| `commands/` | 긴 지시를 `/이름` 단축 명령어로 저장 (파일명이 곧 명령어가 됨) |
| `agents/` | 코드 검토 전담 등 특정 업무만 맡는 보조 에이전트. 자기 공간에서 따로 일하고 결과만 보고 |
| `hooks/` | "저장 시", "명령 실행 직전" 등 특정 타이밍에 자동 실행되는 스크립트. `settings.json`에 등록해야 작동함 |
| `output-styles/` | 답변 말투·형식(가르치듯, 간결하게 등)을 상황별로 전환 |
| `workflows/` | 여러 단계를 하나의 `/이름` 명령으로 묶어 순차 재실행 |
| `agent-memory/` | 서브에이전트가 스스로 배운 패턴·주의점을 기록하는 `MEMORY.md` (자동 생성) |

처음엔 `CLAUDE.md` + `settings.json` 두 개만 있어도 활용의 80%는 커버된다.

### 예약 작업과 자동화

- **Routines(예약 작업)**: 앱 사이드바에서 작업 내용과 주기를 등록. **클라우드**는 컴퓨터를 꺼도 실행되지만 최소 1시간 간격, **로컬**은 앱이 켜져 있어야 하지만 최소 1분 간격
- **`/loop 15m ...`**: 최대 3일간 반복 감시 (터미널)
- **`/schedule`**: 터미널에서 클라우드 예약 생성

### 플러그인과 CLAUDE.md 작성

- 플러그인은 스킬·자동화·앱 연결을 묶은 패키지. `+` 버튼 → Plugins 또는 `/plugin`으로 마켓플레이스 접근. 필요한 것 하나만 설치하는 것을 권장
- `/init`으로 `CLAUDE.md` 초안을 자동 생성한 뒤, 정체성·타깃·말투·금지 표현 등을 채운다. 200줄 이내로 짧고 구체적으로 쓸수록 잘 지켜진다

### 인수인계 (팀 공유)

`CLAUDE.md`, 스킬, 설정, 앱 연결 목록이 모두 작업 폴더 안 `.claude` 폴더에 저장되므로, 폴더를 통째로 압축·공유하면 다른 사람도 동일한 판단·결과물을 얻는다. 단, 앱 로그인 정보(토큰·비밀번호)는 폴더에 담기지 않으므로 각자 `/mcp`로 다시 로그인해야 한다.

### 실전 워크플로우: AI 회사(부서화) 패턴

Claude Code에 여러 "부서"를 만들어 업무를 역할별로 쪼개는 활용법. 한 명(AI)에게 조사·기획·검수·글쓰기를 전부 맡기면 결과가 애매해지지만, 부서별로 "오늘 할 일 / 지켜야 할 기준(3개) / 결과물 형태 / 다음 부서"를 문서 한 장에 정의해두면 품질이 눈에 띄게 올라간다.

- 콘텐츠 제작 기준 12부서 예시: 시장조사팀·브랜드분석팀·기획1팀·브랜드검수팀(QA)·기획2팀·영상제작팀·이미지제작팀·협업소통팀·정산팀·성과리뷰팀·자동화운영팀·비서실. 처음엔 시장조사·기획·검수·대본·비서실 5개만으로 시작해도 충분하다
- 부서 문서를 `AI_COMPANY.md` 같은 파일 하나에 정리해두고, Claude Code에게 "이 회사의 직원들이야"라고 역할을 부여한 뒤 "시장조사팀 → 기획1팀 → 검수팀 순서로 진행하고 TOP 3만 보고해줘. 내가 고르면 그때 다음 단계로"처럼 **의사결정 지점을 사람에게 남기는 것**이 핵심
- 안전 규칙을 문서 맨 위에 명시: 메일 실제 발송 금지(초안까지만), SNS 실제 게시 금지, 결제·구독 금지, 원본 파일 삭제·덮어쓰기 금지, 완료되지 않은 작업을 "완료"라고 보고 금지, 출처 없는 정보를 사실처럼 쓰기 금지

## Claude Cowork

> 코딩 없이 버튼 몇 번으로 내 컴퓨터의 파일·작업을 Claude에게 맡기는 탭. 터미널 명령어를 쓰는 Claude Code와 달리 진입장벽이 낮다.

### 개요

일반 Claude 채팅은 질문에 답만 하지만, Cowork는 지정된 폴더에 직접 접근해 파일을 열고 수정하고 새로 만든다 — "답해주는 AI"가 아니라 "일해주는 AI"다. 로컬 파일을 읽고 쓰려면 데스크톱 앱이 필요하며(웹·모바일 버전은 베타로 로컬 폴더 연결 불가), Pro 이상 유료 플랜이 필요하다.

### 시작하기

1. 앱 설치 후 Pro 이상 계정으로 로그인
2. 입력창 왼쪽 아래에서 "Cowork" 선택
3. 접근을 허용할 폴더를 연결 — **바탕화면 전체나 문서 전체가 아니라 좁은 범위(전용 폴더)로 제한**하는 것이 안전
4. 자연어로 작업 지시

### "나를 아는 AI 직원" 만들기 — 파일 3개 패턴

작업 폴더 안에 `회사정보/` 폴더를 만들고, 아래 3개 파일을 Cowork에게 인터뷰시켜 채우면 매번 처음부터 설명하지 않아도 되는 "직원"이 된다.

| 파일 | 내용 | 만드는 법 |
|---|---|---|
| `about-me.md` | 하는 일, 결과물, 일할 때 중요하게 여기는 것, 소통 방식 | 객관식 질문 약 15개로 Cowork가 직접 인터뷰 (`AskUserQuestion` 활용) |
| `voice-style.md` | 자주 쓰는 표현, 문장 길이, 톤, 피해야 할 표현 | **직접 쓴 글 3개 이상**(인스타 캡션, 블로그, 메일 등 — AI가 다듬은 글 제외)을 제공해 실제 말투를 분석시킴 |
| `my-company.md` | 사업 정보, 수익 모델, 이번 주 우선순위, 진행 중 프로젝트 | 기존 자료(사업계획서, 노션 등)를 먼저 읽힌 뒤 빠진 부분만 질문으로 보완 |

이후 모든 요청은 다음 공식 하나로 충분하다: *"나는 [작업]을 하고 싶고, [완성된 결과물]은 이런 거야. 회사정보 폴더를 먼저 읽고, 바로 시작하지 말고 질문부터 해줘."*

### 스킬 설치

Cowork용 스킬은 `.skill` 파일을 채팅창에 끌어와서 카드로 뜨면 **"Save skill"**을 누르는 것으로 끝난다 (자세한 스킬 개념은 [에이전트 스킬](#에이전트-스킬-agent-skills) 참고).

### 예약 작업 (Scheduled)

왼쪽 사이드바의 **Scheduled**에서 "New task" → "Create with Claude"(대화형 설정) 또는 "Set up manually"(직접 설정)로 등록한다.

- ⚠️ **예약 작업은 로컬 폴더를 읽지 못한다.** 원격으로 실행되기 때문에 커넥터(Gmail·캘린더 등)와 클로드 계정에 저장된 파일로만 작동하며, 참고 자료는 프롬프트에 직접 적어야 한다
- ⚠️ 메일은 "초안" 작성까지만 가능하고 **직접 발송은 안 된다** (Anthropic의 의도된 정책) — 프롬프트에도 "발송해줘"가 아니라 "초안을 써줘"라고 요청해야 함
- 잘 맞는 자동화: 브리핑·요약·리포트·파일 정리·리서치. 맞지 않는 자동화: 메일/메시지 대신 발송, 자동 응답

### 활용 사례: 메타 광고팀 스킬

`.skill` 파일 하나 설치만으로 메타(페이스북·인스타) 광고 대행 업무를 명령어 5개로 대체하는 사례.

| 명령어 | 기능 |
|---|---|
| `/spy` | 경쟁사 광고의 후킹·CTA·오퍼·집행 기간 분석 |
| `/competitive-ads-extractor` | 경쟁사 3~5곳 비교, 아무도 안 쓰는 빈틈(각도) 발견 |
| `/bulk-creative` | 브랜드 톤에 맞는 광고 카피 대량 생성 |
| `/ads-score` | 후킹·카피·CTA·감정·오퍼·비주얼 6가지 기준으로 광고 채점 |
| `/ads meta` | 광고 계정을 50개 항목으로 점검해 0~100점 건강검진 |

메타 광고 계정을 연결하면 데이터를 자동으로 가져오고, 연결하지 않아도 캡처나 텍스트를 붙여넣으면 동일하게 분석된다.

### 활용 사례: 네이버 뉴스 API 자동 브리핑

네이버 검색 API(뉴스) + Cowork + Notion을 조합해 매일 아침 키워드 뉴스 요약이 자동으로 쌓이게 만드는 사례. 네이버 클라우드 API HUB에서 뉴스 검색 API를 신청하면 무료로 하루 25,000건(월 77만 5천 건) 한도가 주어진다.

1. **열쇠 발급**: 네이버 클라우드 API HUB에서 검색 API 신청 → Client ID·Client Secret 발급
2. **첫 실행 테스트**: 발급받은 키와 원하는 키워드를 Cowork에 주고 "이 키로 '[키워드]' 최신 뉴스 10건을 모아서 제목·언론사·링크로 정리해줘"라고 요청 — 호출 코드는 Cowork가 직접 작성
3. **예약 작업으로 승격**: "방금 그 뉴스 수집을 예약 작업으로 만들어줘. 매일 아침 8시, 키워드는 [키워드]. 결과는 노션 '데일리 뉴스' 페이지에 날짜별로 쌓아줘"
4. **브리핑 규칙 추가**: 단순 기사 목록 대신 "겹치는 기사는 하나로 묶고, 기사마다 세 줄 요약을 붙여줘. 중요한 순서대로 정렬하고, 맨 위에 '오늘의 한 줄 총평'을 달아줘"처럼 정리 규칙을 얹으면 다시 읽지 않아도 되는 브리핑이 된다

키워드만 바꾸면 경쟁사 동향 감시, 브랜드 언급 모니터링, 투자 종목 뉴스 등으로 동일한 틀을 재사용할 수 있다. Notion 커넥터는 읽기·쓰기를 모두 지원해 날짜별 아카이브가 자동으로 누적된다.

## Claude Design

> Claude의 UI 디자인 생성 기능. PRD·유저플로우 같은 기획 문서와 실제 피그마(Figma) 디자인 시스템을 입력받아, 그 스타일 그대로 와이어프레임과 하이파이(고해상도) 디자인 시안을 만들어준다.

### 개요

디자인 시스템 없이 Claude Design에 곧바로 화면을 만들어달라고 하면 흔히 "AI가 만든 티"가 나는 밋밋하고 촌스러운("밤티") 결과물이 나온다. 검증된 디자인 시스템(컴포넌트·색상·타이포그래피 규칙이 담긴 피그마 파일)을 먼저 업로드해두면, 이후 생성되는 모든 화면이 그 스타일을 일관되게 따른다는 것이 핵심 활용법이다.

### 디자인 시스템 적용 워크플로우

1. **디자인 시스템 확보**: 피그마 커뮤니티에서 검증된 디자인 시스템 파일을 찾는다 (추천: Wanted Design System, Wix Design System, Vapor Design System). 피그마에서 열고 `File → Save Local Copy`로 `.fig` 파일을 로컬에 저장
2. **Claude Design에 업로드**: 디자인 시스템 탭에서 `Create` 클릭 → `.fig` 파일을 드래그 앤 드롭하면 해당 스타일의 디자인 시스템이 생성됨
3. **기획 문서 준비**: Claude 채팅에서 PRD(제품요구사항정의서)와 유저플로우를 작성 요청. 유저플로우는 바로 복사해 쓸 수 있도록 **Mermaid 다이어그램** 형식으로 요청하면 편리하다
4. **와이어프레임 생성**: Claude Design에서 와이어프레임을 선택하고, PRD+유저플로우를 넣어 화면 구조를 생성 — 이때 업로드한 디자인 시스템(예: Wanted Design System)이 선택되어 있는지 확인
5. **하이파이 시안 생성**: 와이어프레임이 만족스러우면 "하이파이 시안을 그려달라"고 요청하면 완성된 고해상도 디자인이 나온다

### 매니페스트와의 연계 워크플로우

기획 전용 도구 [[매니페스트]]에서 PRD·기능명세서·유저플로우·와이어프레임을 먼저 제작한 뒤, 이를 그대로 Claude Design에 옮겨와 디자인을 진행하는 방식.

1. 매니페스트에서 PRD·기능명세서는 마크다운(.md)으로, 와이어프레임은 피그마로 내보내기 후 `Save Local Copy`로 다운로드
2. 내보낸 문서 전부를 Claude Design에 첨부 — PRD·기능명세서로 "무엇을·왜" 만드는지, 유저플로우·와이어프레임으로 "어떤 화면·흐름"인지를 한 번에 전달
3. (권장) 디자인 시스템을 먼저 적용해두면 통일감 있는 결과물이 나옴
4. 와이어프레임을 토대로 화면 디자인을 생성하고, 채팅으로 반복 수정

기획 문서를 통째로 넘기면 처음부터 다시 설명할 필요 없이 기획 맥락(목적·기능·플로우·화면구조)이 그대로 디자인 단계로 이어진다.

## 모델 라인업

### Fable (Claude Fable 5)

> Anthropic이 공개한 Claude의 최상위 모델. 기존 Opus 라인보다 한 단계 위인 "Mythos" 등급의 첫 공개 모델로, 답을 내놓기 전에 스스로 점검·검증하는 작업 방식이 특징이다. "Fable 모드"는 이 작업 방식(시스템 프롬프트)을 다른 모델에 이식하는 기법을 가리킨다.

Fable 5는 2026년 6월 9일 출시됐고, 3일 뒤 미국 상무부가 보안 우려로 수출 통제를 걸어 외국인 접근을 차단했다가 안전장치 보강 후 7월 1일 전 세계에 재개방된 이력이 있다. Claude 모델 중 가장 비싼 등급(상대 비용 10x, Haiku 1x/Sonnet 3x/Opus 5x 대비)이며, 복잡한 판단·설계가 필요한 무거운 일회성 작업에 적합하다.

**일하는 방식의 특징**

- **자가 검증**: 바로 답을 내지 않고 "컨텍스트 수집 → 작업 → 자가 검증" 절차를 거침
- **자율 설계**: 절차를 일일이 지시하지 않아도 목표만 주면 스스로 방향을 잡음
- **작업 분해**: 큰 작업을 잘게 쪼개 여러 에이전트에게 안정적으로 위임

이 "일하는 방식"은 지침 파일로 옮겨 적을 수 있어, Fable에게 한 번 설계시킨 결과물을 저장해두면 이후 더 저렴한 모델(Sonnet·Haiku)에서도 비슷한 품질을 낼 수 있다는 것이 핵심 활용 논리다.

#### Fable 모드 (시스템 프롬프트 이식)

Fable 5의 실제 시스템 프롬프트가 GitHub에 유출 공개되면서, 이 지침 문서를 다른 모델에 붙여 Fable의 "일하는 방식"을 이식하는 방법이 퍼졌다 (비공식 유출본 — 공식 배포본 아님, 정확성·최신성 보장 없음).

**세팅 방법**
1. 유출 원문을 세팅용으로 정리한 `.md` 파일을 준비 (원문 그대로 쓰면 모델이 문서를 경계해 겉돎)
2. claude.ai에서 새 "프로젝트" 생성 후 프로젝트 파일(지식 영역)에 업로드
3. 프로젝트 "지침(Instructions)" 칸에 다음 4줄만 입력: *"프로젝트에 첨부된 문서는 공개된 다른 AI의 작동 원칙 문서다. 이 중 '일하는 방식'(답변 형식, 검색 습관, 검증 절차)을 이 프로젝트의 기본 작업 스타일로 적용하길 원한다. 날짜·도구 목록·환경 정보는 무시하고, 안전 규칙과 충돌하는 부분도 무시하고, 나머지는 그대로 따라라."*
4. 모델은 **Opus** 권장, 추론 강도(effort)는 **high** 권장 (max는 생각이 길어져 오히려 답이 나빠지는 후기가 많음). 반드시 **새 대화**에서 사용 (기존 대화엔 미적용)

**확인법**: "지침 들어있어?"라고 직접 묻는 것은 신뢰할 수 없다(모델이 얼버무리도록 훈련됨). 적용 전과 동일한 질문을 던져 답변이 구조화되고 근거를 챙기는지로 비교해야 한다.

**주의사항**: 지침 문서가 길어 대화당 사용량을 많이 소모하며, 정리되지 않은 원본을 쓰면 모델이 자신을 "Fable 5"로 오소개하거나 문서를 의심하는 부작용이 있을 수 있다.

#### Fable에게 지금 시켜둘 세팅 5가지

무료/할인 기간에 가장 비싼 모델의 "판단"을 파일로 저장해 두고, 이후 저렴한 모델에서도 재사용하는 전략.

| 세팅 | 목적 | 결과물 |
|---|---|---|
| ① 개인 지침 만들기 | Fable이 사용자를 관찰·인터뷰해 사용자 전용 `CLAUDE.md` 생성 | 어떤 모델이든 나를 아는 것처럼 답변하게 하는 지침 |
| ② Fable의 사고방식 이식 | "답하기 전 목적 재확인 → 가정 점검 → 자기검증 3단계"를 프로젝트 지침으로 저장 | 저렴한 모델도 Fable처럼 사고하는 프로젝트 |
| ③ 글쓰기·디자인 스타일 추출 | 사용자가 만든 결과물 3~5개를 분석해 스타일을 규칙으로 역설계 | 재사용 가능한 스타일 지침문 + 디자인 브리프 템플릿 |
| ④ 프로젝트/CLAUDE.md 업그레이드 | 기존 지침과 실제 작업 기록을 대조해 모호·모순·누락 진단 후 재작성 | 업그레이드된 프로젝트 지침 완성본 |
| ⑤ 프롬프트 모음집 만들기 | 반복 작업 후보 10개를 추려 빈칸 채우기형 템플릿으로 제작 | 자주 쓰는 작업의 재사용 프롬프트 문서 |

이 외에도 방향을 못 잡은 사업 전략, 방치한 복잡한 문제, 미뤄둔 선택(이직·투자) 등 "생각이 필요한" 무거운 의사결정을 Fable에게 먼저 맡겨두는 활용법이 소개된다.

#### "전담 AI 코치" 만들기 (간단 버전)

위 5가지 세팅이 부담스러울 때 쓰는 축약 버전. Fable에게 "AI 세팅 코치" 역할을 맡기고 직업·용도·선호 답변 스타일·기존 불만 4가지를 질문받은 뒤, ① 개인 설정(preferences)에 넣을 300자 이내 맞춤 지침 ② 자주 쓸 전용 프롬프트 3개 ③ 사용법 3줄을 결과물로 받는다. 마지막에 "내가 놓쳤을 정보를 되물어봐 달라"는 한 줄을 추가하면 완성도가 올라간다.

### Claude Opus 5

> 2026년 7월 24일 Anthropic이 공개한 플래그십 모델. Fable에 가까운 지능을 절반 비용으로 제공하도록 설계됐으며, Claude Max 요금제의 기본 모델이자 Claude Pro에서 쓸 수 있는 가장 강력한 모델이다.

직전 모델 Opus 4.8 대비 성능은 2배 이상이면서 가격은 동일하다(입력 100만 토큰당 5달러, 출력 25달러). Fast 모드는 기본 속도의 약 2.5배로 실행되지만 요금도 2배다. Claude.ai · Claude API(`claude-opus-5`) · Claude Code · Claude Cowork 어디서나 쓸 수 있다.

**벤치마크 성적표 (공식 발표 기준)**

| 벤치마크 | 결과 |
|---|---|
| 코딩 (Frontier-Bench v0.1) | 전 모델 1위, Opus 4.8의 2배 이상 성능을 더 낮은 비용으로 (43.3% vs 21.1%) |
| 처음 보는 문제 (ARC-AGI 3) | 2위 모델의 3배 점수 (30.2%) |
| 컴퓨터 조작 (OSWorld 2.0) | 모든 비용 구간에서 1위, Fable 5 최고 기록을 약 1/3 비용으로 추월 (70.6%) |
| 업무 자동화 (Zapier AutomationBench) | 같은 비용에서 2위 모델의 약 1.5배 통과율 (26.0%) |
| 안전성 (자동 행동 감사) | '어긋난 행동' 점수 2.3 — 최근 모델 중 최저(가장 안전) |

자기 결과물을 검증하고 성공할 때까지 반복하는 능력이 강화되어, 도면 없이 픽셀만으로 3D 부품을 복원하거나 오픈소스 패키지의 근본 원인 버그를 스스로 찾아 고친 사례가 공식 발표에 소개됐다.

**추론 강도(Effort) 사용법** — 추론 강도는 답변 길이가 아니라 모델이 속으로 얼마나 생각할지를 조절하는 손잡이다.

| 항목 | 내용 |
|---|---|
| 단계 | 낮음 · 중간 · 높음 · 아주 높음 · 최대 (5단계) |
| 기본값 | 높음 |
| 권장 시작점 | 높음으로 시작해 직접 돌려보고 조정 |
| 비용·속도 조절 | 낮음·중간을 주로 활용 |
| 컨텍스트 | 최대 100만 토큰 기억, 한 번에 출력 가능한 답은 최대 12.8만 토큰 |

이전 모델에서 효과 있던 방식과 달리, Opus 5는 지시를 더 얹을수록 좋아지지 않고 스스로 하는 일이 늘어난 만큼 같은 지시를 겹치면 토큰만 낭비된다. 이전 모델용 프롬프트를 그대로 옮기지 말고 강도를 처음부터 다시 맞추는 것이 공식 권장 사항이다.

**지워야 할 지시문** — 공식 프롬프트 가이드가 강조하는 것은 "이렇게 쓰라"가 아니라 "이건 빼라"다. 다음 3가지는 예전 모델에서는 품질을 높였지만 Opus 5에서는 비용만 늘리고 효과가 없거나 오히려 나빠진다: "다시 확인해봐" 류의 재확인 요구, "검증 단계를 넣어라" 류의 과잉 검증 지시, 검증용 보조 Claude를 별도로 두는 방식. 대신 "심각한 것만 보고해"처럼 코드 검토 범위를 좁히는 지시로 대체하는 것이 권장된다.

**개발자용 신기능** — 대화 중 도구 변경(베타): 대화 도중 도구를 바꿔도 프롬프트 캐시가 유지됨. 자동 폴백(베타): 안전 분류기에 걸린 요청은 다른 모델(기본적으로 Opus 4.8)이 자동으로 이어받음.

## 에이전트 스킬 (Agent Skills)

> Claude에게 특정 작업의 절차·노하우·금지사항을 담아 설치하는 지침서 파일(`SKILL.md`). "클로드는 요리사, 스킬은 요리 레시피"에 비유되며, 한 번 설치하면 관련 요청이 들어올 때 Claude가 알아서 꺼내 쓴다.

### 개요

스킬은 매번 "이런 말투로 써줘", "이 형식 지켜줘"를 반복 설명하는 비효율을 없애는 기능이다. 파일 하나(`SKILL.md`)가 하나의 매뉴얼이며, Claude·[[Codex]]·Cursor 등 "에이전트 스킬" 표준을 지원하는 여러 AI 도구에서 공용으로 쓸 수 있다. 커뮤니티에 공개된 스킬만 수만 개이며 대부분 무료다.

### 설치 방법

| 환경 | 방법 |
|---|---|
| Claude 웹/앱 (Pro 이상) | GitHub의 `Code → Download ZIP` → 설정(Settings) → 기능(Capabilities)에서 "클라우드 코드 실행" 켜기 → Customize → Skills → "+" → ZIP 업로드 → 목록에서 토글 켜기 |
| Claude Code | `npx skills add <저장소>` 또는 `git clone <저장소> ~/.claude/skills/<이름>` 한 줄로 설치. `/plugin` 마켓플레이스를 통한 설치도 가능 |

설치 후 "지금 사용할 수 있는 스킬 목록 보여줘"로 적용 여부를 확인할 수 있고, 세션 재시작이 필요한 경우가 있다.

### 발동 방식

- **자동 발동**: 요청 내용이 스킬 설명과 맞아떨어지면 Claude가 알아서 선택해 사용
- **직접 호출**: "OO 스킬 써서 해줘"처럼 이름을 언급하거나 `/스킬이름`으로 슬래시 호출하면 100% 발동

여러 스킬을 동시에 설치해도 작업에 맞는 것만 골라 쓰므로 충돌 걱정은 적고, 오히려 조합(예: 마케팅 스킬로 기획 + 영상 스킬로 제작)될 때 시너지가 난다.
