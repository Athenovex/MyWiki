# Codex

> OpenAI의 코딩 전용 AI 에이전트. [[GPT-5.6]]의 3개 모드 중 하나(개발자용)이자, 데스크톱 앱으로도 제공되어 플러그인 생태계(예: 챗컷)를 갖춘다. [[Claude|Claude Code]]에 대응하는 OpenAI 진영의 코딩 에이전트로 이해할 수 있다.

## 개요

ChatGPT 안에서는 Chat(질문응답)·Work(파일·앱 넘나드는 작업)와 구분되는 코드 작성 전용 모드로 동작한다. 별도로 **Codex 데스크톱** 앱이 존재하며, 여기에 플러그인을 연결해 코딩 외 영역(영상 편집 등)까지 확장할 수 있다.

## 챗컷 (Chatcut) — Codex 데스크톱 영상 편집 플러그인

Codex 데스크톱에 플러그인으로 연결해 쓰는 AI 영상 편집기. Codex 대화창에 편집 목표를 입력하면 챗컷 프로젝트가 열리고, **영상 업로드 → 프롬프트 편집 → 대본·타임라인 보정 → 자막·모션·에셋 생성 → 내보내기**까지 하나의 흐름으로 처리한다.

> ⚠️ 정보 손실 안내: 원본 자료의 세부 섹션(편집 프롬프트 예시, AI 에이전트 편집, 자막·모션그래픽 생성법, 무료 플랜·크레딧 기준)은 웹클리핑 과정에서 토글(아코디언) 안의 본문이 소실되어 제목만 확인 가능했다. 상세 사용법이 필요하면 원본 링크를 다시 확인해야 한다.
