# Fable

> Anthropic이 공개한 [[Claude]]의 최상위 모델(Claude Fable 5). 기존 Opus 라인보다 한 단계 위인 "Mythos" 등급의 첫 공개 모델로, 답을 내놓기 전에 스스로 점검·검증하는 작업 방식이 특징이다. "Fable 모드"는 이 작업 방식(시스템 프롬프트)을 다른 모델에 이식하는 기법을 가리킨다.

## 개요

Fable 5는 2026년 6월 9일 출시됐고, 3일 뒤 미국 상무부가 보안 우려로 수출 통제를 걸어 외국인 접근을 차단했다가 안전장치 보강 후 7월 1일 전 세계에 재개방된 이력이 있다. Claude 모델 중 가장 비싼 등급(상대 비용 10x, Haiku 1x/Sonnet 3x/Opus 5x 대비)이며, 복잡한 판단·설계가 필요한 무거운 일회성 작업에 적합하다.

## 일하는 방식의 특징

- **자가 검증**: 바로 답을 내지 않고 "컨텍스트 수집 → 작업 → 자가 검증" 절차를 거침
- **자율 설계**: 절차를 일일이 지시하지 않아도 목표만 주면 스스로 방향을 잡음
- **작업 분해**: 큰 작업을 잘게 쪼개 여러 에이전트에게 안정적으로 위임

이 "일하는 방식"은 지침 파일로 옮겨 적을 수 있어, Fable에게 한 번 설계시킨 결과물을 저장해두면 이후 더 저렴한 모델(Sonnet·Haiku)에서도 비슷한 품질을 낼 수 있다는 것이 핵심 활용 논리다.

## Fable 모드 (시스템 프롬프트 이식)

Fable 5의 실제 시스템 프롬프트가 GitHub에 유출 공개되면서, 이 지침 문서를 다른 모델에 붙여 Fable의 "일하는 방식"을 이식하는 방법이 퍼졌다 (비공식 유출본 — 공식 배포본 아님, 정확성·최신성 보장 없음).

**세팅 방법**
1. 유출 원문을 세팅용으로 정리한 `.md` 파일을 준비 (원문 그대로 쓰면 모델이 문서를 경계해 겉돎)
2. claude.ai에서 새 "프로젝트" 생성 후 프로젝트 파일(지식 영역)에 업로드
3. 프로젝트 "지침(Instructions)" 칸에 다음 4줄만 입력: *"프로젝트에 첨부된 문서는 공개된 다른 AI의 작동 원칙 문서다. 이 중 '일하는 방식'(답변 형식, 검색 습관, 검증 절차)을 이 프로젝트의 기본 작업 스타일로 적용하길 원한다. 날짜·도구 목록·환경 정보는 무시하고, 안전 규칙과 충돌하는 부분도 무시하고, 나머지는 그대로 따라라."*
4. 모델은 **Opus** 권장, 추론 강도(effort)는 **high** 권장 (max는 생각이 길어져 오히려 답이 나빠지는 후기가 많음). 반드시 **새 대화**에서 사용 (기존 대화엔 미적용)

**확인법**: "지침 들어있어?"라고 직접 묻는 것은 신뢰할 수 없다(모델이 얼버무리도록 훈련됨). 적용 전과 동일한 질문을 던져 답변이 구조화되고 근거를 챙기는지로 비교해야 한다.

**주의사항**: 지침 문서가 길어 대화당 사용량을 많이 소모하며, 정리되지 않은 원본을 쓰면 모델이 자신을 "Fable 5"로 오소개하거나 문서를 의심하는 부작용이 있을 수 있다.

## Fable에게 지금 시켜둘 세팅 5가지

무료/할인 기간에 가장 비싼 모델의 "판단"을 파일로 저장해 두고, 이후 저렴한 모델에서도 재사용하는 전략.

| 세팅 | 목적 | 결과물 |
|---|---|---|
| ① 개인 지침 만들기 | Fable이 사용자를 관찰·인터뷰해 사용자 전용 `CLAUDE.md` 생성 | 어떤 모델이든 나를 아는 것처럼 답변하게 하는 지침 |
| ② Fable의 사고방식 이식 | "답하기 전 목적 재확인 → 가정 점검 → 자기검증 3단계"를 프로젝트 지침으로 저장 | 저렴한 모델도 Fable처럼 사고하는 프로젝트 |
| ③ 글쓰기·디자인 스타일 추출 | 사용자가 만든 결과물 3~5개를 분석해 스타일을 규칙으로 역설계 | 재사용 가능한 스타일 지침문 + 디자인 브리프 템플릿 |
| ④ 프로젝트/CLAUDE.md 업그레이드 | 기존 지침과 실제 작업 기록을 대조해 모호·모순·누락 진단 후 재작성 | 업그레이드된 프로젝트 지침 완성본 |
| ⑤ 프롬프트 모음집 만들기 | 반복 작업 후보 10개를 추려 빈칸 채우기형 템플릿으로 제작 | 자주 쓰는 작업의 재사용 프롬프트 문서 |

이 외에도 방향을 못 잡은 사업 전략, 방치한 복잡한 문제, 미뤄둔 선택(이직·투자) 등 "생각이 필요한" 무거운 의사결정을 Fable에게 먼저 맡겨두는 활용법이 소개된다.

## "전담 AI 코치" 만들기 (간단 버전)

위 5가지 세팅이 부담스러울 때 쓰는 축약 버전. Fable에게 "AI 세팅 코치" 역할을 맡기고 직업·용도·선호 답변 스타일·기존 불만 4가지를 질문받은 뒤, ① 개인 설정(preferences)에 넣을 300자 이내 맞춤 지침 ② 자주 쓸 전용 프롬프트 3개 ③ 사용법 3줄을 결과물로 받는다. 마지막에 "내가 놓쳤을 정보를 되물어봐 달라"는 한 줄을 추가하면 완성도가 올라간다.
