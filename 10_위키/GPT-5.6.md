# GPT-5.6

> OpenAI가 출시한 최신 모델 패밀리. Sol(플래그십)·Terra(가성비)·Luna(최속·최저가) 3종으로 나뉘며, 프롬프트 하나로 몇 시간에서 며칠씩 자율적으로 작업을 완수하는 장시간 자율 작업 능력이 특징이다.

## 개요

| 모델 | 포지션 | 용도 |
|---|---|---|
| Sol | 플래그십(최고 성능) | 복잡한 작업, 코딩, 에이전트 |
| Terra | 중간 티어(가성비) | 일상 업무 대부분 |
| Luna | 최속·최저가 | 빠른 질문, 대량 처리 |

이전 버전 대비 3가지 차이가 강조된다: ① **장시간 자율 작업** — 프롬프트 하나로 몇 시간~며칠씩 혼자 작업(예: 일주일간 자율 작업으로 3D 맨해튼 완성). ② **컴퓨터 사용(computer use) 강화** — 자신이 만든 결과물을 직접 열어보고 스스로 수정. ③ **울트라 모드** — 여러 에이전트를 동시에 굴려 큰 작업을 병렬 처리하는 최고 성능 모드(Pro 요금제 전용).

Plus 요금제(월 $20)는 사용량 제한이 빡빡해 대형 작업 1~2개면 한도가 끝난다는 후기가 많아, 가벼운 작업은 Terra/Luna로 분산하는 것이 권장된다.

## 3개 모드

| 모드 | 설명 |
|---|---|
| Chat | 기존 ChatGPT처럼 질문에 답변 |
| Work | 내 앱·파일을 넘나들며 작업을 대신 완수 |
| [[Codex]] | 코드 작성 전용 (개발자용) |

게임·웹사이트·3D 제작류는 Codex, 문서·조사·자동화류는 Work에서 실행하는 것이 권장된다.

## 공식 프롬프팅 원칙

OpenAI가 GPT-5.6 전용 프롬프팅 가이드에서 제시하는 핵심 3가지:

- "단계별로 생각해줘" 같은 옛 지시는 오히려 방해가 됨 — **원하는 결과물만 명확히** 쓴다
- 작업을 잘게 쪼개지 말고 **통째로 맡긴다** — 긴 작업에 강한 모델이기 때문
- 결과 검증 기준(예: "모바일에서 깨지지 않아야 함")을 프롬프트에 미리 넣으면 스스로 확인하고 고침

## 활용 원칙 3가지

1. **쪼개지 말고 통째로 맡긴다** — 큰 목표를 한 번에 주고 오래 돌리는 방식이 이 모델의 강점을 살린다
2. **"스스로 확인해"를 프롬프트에 명시한다** — 자기 결과물을 직접 실행·검토·수정하게 하는 한 줄이 품질을 가장 크게 바꾼다
3. **사용량은 전략적으로 분배한다** — 가벼운 작업은 Terra/Luna, 승부처에만 Sol을 사용

## 실사용 사례 요약

Blender 3D 모델링(파이썬 스크립트로 직접 조작), 화면 녹화 기반 모션그래픽 영상 제작, 시네마틱 원페이지 웹사이트, 도시 3D 인터랙티브 복제, RPG 게임 개발(리드 에이전트+서브에이전트 분업), 브랜드 커스텀 폰트 제작(.otf 출력), 보험료 비교 자동화(폼 작성 대행, 제출 전 사용자 확인 필수), 마인크래프트 클론 게임 등이 소개된다. 공통적으로 "완성 후 직접 실행해서 확인하고 수정해줘"라는 지시가 결과물 품질을 좌우한다.
