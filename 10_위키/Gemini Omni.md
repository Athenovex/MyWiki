# Gemini Omni (Omni Flash)

> [[Gemini]] 계열의 영상 생성·편집 모델. 영상 편집 프로그램 없이 "이 자동차를 빨간 스포츠카로 바꿔줘"처럼 문장으로 지시하면 원본 영상을 그대로 변형해준다. Gemini 앱에서 직접 쓰거나, [[Higgsfield]] 같은 크리에이티브 스위트를 통해서도 접근할 수 있다.

## 개요

핵심 흐름은 "원본 영상 → 원하는 문장 입력 → 결과 영상" 3단계로, 타임라인이나 마스크 같은 편집 개념 없이 자연어(한국어 포함)만으로 스타일 변경·분위기 전환·사물 교체·자막 추가·카메라 움직임 지정이 가능하다. 기본 8초, 최대 60초 길이의 영상을 생성한다.

## 사용법

1. Gemini 앱 또는 Higgsfield의 "영상 만들기(Create → Video)" 메뉴에서 모델을 **Gemini Omni Flash**로 선택
2. 편집할 원본 영상을 업로드 (참고 이미지 최대 7장 추가 가능)
3. 원하는 변경을 문장으로 입력 (예: "비 오는 밤 감성으로 바꿔줘")
4. 생성 후 마음에 안 들면 같은 세션에서 "배경을 더 어둡게"처럼 이어서 수정 요청

## 프롬프트 요령

- **한 번에 하나씩만 수정**: 한 문장에 한 가지 변경만 담아야 정확도가 올라간다
- **참고 이미지 첨부**: 사물·인물을 교체할 때 참고 이미지를 함께 넣으면 구도·색감까지 그 이미지를 따라간다
- **저해상도로 먼저 확인**: 720p로 빠르게 검토한 뒤 마음에 들면 1080p로 변환해 크레딧을 아낀다
- **"무엇을 + 어떻게" 순서**로 구체적으로 작성

## 실전 워크플로우: 레퍼런스 스타일 재현

[[Claude]]와 조합해 마음에 드는 영상 스타일을 자신의 대본으로 재현하는 파이프라인 (사용 도구: Claude → Gemini Omni → CapCut → 배포).

1. **레퍼런스 영상 찾기**: 인스타그램·Pinterest·YouTube에서 원하는 스타일의 모션 디자인 영상 1~2개 확보, 대본도 함께 준비
2. **Claude에 스타일 분석 요청**: 레퍼런스 영상과 대본을 첨부해 애니메이션 스타일·움직임 특징·전환 방식·색상 팔레트·타이포그래피·카메라 움직임·분위기·사운드 느낌을 8가지 항목으로 분석시킨다
3. **씬별 프롬프트 생성**: Claude가 대본을 8~10초 단위 씬으로 쪼개고(Gemini Omni가 한 번에 생성 가능한 최대 길이), 씬마다 화면 요소·정확한 텍스트(최대 5~6단어)·색상·카메라·전환·사운드를 담은 상세 프롬프트를 작성
4. **씬별 영상 생성**: Gemini Omni에서 씬 프롬프트와 **레퍼런스 영상을 함께 첨부**해 생성 — 레퍼런스를 첨부하지 않으면 Omni가 스타일을 임의로 만들어버리므로 반드시 첨부
5. **채팅으로 수정**: 어색한 부분은 "텍스트 더 크게 해줘"처럼 채팅으로 바로 수정 요청
6. **CapCut에서 조립**: 생성된 씬들을 순서대로 배치하고 음악·내레이션 추가 후 내보내기. 화면 텍스트가 깨졌다면 CapCut·Figma에서 직접 재입력 (AI는 아직 텍스트를 완벽하게 그리지 못함)

씬 프롬프트는 영어로 작성하면 결과물 품질이 더 좋고, 한글 자막은 CapCut에서 별도로 얹는 것이 권장된다.
