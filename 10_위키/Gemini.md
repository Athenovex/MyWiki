# Gemini

> 구글이 만든 멀티모달 대화형 AI. 글·표·데이터를 이해·분석하고, 기획·스크립트·자막·아이디어 도출의 "두뇌" 역할을 하는 범용 어시스턴트이자 API 서비스.

## 개요

Gemini는 두 가지 형태로 언급된다: ① 사용자가 대화형으로 사용하는 어시스턴트(콘텐츠 기획, 데이터 분석 등), ② 애플리케이션에 통합하는 API(Gemini API).

## Gemini API 사용 구조 (클라이언트-서버)

사용자가 클라이언트를 통해 요청을 보내면, 서버가 Gemini API를 호출하고 응답을 받아 사용자에게 전달한다.

1. 클라이언트: 사용자가 질문 입력 → HTTP(S) Request(JSON)
2. 서버(애플리케이션 서버): 요청 검증 → Gemini API 호출(API Key 포함) → 응답 파싱·비즈니스 로직 처리
3. Gemini API(Google): 텍스트 생성·대화형 응답·요약/번역·코드 생성·멀티모달(텍스트+이미지) 등 기능 제공, Google Cloud 인프라(보안/확장성/가용성) 기반
4. 서버 → 클라이언트: 응답 반환

필수 구성요소: Gemini API Key(Google AI Studio 발급), HTTPS 통신, 백엔드 서버.

## 대화형 어시스턴트로서의 역할

- **기획 파트너**: 트렌드 분석, 콘텐츠 구성안, 스크립트·카피 작성, 아이디어 확장(해시태그·제목·A/B 문안)
- **자동 자막**: 영상 자막 초안 생성
- **데이터 분석 비서**: 엑셀·시트 데이터를 붙여넣으면 요약·패턴 분석, 자연어 질의응답, 표/차트 정리, Google Sheets 연동

## 관련 도구

- **Google AI Studio**: 이미지·영상 생성, 프롬프트 실험 등을 수행하는 스튜디오
- **flow**: 이미지·영상·사운드 소스를 하나의 콘텐츠로 통합·연출하는 제작 흐름 도구
