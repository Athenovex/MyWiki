# Higgsfield

> AI 네이티브 크리에이티브 스위트(AI-native creative suite). 이미지·영상 생성 모델 여러 개(Soul 2, GPT Image 2, Seedance, Gemini Omni Flash 등)를 하나의 플랫폼에서 쓸 수 있고, [[Claude]] 등 AI 에이전트와 [[MCP]]로 직접 연결할 수 있다.

## 개요

구글 계정 등으로 로그인만 하면 바로 쓸 수 있으며, 상단 "영상 만들기(Create → Video)" 메뉴에서 [[Gemini Omni]] 같은 모델을 선택해 원본 영상을 문장으로 편집할 수 있다. 별도 프로그램 지식 없이도 이미지·영상 생성부터 편집까지 한 플랫폼에서 처리하는 것이 특징이다.

## Claude와 MCP로 연결하기

1. Claude(claude.ai) → 설정 → 커넥터(Connectors)
2. 커스텀 커넥터 추가 → Higgsfield URL 직접 입력: `https://mcp.higgsfield.ai/mcp`
3. Higgsfield 계정으로 OAuth 로그인 → 권한 승인
4. 대화창에 "힉스필드 크레딧 잔액 알려줘"처럼 입력해 연결 확인

MCP로 연결하면 Claude가 대화 중에 직접 이미지·영상 생성을 요청하고 결과를 받아 다음 단계로 이어갈 수 있다 — "무드 4장 뽑아줘" 한마디로 생성→셀렉→합성→영상화가 하나의 대화 흐름 안에서 처리되는 이유다. 이미지·영상 생성은 크레딧을 소모하므로 단계별 생성 수량을 미리 정하고, 고해상도(4K)는 최종 셀렉본에만 사용하는 것이 권장된다.

**MCP 연결 전/후 비교**: 연결 전에는 Higgsfield 사이트에 따로 로그인해 프롬프트를 입력하고, 수정할 때마다 다시 사이트로 돌아가 결과물을 다운로드해 별도 보관하며, 대본·아이디어는 또 다른 Claude 창에서 따로 물어봐야 했다(여러 탭을 오가며 복사-붙여넣기). 연결 후에는 Claude 대화창에 "이런 영상 만들어줘"라고 요청하면 Claude가 Higgsfield 기능을 직접 호출해 결과를 바로 가져오고, "이 부분만 다르게 해줘"처럼 같은 대화에서 이어서 수정할 수 있다 — 대본 작성·아이디어 정리·영상 생성이 하나의 대화 흐름 안에서 끝난다. 이전 대화 맥락을 기억한 채 수정 요청이 가능하다는 것과, 반복되는 제작 과정을 자동화하기 좋다는 것이 핵심 장점이다.

**연결 절차 요약**: ① Higgsfield 사이트 로그인 → 설정(또는 상단 메뉴)의 "MCP" 항목에서 MCP 서버 URL 복사(`https://mcp.higgsfield.ai/mcp` 형태) ② Claude.ai → 사용자 지정 → 커넥터(Connectors) → 커스텀 커넥터 추가 → 복사한 URL 붙여넣기 → (인증 필요 시) OAuth Client ID/Secret 입력 → 추가 및 인증 완료 ③ 새 대화에서 커넥터가 켜짐(on) 상태인지 확인 후 프롬프트 입력.

## 실전 워크플로우: 손스케치 → 목업 포스터

Claude + Higgsfield MCP로 손그림 스케치 한 장을 하이엔드 목업 포스터와 광고 영상까지 만드는 파이프라인. 핵심 설계 철학은 **구도와 무드를 분리**하는 것 — 스케치는 "무엇이 어디에 놓이는가"만 담당하고, 분위기(색감·조명·질감)는 별도 단계에서 탐색한 뒤 마지막에 합친다. 이렇게 하면 어떤 스케치를 넣어도 일관된 품질이 나온다.

**파이프라인**: `① MCP 세팅` → `② 스케치 라벨링` → `③ Claude 업로드+프롬프트` → `④ Soul 2 무드 탐색` → `⑤ GPT Image 2 구도×무드 합성` → `⑥ Seedance 영상화`

1. **스케치 준비**: 종이·태블릿에 원하는 구도를 스케치(그림 실력 무관, 위치·크기 비율·겹침 관계만 전달되면 충분). 각 도형 위에 눈에 띄는 색(빨강 권장)으로 `제품명`, `소품A`처럼 디지털 텍스트 라벨을 단다 — 같은 오브제가 여럿이면 전부 라벨링. 손글씨보다 디지털 텍스트가 인식률이 높다
2. **Claude 업로드 + 시작 프롬프트**: 라벨링된 스케치를 Claude에 업로드하고, "힉스필드 MCP 사용해서 이 스케치 구도로 하이퀄리티 목업 포스터 제작해줘"와 함께 3단계 프로세스(① 구성요소 파악 → ② Soul 2로 무드 3방향×4장 생성 → ③ 고른 무드+스케치로 GPT Image 2 합성)를 지시. Claude가 스케치의 구도를 언어로 재기술하므로, 의도와 맞는지 검수 후 필요하면 수정 요청
3. **Soul 2로 무드 이미지 생성**: Soul 2는 에디토리얼·감성 표현에 강해 무드보드 용도로 최적. 구도는 무시하고 분위기만 탐색 — 조명(빛의 방향·성질), 재질·질감, 색 팔레트, 렌즈 느낌(매크로, 얕은 심도), "high-end editorial" 같은 광고 사진 키워드로 프롬프트를 구성하며, 3가지 방향은 조명·배경·톤이 확실히 구분되게 설계
4. **GPT Image 2로 구도×무드 합성**: 선택한 무드 이미지를 먼저, 스케치를 뒤에 넣어 quality를 high로 설정하면 스케치 구도 그대로 + 선택한 무드로 최종 포스터가 나온다
5. **Seedance로 영상화**: 최종 이미지를 4K로 업스케일 요청 → Seedance 2.0으로 영상화 요청 (길이 4~15초, 해상도 720p/1080p/4K 중 선택)

## 앱 빌더 (App Builder)

Higgsfield 구독자가 [[Fable]](Claude Fable 5 모델)로 대화하며 Higgsfield 안에 자신만의 미니 앱(웹사이트·게임 등)을 만들 수 있는 기능. 반복적으로 수행하는 이미지·영상 생성 작업을 매번 프롬프트를 새로 짜는 대신, 옵션 선택 몇 번으로 끝나는 전용 도구로 만들어두는 용도다.

**사례: 화장품 연출컷 자동 생성 앱** — 기본 정면컷 이미지 한 장을 업로드하면 정면컷·듀얼컷·손으로 든 컷·초근접 디테일컷 등 상세페이지용 연출컷 8장을 자동 생성하는 앱. 제작 과정은 ① Higgsfield 앱 빌더에서 Fable 5에게 "화장품 연출컷을 생성해주는 앱 만들어줘. 기본컷을 업로드하면 8개의 연출컷이 생성되도록 해줘. 배경색은 업로드된 제품 컬러 팔레트 기준으로 맞춰줘" 같은 초기 프롬프트를 준 뒤, ② 각 구도(Hero Front Shot, Dual Product Shot, Close-up Hand Shot 등)별로 조명·구도·배경을 구체적으로 지시하는 프롬프트를 여러 번 수정해 최종본으로 확정하는 방식이다. 완성된 앱은 웹사이트 형태로 배포되어 누구나 기본 이미지만 넣으면 8컷을 생성할 수 있다.

## Seedance 2.0 — FPV 드론 영상 프롬프트

Higgsfield의 Seedance 2.0 4K 모델로 몰입감 있는 1인칭 FPV(First-Person View) 드론 비행 영상을 만드는 프롬프트 기법. 핵심은 **참고 이미지 위에 빨간 선으로 카메라 경로를 직접 그려서 지정**하는 것이다.

**작성 절차**: ① 원하는 장소 이미지 위에 빨간 선으로 카메라 이동 경로를 그린다 ② 시작점은 1, 경유지는 2, 도착지는 3으로 번호를 매긴다 ③ 프롬프트 안의 장소·주요 피사체·최종 도착 지점만 상황에 맞게 바꿔 사용한다 ④ **빨간 경로 표시 자체는 최종 영상에 나오면 안 된다는 것을 프롬프트에 반드시 명시**한다(전처리 지시로 "빨간 선·화살표·낙서를 제거하고 원래 장면을 자연스럽게 복원하라"는 문장을 넣음).

재사용 가능한 스탠다드 프롬프트 골격:

```
Create a first-person, one-take FPV drone flight shot with a cinematic atmosphere...
The camera starts at [Node 1: 시작점]. From there, it flies toward [주요 피사체/장소]
while following the red path... The final destination must be [Node 3: 최종 목표].
...
Final cleanup instruction: Remove all red path markings and all guide elements from
the final result. The red path is only a camera movement reference.
```

품질을 위해 "실제 촬영처럼 보이게"(anti-AI look: 왁스 같은 질감·건물 모양 변형·깜빡이는 디테일 금지), "자연스러운 가속·감속·뱅킹" 같은 카메라 물리 조건, 그리고 빨간 선·워터마크·중복 객체 등을 금지하는 네거티브 프롬프트를 함께 명시하는 것이 실사 같은 결과물의 핵심이다.

## 수익화 활용

Higgsfield로 만든 영상을 활용한 수익화 방법 두 가지가 소개된다.

- **영상 납품**: 제품 상세페이지 URL과 제품 사진을 Claude(Higgsfield MCP 연결 상태)에 주고 "광고영상 만들어줘"라고 요청하면, 상세페이지에서 제품 장점을 추출해 광고 영상을 제작한다. 이런 AI 광고 숏폼을 필요한 사람·업체에 납품하면 건당 20만원 이상의 수익을 기대할 수 있다고 소개된다(검증되지 않은 사례 기반 수치)
- **제휴수익(어필리에이트)**: 쿠팡파트너스·지그재그파트너스·올리브영 큐레이터·오늘의집 큐레이터·알리 어필리에이트 등과 협업해 구매 금액의 일정 수수료를 받는 방식. 제작한 영상에 사용 제품의 제휴 링크를 연결해 수익화한다
