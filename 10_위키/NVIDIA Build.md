# NVIDIA Build

> NVIDIA가 MiniMax·DeepSeek·GLM·Qwen 등 ChatGPT급 AI 모델 100개 이상을 무료 API로 개방한 플랫폼(`build.nvidia.com`). 개인 학습·콘텐츠 제작·실험 용도는 무료이고, 상업 서비스 운영에만 유료 라이선스가 필요하다.

## 개요

이메일만으로 가입할 수 있고 신용카드 등록 칸 자체가 없어 "모르는 사이 결제"가 발생할 구조가 아니다. 무료 한도는 분당 약 40회 호출(상향 신청 시 약 200회)이며, 한도를 넘으면 청구되지 않고 그냥 멈춘다. 입력 데이터는 모델 학습에 사용되지 않는다고 안내되지만, 무료 엔드포인트의 입출력은 기록·활용될 수 있어 개인정보·기밀 정보 입력은 피해야 한다.

## 용도별 추천 모델

| 용도 | 추천 모델 | 메모 |
|---|---|---|
| 글쓰기·요약 | MiniMax M3 | 성능 상위, 만능형 (Claude Opus보다 약간 아래급으로 소개됨) |
| 번역·다국어 | GLM 5.1, DeepSeek V4 | 한·중·영에 강함 |
| 이미지 생성·편집 | Qwen-Image / Qwen-Image-Edit | 한글 글자도 또렷하게 렌더링 |
| 음성 생성 | Chatterbox TTS | 23개 언어 더빙 지원 |
| 영상 생성 | Cosmos3 Nano | 사진 한 장을 짧은 영상으로 변환 |
| 코딩·자동화 | Mistral Nemotron, GLM 5.1 | 도구 호출(tool calling)에 강함 |

모델 목록은 자주 바뀌므로 최신 목록은 `build.nvidia.com/models`에서 확인해야 한다.

## 사용 방법 두 가지

### 방법 1 — 사이트에서 바로 쓰기

가입 → 모델 선택(글쓰기는 minimax/deepseek, 이미지는 qwen-image) → 모델 페이지 우측 Playground(채팅창)에 한국어로 바로 질문. 코드나 설치 없이 "Get API Key" 버튼을 누르지 않아도 이 단계만으로 무료 AI를 쓸 수 있다.

### 방법 2 — API 연동으로 나만의 도구 만들기

1. 모델 페이지에서 "Get API Key" 클릭 → 휴대폰 인증 1회 → `nvapi-`로 시작하는 키 발급 (비밀번호처럼 취급, 공개 노출 금지)
2. Claude나 ChatGPT를 열고, 역할·연결 정보(`base_url: https://integrate.api.nvidia.com/v1`, 모델 ID)·요구사항을 명시한 "주문서" 프롬프트를 붙여넣어 코드 생성을 요청 — 코드를 직접 짜지 않고 AI에게 "만들어줘"라고 시키는 방식(바이브 코딩)
3. 완성된 코드의 `YOUR_API_KEY` 자리에 발급받은 키를 넣으면 전용 도구가 작동

## 다른 도구·자동화에 연결하기

NVIDIA Build의 모델은 **OpenAI 호환** 방식이라 이미 OpenAI 연동을 지원하는 도구 대부분에 그대로 꽂힌다 — 바꾸는 것은 주소(base URL)와 API 키 두 가지뿐이다.

- **AI 코딩 도구** (Cursor·Cline·VS Code): OpenAI 호환 주소 입력란에 NVIDIA 주소·키를 넣으면 유료 모델 대신 무료 모델로 코딩 보조를 받음
- **노코드 자동화** (n8n 등): 문의 자동 분류·다국어 번역·뉴스 요약·RAG 챗봇 같은 파이프라인에 무료 모델을 백엔드로 연결
- **대량 번역**: 글자 수 과금 없이 여러 언어로 한 번에 번역
- **모델 비교**: 같은 프롬프트를 여러 모델에 돌려 용도에 맞는 모델을 직접 선별

대량 자동화 시 분당 약 40회 제한에 걸릴 수 있어 상향 신청이 필요할 수 있다.

## 실전 활용 시나리오

| 상황 | 순서 | 결과물 |
|---|---|---|
| 회의록 정리 | 메모 붙여넣기 → "3줄 요약+결정사항+할일+보고 메일 초안" | 요약+액션아이템+메일 초안 |
| 상품 판매 페이지 제작 | Qwen-Image-Edit로 배경 교체 → MiniMax M3로 상세페이지 카피 → 영문 번역 | 이미지+카피+영문판 |
| 릴스 콘텐츠 한 세트 | 후킹 문구 10개 → 캐러셀 8장 카피 → Qwen-Image 표지 → Chatterbox TTS 내레이션 | 기획+카피+표지+음성 |
| 반복 CS 응대 도구 | "고객 문의를 붙여넣으면 답변 초안을 뽑는 웹 도구 만들어줘" | 나만의 응대 창구 |

핵심은 한 모델로 끝내려 하지 않고 여러 모델을 이어 붙이는 것 — 글은 MiniMax, 이미지는 Qwen, 음성은 Chatterbox로 넘기는 식이다.

## 과금 기준

| 구분 | 무료 (개인·학습·실험) | 유료 (상업 운영) |
|---|---|---|
| 결제수단 | 카드 등록 없음 | NVIDIA AI Enterprise 라이선스 |
| 한도 | 분당 약 40회 (상향 시 약 200) | 라이선스 범위 내 |
| 비용 | 0원 | GPU당 연 약 4,500달러 또는 GPU 시간당 약 1달러 |

개발·테스트·학습·콘텐츠 제작은 무료이고, 실제 비즈니스 서비스 운영(production)에만 유료 라이선스가 필요하다. 정식 운영 전 90일 무료 체험도 제공된다.

## NVIDIA 공식 에이전트 스킬 (참고)

무료 API와는 별개로, NVIDIA가 [[Claude Code]]·Codex·Cursor 같은 코딩 에이전트에 자사 기술(CUDA, NeMo, Omniverse, 로보틱스 등)을 다루게 하는 공식 [[Claude 에이전트 스킬|스킬]]을 `npx skills add nvidia/skills`로 설치할 수 있다. 개발자·AI 엔지니어 대상이며, 일반 콘텐츠·업무 활용 목적이라면 무료 모델 API만으로 충분하다.
