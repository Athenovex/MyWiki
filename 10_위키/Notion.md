# Notion

> 페이지·데이터베이스 기반의 올인원 워크스페이스 툴. 문서 작성, 데이터베이스 관리, 일정 관리를 하나의 페이지 구조 안에서 처리한다.

## 개요

Notion(노션)은 모든 작업 단위를 "페이지"로 다루는 생산성 도구다. 페이지 안에 다시 페이지를 중첩할 수 있어, 최상위 페이지가 "거실"이라면 그 안의 하위 페이지들은 "방"에 비유된다 — 하나의 구조 안에서 문서·표·일정을 계층적으로 정리한다.

## 핵심 기능

| 기능 | 용도 |
|---|---|
| 페이지 | 모든 작업의 기본 단위. 페이지 안에 하위 페이지를 중첩 가능 |
| 콜아웃 | 인사말·주석·강조 문구를 박스 형태로 표시. 2개를 가로로 배치하면 정돈되어 보임 |
| 토글 | 이미지나 내용이 길 때 접어서 숨김. 화살표 클릭으로 펼침 |
| 제목 크기 (H1~H4) | 강조·단락 구분에 사용. `#` 개수로 레벨 결정 |
| 데이터베이스 표 | 여러 페이지를 담는 폴더 역할. 엑셀처럼 함수 계산도 가능 |
| 구분선 | 페이지를 시각적으로 분리. 하이픈(`-`) 3개 연속 입력으로 생성 |
| 캘린더 | 월별 일정을 한눈에 확인. 데이터베이스 표 보기로도 전환 가능 |

## 단축 입력

- **`#` + 스페이스**: 제목1, **`##`**: 제목2, **`###`**: 제목3, **`####`**: 제목4로 즉시 변환
- **`/` (슬래시) + 기능 이름 첫 글자**: 원하는 블록(표·이미지·데이터베이스 등)을 빠르게 생성. 가장 자주 쓰이는 입력 방식
- **`:` (콜론) + 이모지 이름**: 자동으로 이모지 삽입
- **텍스트 드래그 + `Ctrl+E`**: 인라인 코드 서식으로 키워드 강조
