# RAG (검색 증강 생성)

> 사용자의 질문에 대해 관련 정보를 외부 지식베이스에서 검색하고, 그 정보를 바탕으로 LLM이 더 정확하고 신뢰할 수 있는 답변을 생성하는 방식.

## 개요

대규모 언어모델의 출력을 최적화하기 위해, 응답 생성 전에 학습 데이터 소스 외부의 신뢰할 수 있는 지식베이스(예: 위키피디아, 기업 문서)를 참조한다. LLM의 환각(Hallucination) 문제를 극복하기 위한 대표적 기법이다.

## 작동 흐름 (5단계)

1. **질문 입력**: 사용자가 질문(프롬프트) 입력
2. **관련 정보 검색**: 질문(Query)을 바탕으로 지식베이스에서 관련 정보 검색
3. **관련 정보 전달**: 검색된 정보를 LLM에 전달해 맥락(Context) 강화
4. **맥락이 포함된 입력 전달**: 사용자 질문 + 검색된 정보를 합쳐 LLM에 입력
5. **답변 생성**: LLM이 맥락을 이해하고 더 정확한 답변 생성

지식베이스는 웹 문서(예: 위키피디아), 문서 파일(PDF·DOCX), 데이터베이스 등 다양한 외부 지식원이 될 수 있다.

## 장점

- 최신 정보 반영
- 환각(Hallucination) 감소
- 출처 기반의 신뢰성 향상
- 도메인 특화 지식 활용 가능

## 관련 지식

- [[LangChain]] — RAG 파이프라인(문서 로딩→분할→벡터 저장→검색→생성)을 구현하는 대표적 프레임워크
- [[임베딩]] — RAG의 검색 단계에서 문서와 질문을 벡터로 변환하는 데 사용
- [[FAISS]] — RAG의 벡터 데이터베이스로 흔히 사용되는 라이브러리
