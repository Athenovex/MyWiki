# SNS 콘텐츠 마케팅

> 채널별 콘텐츠 전략·캘린더·해시태그로 팔로워를 팬으로, 팬을 고객으로 전환하는 마케팅 방식. SNS(모으기) → 프로필 링크(안내) → 랜딩페이지(팔기) → 챗봇(응대) → 재구매로 이어지는 다리 역할을 한다.

> 아래 콘텐츠 캘린더 요일 테마, 해시태그 크기 구분, SNS 위기 대응 표, 스레드 프로필 예시와 판매 글 Before/After는 [[AI마케팅_이커머스_전문가과정]] 원본 슬라이드(본편 p.87-100, 부록 "스레드 마케팅 완전정복" p.130-158)에 실제로 등장하는 내용을 그대로 인용했다. 특히 무드컵의 실제 스펙("용량 500ml, 스테인리스 이중진공, 파스텔 5색")과 프로필 소개 문구, 판매 글 예시는 부록 실습 슬라이드(p.134, p.143)에서 그대로 가져온 것이다. 콘텐츠 캘린더의 구체적 캡션 문구, 챗봇 대화 스니펫은 원본에 없어 형식을 보여주기 위해 편집자가 작성했다 — 해당 부분은 표시해 두었다.

## 채널별 성격

같은 브랜드라도 채널마다 이용자의 소비 목적이 다르므로 콘텐츠 형태와 기대 효과를 구분해서 접근해야 한다. (원본 슬라이드 p.86 그대로)

| 채널 | 성격 | 기대 효과 |
|---|---|---|
| 인스타그램 | 감성·비주얼 중심 | 브랜드 이미지 구축 |
| 릴스·쇼츠·틱톡 | 짧은 영상 | 신규 도달 최고 (알고리즘 추천 노출) |
| 스레드·X | 텍스트·대화 | 빠른 화제성, 팬과의 직접 소통 |
| 블로그·유튜브 | 정보·검색 자산 | 시간이 지나도 검색 유입이 쌓이는 자산형 콘텐츠 |

## 콘텐츠 황금 비율 (50:30:20)

한 계정의 게시물을 판매 콘텐츠로만 채우면 팔로워가 이탈하므로, 아래 비율로 "팔로우할 이유"와 "떠나지 않을 이유"를 먼저 채운 뒤 판매를 얹는다. (원본 슬라이드 p.87 정의 그대로)

- **50% 가치 콘텐츠** (정보·꿀팁) — "이 계정을 팔로우하면 도움이 된다"는 이유를 만든다
- **30% 관계 콘텐츠** (공감·재미·브랜드 일상) — 브랜드를 사람처럼 느끼게 해 친밀감을 쌓는다
- **20% 판매 콘텐츠** (제품·혜택) — 너무 많으면 "광고 계정"으로 인식되어 팔로워가 이탈한다

## 콘텐츠 캘린더

요일별 테마를 미리 고정해두면 매일 "오늘 뭐 올리지"를 고민하지 않아도 되고, 팔로워 입장에서도 "이 요일엔 이 콘텐츠가 온다"는 기대가 생겨 재방문율이 올라간다. 원본은 이 표를 Gemini에게 그대로 주고 "이번 주 테마로 게시물 아이디어와 캡션을 표로 만들어줘"라고 요청하라고 제안한다.

요일별 테마(레이블은 원본 슬라이드 p.88 그대로, 캡션 예시는 형식을 보여주기 위한 편집자 작성):

| 요일 | 테마 | 예시 캡션(편집자 작성) |
|---|---|---|
| 월 | 정보·꿀팁 | "텀블러 세척, 이렇게 하면 냄새 안 나요" |
| 화 | 고객 후기 | "구매 고객님이 남겨주신 솔직 후기 모음" |
| 수 | 제품 소개 | "오늘 소개할 컬러는 파스텔 라인" |
| 목 | 브랜드 일상 | "무드컵 사무실, 오늘의 풍경" |
| 금 | 릴스·영상 | "3초 만에 알아보는 뚜껑 잠금법" |
| 토 | 이벤트·소통 | "댓글 이벤트, 참여만 해도 할인 쿠폰" |
| 일 | 휴식/재활용 | "이번 주 반응 좋았던 게시물 다시 보기" |

## 해시태그 전략

대형 태그(노출 큼, 경쟁 치열) + 중형 태그(타깃에 잘 닿음) + 소형·니치 태그(진짜 관심층) + 브랜드 태그를 섞어야 한다. 대형 태그만 쓰면 노출은 되지만 경쟁이 치열해 묻히기 쉽고, 소형 태그만 쓰면 정확한 타깃에는 닿지만 노출량 자체가 작다.

원본 슬라이드가 실제로 예시로 든 조합(p.93, 무드컵 브랜드 태그 포함 그대로 인용):

```
대형 태그   : #일상
중형 태그   : #자취요리
소형/니치 태그 : #자취생텀블러
브랜드 태그  : #무드컵
```

## 챗봇

브랜드 정보·FAQ·말투를 페르소나로 설정해 24시간 응대한다. 사람이 잠든 새벽에도 구매 직전 망설임을 즉시 해소해 이탈을 막는 역할을 한다. 원본은 "브랜드 정보·자주 묻는 질문·말투를 페르소나로 설정하면, 우리 브랜드 전담 상담원 챗봇이 된다"고 설명한다(p.91, 해커톤 산출물 예시로 언급). 구체적인 대화 스니펫은 원본에 없어 아래는 편집자가 형식을 보여주기 위해 작성했다:

```
고객: 색상 교환 되나요?
챗봇: 네! 미개봉 상태면 수령 후 7일 이내 무료 교환 가능해요.
      원하시는 컬러 알려주시면 재고 확인해드릴게요 😊
```

## SNS 위기 대응

부정 댓글을 몰래 삭제하거나 감정적으로 맞받아치지 않는다. 원본 슬라이드(p.95)가 실제로 대비시킨 잘못된 대응 vs 올바른 대응:

| 잘못된 대응 | 올바른 대응 |
|---|---|
| 부정 댓글을 몰래 삭제한다 | 빠르게 인정하고 사과한다 |
| 감정적으로 맞받아친다 | 차분하고 정중하게 답한다 |
| 못 본 척 무시한다 | 공개적으로 해결 과정을 보인다 |
| 변명·책임 회피로 일관한다 | 재발 방지책을 약속·실행한다 |

위기는 오히려 신뢰를 쌓을 기회이며, 진솔한 대응은 지켜보는 모두에게 좋은 인상을 남긴다(원본 문구). 실제 응대 문구 예시는 원본에 없어 위 원칙을 대입해 편집자가 작성했다:

```
Before(피해야 할 대응): 부정 댓글 삭제 후 무대응
After(권장 대응): "불편을 드려 죄송합니다. DM으로 주문번호 남겨주시면
                  바로 확인 후 교환/환불 도와드리겠습니다."
```

## 스레드(Threads) 마케팅 (텍스트 중심 SNS)

스레드는 사진·영상 없이 "한 줄"로 시작하는 텍스트·대화 중심 SNS다. 인스타그램 계정으로 즉시 시작할 수 있고, 상대적으로 성장 초기 단계의 플랫폼이라 팔로워가 적어도 노출이 잘 되는 편이라 초기 진입에 유리하다. (원본 부록 p.130-132)

- **계정 설계**: 한 줄 정체성("누구에게 무엇을 주는 계정"인지 프로필에서 즉시 파악되는 문구), 2~3개 핵심 주제로 좁히기, 톤 정하기(전문가형·친구형·솔직형), 프로필 최적화.
- **콘텐츠 6유형**: 꿀팁·정보 / 경험·후기 / 질문·투표 / 생각·관점 / 비하인드 / 리스트형. 매번 새로운 유형을 고민하지 않고 이 6개를 로테이션하면 소재 고갈을 막을 수 있다.
- **글 구조**: 훅(첫 줄, 스크롤을 멈추게 하는 한 문장) → 전개(짧은 문장, 잦은 줄바꿈으로 가독성 확보) → 핵심 메시지 → 마무리·유도(댓글·저장 유도).
- **성장 원리**: 꾸준함(매일 1~3개) > 댓글 소통 > 일관된 주제 반복 > 저장/공유 유도.
- **판매 전환**: 신뢰 먼저·판매 나중. 스펙을 나열하기보다 "왜 이 제품을 만들었나"라는 스토리로 파는 방식이 텍스트 중심 플랫폼에 더 잘 맞는다. 프로필 링크로 랜딩페이지 유도.
- **90일 로드맵**: 1개월 기반(계정 세팅, 매일 게시, 톤·주제 확립, 첫 팬 형성) → 2개월 확장(시리즈·소통 강화, 반응 데이터로 콘텐츠 최적화) → 3개월 전환(신뢰 기반 판매·링크 유도, 협업·라이브로 확산).

### 실제 무드컵 프로필 예시

원본 부록(p.134)에 실제로 실린 "좋은 소개 예시" (그대로 인용):

```
무드컵 | 감성 텀블러
매일의 기분을 담는 텀블러를 만듭니다.
손에 감기는 그립감, 파스텔 컬러.
커피 좋아하는 당신을 위한 이야기 ↓
```

### 실제 판매 글 Before/After (무드컵 실제 스펙 포함)

원본 부록(p.143)에 실제로 실린 예시. 이전 노트에서 "편집자가 지어낸 가상 스펙"이라고 밝혔던 500ml·스테인리스 이중진공·파스텔 5색·40% 할인은 사실 원본 슬라이드에 그대로 등장하는 실제 스펙이다:

```
광고 티 나는 글 (✕)
무드컵 텀블러 출시!
용량 500ml, 스테인리스 이중진공, 파스텔 5색.
지금 40% 할인! 링크에서 구매하세요!!

이야기로 파는 글 (○)
아침마다 커피가 금방 식어서 스트레스였어요.
그래서 6개월간 텀블러를 뜯어봤습니다.
손에 감기는 그립감에 특히 신경 썼는데,
써본 분들이 '이거 놓기 싫다'고 하시더라고요
(궁금하시면 프로필 링크에 있어요)
```

### 실제 텀블러 리라이팅 예시 (밋밋한 글 → 살아난 글)

원본 부록(p.148)에 실제로 실린 예시. 그립감을 강조하는 어조가 위 무드컵 스펙과 자연스럽게 이어진다:

```
밋밋한 글 (✕)
텀블러를 고를 때는 보온력과 용량, 그립감을 잘 살펴보는 것이 중요합니다.
저는 여러 제품을 비교해본 결과 이런 기준이 좋다고 생각합니다.

살아난 글 (○)
텀블러 살 때 이거 하나만 보세요.
바로 '그립감'.
보온·용량은 다 비슷비슷해요.
결국 매일 손에 쥐는 느낌이 다 하더라고요.
여러분은 뭐 보고 고르세요?
```

### 스크롤을 멈추는 첫 문장(훅) 예시

원본 부록(p.136)이 실제로 든 6가지 훅 유형과 예문(그대로 인용, 무드컵과 무관한 일반 예문):

```
숫자로 시작   : "3년간 마케팅하며 배운 5가지"
반전·의외    : "광고비를 0원으로 줄였더니 매출이 올랐다"
질문 던지기   : "왜 당신의 게시물은 안 팔릴까?"
고백·솔직함   : "솔직히 처음엔 다 실패했습니다"
강한 주장    : "팔로워 수는 사실 중요하지 않다"
결과 먼저    : "이 한 문장으로 문의가 2배 됐다"
```
