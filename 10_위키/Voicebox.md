# Voicebox

> 오픈소스 AI 보이스 스튜디오. AI 음성 생성·목소리 복제·음성 받아쓰기(타이핑) 세 기능을 하나로 묶은 무료 앱으로, 모든 처리가 인터넷 서버가 아닌 **사용자 컴퓨터 안에서(100% 로컬)** 이뤄진다.

## 개요

일레븐랩스 같은 유료 구독형 서비스와 달리 완전 무료이며 계정 가입도 필요 없다. 목소리 데이터가 회사 서버로 전송되지 않고 내 컴퓨터에만 저장되는 것이 핵심 차별점이다. 최초 AI 모델 다운로드 때만 인터넷이 필요하고 이후에는 오프라인에서도 작동한다. 컴퓨터 사양(특히 GPU)에 따라 처리 속도가 달라진다.

## 설치

`voicebox.sh/download`에서 Mac(애플 실리콘/인텔) 또는 Windows 10 이상용 설치 파일을 받는다. 저장 공간 5GB 이상 필요(AI 모델 다운로드용). 첫 실행 시 모델 다운로드가 진행된다.

## 핵심 기능

| 기능 | 설명 |
|---|---|
| 보이스 프로필 | 모든 기능의 선행 조건. Built-in voice(녹음 불필요) 또는 Clone from audio(내 녹음으로 복제) 중 선택해 생성 |
| AI 음성 생성 (TTS) | 텍스트 입력 → 보이스 프로필 선택 → TTS 모델 선택 → 생성. 한국어는 **Qwen3-TTS 1.7B** 권장 |
| 목소리 복제 | 몇 초 분량의 음성 샘플로 복제. 한국어 포함 23개 언어 지원, 감정 표현 태그 삽입 가능. **본인 또는 동의받은 목소리만** 복제할 것 |
| 받아쓰기 | 글로벌 단축키를 누르고 말하면 카톡·메모장 등 어떤 앱에도 텍스트가 입력됨 |
| 캡처(Captures) | 받아쓰기·녹음 음성이 원본 오디오+텍스트 세트로 자동 저장. 말버릇("음", "어") 자동 정리, 클릭 한 번으로 복제용 샘플 등록 가능 |
| 스토리즈(Stories) | 유튜브 나레이션·팟캐스트급 긴 오디오 편집. 타임라인 배치, 여러 목소리 혼합, 최대 5만 자 대본 자동 분할 생성 |
| 이펙트 | 피치·리버브·딜레이 등 8종 후처리 효과, 로봇/라디오 목소리 원클릭 프리셋 |

## 활용 예시

| 활용 | 사용 기능 |
|---|---|
| 유튜브/릴스 나레이션 | 목소리 복제 + 스토리즈 |
| 얼굴 없는 채널 운영 | AI 음성 생성 |
| 블로그 글 초안 말로 작성 | 받아쓰기 |
| 팟캐스트 대화 콘텐츠 | 목소리 복제 + 스토리즈 |
| 외국어 콘텐츠 더빙 | 다국어 음성 생성 (23개 언어) |
