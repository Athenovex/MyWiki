# 나노바나나 PRO

> Google Gemini 계열의 이미지 생성 모델. 향상된 추론 능력을 바탕으로 단순 이미지가 아닌 정보 기반 시각 콘텐츠(인포그래픽·다이어그램 등)를 생성한다.

## 개요

구글 검색 데이터에 연결해 실시간 정보(예: 날씨)를 시각화하는 등, 단순 그림 생성을 넘어 "정보를 시각적으로 해결"하는 솔루션을 지향한다.

## 향상된 기능

- **향상된 추론**: 정보를 바탕으로 인포그래픽·다이어그램 등 시각 자료 생성
- **향상된 텍스트 출력**: 다양한 글꼴·캘리그라피 구현 (한국어 포함), 번역에도 유용
- **더 향상된 비주얼 기능**: 최대 14개 이미지 활용, 5명까지 인물 일관성 유지, 6개 고화질샷 통합, 이미지 특정 부분 편집(카메라 각도·초점·색상·색보정·조명·화면비율 변형)

## 프롬프트 구성 요소

| 항목 | 설명 |
|---|---|
| 주제 | 이미지 속 인물/사물이 무엇인가 |
| 구도 | 샷의 구성 (클로즈업, 로우 앵글 등) |
| 동작 | 무슨 일이 일어나는가 |
| 장소 | 장면이 어디서 벌어지는가 |
| 스타일 | 전체적인 미적 방향 (3D 애니메이션, 필름 누아르 등) |
| 편집 지침 | 직접적이고 구체적인 수정 요청 |

### 세부 지침

구성 및 화면비, 카메라 및 조명(촬영 감독처럼 연출), 특정 텍스트(표시될 텍스트와 모양 명시), 사실적 제약 사항(정확성 요구 명시), 참고 자료(각 이미지의 역할 정의: "캐릭터 포즈에 이미지 A를, 아트 스타일에 이미지 B를 사용").

## AI 이미지 워터마크

생성된 이미지에는 AI 디지털 워터마크가 포함된다.

## 스튜디오 컷 40개 프롬프트 키워드 체계

제품 촬영 스타일 이미지 생성을 위한 10개 카테고리 40개 핵심 요소: 제품 속성·디테일, 구도·프레이밍, 앵글·시점, 조명·톤, 모델 포즈·상호작용, 배경·장소, 소품·세트 디자인, 이미지 스타일·퀄리티, 편집·후처리, 마케팅·브랜드 요소.

## API 활용

나노바나나 Pro API의 핵심 특징: 검색 그라운딩, 추론, 텍스트 렌더링, 일관성 유지 — 단순 그림 그리기가 아니라 정보를 시각적으로 해결해주는 솔루션.
