# 나노바나나 PRO

> Google Gemini 계열의 이미지 생성 모델. 향상된 추론 능력을 바탕으로 단순 이미지가 아닌 정보 기반 시각 콘텐츠(인포그래픽·다이어그램 등)를 생성한다.

## 개요

구글 검색 데이터에 연결해 실시간 정보(예: 날씨)를 시각화하는 등, 단순 그림 생성을 넘어 "정보를 시각적으로 해결"하는 솔루션을 지향한다.

## 향상된 기능

일반 이미지 생성 모델 대비 나노바나나 PRO가 강의자료에서 강조하는 세 가지 향상점이다 ([[251128_나노바나나_PRO]] p.3-13).

- **향상된 추론** (p.3-4): 단순히 그림을 그리는 것이 아니라 요청의 배경 정보를 이해하고 인포그래픽·다이어그램 같은 "정보 시각화" 결과물을 만든다. 구글 검색 데이터에 연결되어 있어, 예를 들어 실시간 날씨 정보처럼 그 순간의 데이터를 반영한 이미지도 생성할 수 있다.
- **향상된 텍스트 출력** (p.5-8): 다양한 글꼴·캘리그라피 표현이 가능해 번역 자료 제작에도 유용하다. 특히 한국어 텍스트 렌더링 품질이 눈에 띄게 개선된 점이 강의에서 별도로 강조된다("한국어!!!", p.7).
- **더 향상된 비주얼 기능** (p.9-13): 최대 14개의 이미지를 참고 자료로 동시에 활용할 수 있고, 5명까지 인물의 얼굴·특징을 일관되게 유지하며, 6개의 고화질 샷을 하나로 통합할 수 있다. 이미지의 특정 부분만 골라 카메라 각도·초점·색상·색보정·조명·화면비율을 편집 지시로 바꿀 수 있다.

## 프롬프트 구성 요소

이미지 프롬프트를 작성할 때 포함해야 하는 6가지 요소와, 원본 슬라이드에 실제로 실린 예시 문구다 (p.14, 예시 열은 원문 그대로 인용).

| 항목 | 설명 | 예시 (원문, p.14) |
|---|---|---|
| 주제 | 이미지 속 인물/사물이 무엇인가 | "푸른 빛이 나는 광학 장치를 가진 냉철한 로봇 바리스타" |
| 구도 | 샷의 구성은 어떤가 | "극단적인 클로즈업, 로우 앵글 샷, 초상화 샷" |
| 동작 | 무슨 일이 일어나고 있는가 | "커피 한 잔을 내리고 있는 중, 마법 주문을 걸고 있는 중" |
| 장소 | 장면은 어디에서 벌어지는가 | "화성의 미래형 카페, 어수선한 연금술사의 서재" |
| 스타일 | 전체적인 미적 방향은 무엇인가 | "3D 애니메이션, 필름 누아르, 수채화, 사실적인 사진" |
| 편집 지침 | 직접적이고 구체적인 수정 요청 | "남성의 넥타이를 녹색으로 변경, 배경의 차량 제거" |

이 6요소를 한 문장으로 이으면 하나의 완성된 프롬프트가 된다. 예를 들어 "화성의 미래형 카페에서 커피를 내리는 중인, 푸른 빛이 나는 광학 장치를 가진 냉철한 로봇 바리스타를 극단적인 클로즈업, 3D 애니메이션 스타일로" 처럼 주제·장소·동작·구도·스타일을 한 번에 조합할 수 있다.

### 세부 지침

기본 6요소만으로 부족할 때 추가로 넣는 세부 지침 5가지와 원문 예시다 (p.15).

| 항목 | 설명 | 예시 (원문, p.15) |
|---|---|---|
| 구성 및 화면비 | 캔버스의 형태와 비율을 정의 | "9:16 세로 포스터", "21:9 시네마틱 와이드 샷" |
| 카메라 및 조명 | 촬영 감독처럼 샷을 연출 | "얕은 심도(f/1.8)의 로우 앵글 샷", "골든 아워 백라이트", "차분한 청록색 톤의 시네마틱 컬러 그레이딩" |
| 특정 텍스트 | 이미지에 표시될 텍스트와 그 모양을 명시 | "상단에 'URBAN EXPLORER' 제목을 굵은 흰색 산세리프 글꼴로 렌더링." |
| 사실적 제약 사항 | 정확성 또는 사실 준수의 필요성을 명시 | "과학적으로 정확한 단면도", "빅토리아 시대의 역사적 정확성을 보장하십시오" |
| 참고 자료 | 각 참고 이미지의 역할을 명확히 정의 | "캐릭터 포즈에 이미지 A를, 아트 스타일에 이미지 B를 사용하십시오." |

참고 자료 항목은 나노바나나 PRO가 여러 장의 참고 이미지를 동시에 입력받을 수 있다는 "더 향상된 비주얼 기능"과 직결된다 — 이미지마다 역할(포즈용/스타일용 등)을 프롬프트에서 명시해야 의도대로 합성된다.

## 실전 활용 사례

강의자료 p.21-44에 소개된 실제 편집·합성 사례 중 대표적인 프롬프트 유형이다. 아래 문구는 슬라이드에 실린 지시문을 그대로 옮긴 것으로, 나노바나나 PRO가 단순 생성을 넘어 "기존 이미지의 편집·합성·연속 작업"까지 지원한다는 점을 보여준다.

| 유형 | 프롬프트 예시 (원문) | 페이지 |
|---|---|---|
| 부분 편집 | "그의 팔과 손을 크롬 금속으로 바꿔" | p.22 |
| 다중 이미지 합성 | "25개의 모든 아이템을 하나의 통합된 이미지로 합쳐라" | p.23 |
| 스타일 결합 | "이미지들을 창의적으로 결합하여 스타일리시한 잡지 표지 화보를 만들어라" | p.24 |
| 정보 시각화 | "문제를 풀고 화이트보드에 전체 풀이를 작성해라" | p.25 |
| 텍스트 렌더링 | "16:9 비율의 바나나 클로즈업 사진, 바나나 껍질에 긴 비밀 메시지가 손글씨로 적혀 있다" | p.27 |
| 연속 편집(멀티턴) | "비밀 메시지를 기반으로 만화 스트립 스타일의 비주얼을 만들어라" (위 이미지를 이어받아 후속 요청) | p.28 |
| 인물 나이 변형(일관성 유지) | "젊게해줘, 늙게 해줘, xx살로 해줘" | p.29 |
| 분해도/기술 도면 | "전문적인 흰색 배경과 스튜디오 조명을 사용하여, 이것의 정확한 분해도를 만들어라" | p.32 |
| 카메라 앵글 변경 | "이 샷에서 새로운 카메라 앵글: 그룹 미디엄 클로즈업" | p.40 |
| 캐릭터·세계관 합성 | "현실적인 휴대폰 카메라, 영화 아바타의 제이크 설리와 라스트 에어벤더의 아앙이 함께 촬영장에 있는 모습" | p.42 |

p.34는 여러 요소(패널 구성·대사·전체 스타일 노트)를 하나의 긴 프롬프트에 모두 담은 예시를 보여준다. 짧은 한 줄 지시와 달리, 복잡한 결과물(4컷 만화)을 만들 때는 이 정도 밀도의 프롬프트가 필요하다는 것을 보여주는 참고 사례다.

```
강렬한 만화책 스타일의 생생한 멀티 패널 코믹 스트립.
패널들은 세상을 구하기 위해 살아난 영웅적인 바나나를 보여준다.
굵은 검은 콘투어 라인, 역동적인 포즈, 극적인 조명, 하프톤 음영,
그리고 화려한 액션 효과.

패널 1 – 기원의 순간
부엌 그릇에 놓인 평범한 바나나가 갑자기 황금빛 에너지를 내며 빛난다.
눈과 팔다리가 생겨나고, 바나나는 깜짝 놀라지만 결심한 듯 일어선다.
대사(바나나): "와… 내가 살아있다고? 그리고 밖에 뭔가 잘못된 게 있어!"

(패널 2~4 생략 — 위협 등장 → 영웅의 행동 → 승리와 유머 순으로 전개)

전체 스타일 노트
선명한 잉킹, 굵은 라인 아트, 역동적인 시점
밝고 채도가 높은 색감, 하프톤 질감, 폭발적인 액션 레터링
바나나 캐릭터에 감정 표현이 담긴 얼굴
각 패널에 자연스럽게 통합된 말풍선
유머러스하면서도 영웅적인 분위기
```

(위 프롬프트는 [[251128_나노바나나_PRO]] p.34 원문을 그대로 인용한 것이며, 지면상 패널 2~4의 세부 대사는 생략함)

## AI 이미지 워터마크

나노바나나 PRO로 생성한 모든 이미지에는 AI 생성물임을 나타내는 디지털 워터마크가 자동으로 포함된다 (p.17). 결과물이 실제 촬영본인지 AI 생성본인지 확인해야 할 때 이 워터마크로 판별할 수 있다.

## 스튜디오 컷 40개 프롬프트 키워드 체계

제품 촬영 스타일 이미지를 생성하기 위한 10개 카테고리 40개 핵심 요소 체계다 (p.47-48). 카테고리별 대표 요소와 실제 프롬프트 키워드 예시는 다음과 같다 (전체 40개 항목은 [[251128_나노바나나_PRO]] p.47-48 참고).

| 카테고리 | 대표 핵심 요소 | 프롬프트 키워드 예시 (원문) |
|---|---|---|
| I. 제품 속성 및 디테일 | 소재/질감 하이라이트 | "부드러운 벨벳 질감," "차가운 메탈릭 광택" |
| II. 구도 및 프레이밍 | 삼분할 법칙, 네거티브 스페이스 | "삼분할 구도를 활용한 안정적인 배치", "제품 주변에 넓은 여백을 활용한 미니멀한 구도" |
| III. 앵글 및 시점 | 하이 앵글/로우 앵글 | "하이 앵글로 내려찍어 슬림한 핏 강조", "로우 앵글로 제품을 웅장하게 강조" |
| IV. 조명 및 톤 | 역광, 스플릿 라이팅 | "모델 뒤에서 비추는 강한 역광, 후광 효과", "얼굴에 스플릿 라이팅을 적용하여 드라마틱한 명암 대비" |
| V. 모델 포즈 및 상호작용 | 자연스러운 워킹 포즈 | "자연스러운 워킹 샷, 옷자락이 살짝 휘날리는 모습" |
| VI. 배경 및 장소 | 인더스트리얼/야외 라이프스타일 | "질감이 살아있는 노출 콘크리트 배경", "파리 자갈길의 야외 스트리트 샷" |
| VII. 소품 및 세트 디자인 | 톤온톤/대비 소품 배치 | "아이보리 니트 옆에 베이지색 톤온톤 머그잔 소품" |
| VIII. 이미지 스타일 및 퀄리티 | 매거진 화보, 시네마틱 룩 | "고급 패션 매거진 화보 스타일", "깊은 색감의 시네마틱 톤" |
| IX. 편집 및 후처리 | 피부 보정, 색온도 조절 | "잡티 없이 깨끗하게 보정된 모델의 피부", "전체적으로 따뜻하고 포근한 웜톤 보정" |
| X. 마케팅 및 브랜드 요소 | 타겟 연령대 분위기 | "20대 여성 타겟의 트렌디하고 발랄한 분위기" |

강의자료는 "레퍼런스 사용이 최고"(p.49)라고 강조한다 — 키워드를 텍스트로 나열하는 것보다, 원하는 결과물과 비슷한 참고 이미지를 함께 입력하는 편이 더 정확하다는 의미다.

## API 활용

나노바나나 Pro API의 핵심 특징은 검색 그라운딩·추론·텍스트 렌더링·일관성 유지 4가지이며, 이를 "단순 그림 그리기가 아니라 정보를 시각적으로 해결해주는 솔루션"으로 정의한다 (p.55). p.56-64는 이 특징을 활용한 예시 화면 위주로 구성되어 있어 텍스트로 옮길 만한 추가 설명은 확인되지 않았다 — 구체적인 API 사용법·요금 등은 이 슬라이드만으로는 확정할 수 없으므로 별도 공식 문서 확인이 필요하다.
