# 매니페스트 (Manyfast)

> 에디터 기반의 AI 기획 에이전트(AI Planning Agent) 서비스. 아이디어 하나로 PRD(제품요구사항정의서)→기능명세서→유저플로우→와이어프레임까지 소프트웨어 기획 문서를 순서대로 만들어준다.

## 개요

코딩·디자인 속도가 아무리 빨라져도 초기 기획이 구조화되어 있지 않으면 이후 모든 단계가 흔들린다는 문제의식에서, 기획 단계 자체를 AI로 구조화하는 도구다. `manyfast.io`에서 제공된다.

## 사용 흐름

1. **주제 작성**: 채팅창에 만들고 싶은 서비스 주제를 입력. 목적·타깃·핵심 기능을 구체적으로 쓸수록 완성도 높은 초안이 나온다
2. **PRD·기능명세서 제작**: AI와 질문을 주고받으며 PRD와 기능명세서를 작성. AI가 논리적 오류나 누락 사항을 검토해 개선점을 제안한다
3. **유저 플로우 제작**: 사용자가 서비스를 이용하며 거치는 단계·분기를 시각화한 플로우차트를 생성 — 서비스 전체 구조를 한눈에 파악 가능
4. **와이어프레임 제작**: 색상·타이포그래피보다 레이아웃·정보 계층·상호작용에 집중한 화면 설계도를 생성 — 디자인·개발 이전 단계의 토대
5. **내보내기**: PRD·기능명세서·유저플로우는 `.md` 형식으로, 와이어프레임은 피그마로 내보내 `Save Local Copy`로 피그마 파일 다운로드

## Claude Code와의 MCP 연동

매니페스트는 [[MCP]]를 지원해 [[Claude Code]]·Cursor 같은 코딩 도구에 연결하면, AI가 매니페스트의 기획 문서를 직접 읽고 그 내용대로 바로 구현한다. 문서를 가공해 붙여넣을 필요 없이 기획 맥락이 그대로 개발 단계로 이어지며, 개발 중 변경된 내용을 문서에 다시 반영하는 **양방향 동기화**도 가능하다. 연결은 보통 Claude Code 터미널에서 `claude mcp add` 명령으로 매니페스트 서버 URL을 등록하고 브라우저에서 OAuth 인증을 완료하는 방식이다.

MCP 연결 후 Claude Code 활용 예시:

```
매니패스트에서 프로젝트 리스트 보여줘.
```

```
매니패스트에서 [프로젝트 이름] 기획 전체 읽고,
기능 목록을 우선순위별로 정리해서 레포에 PROGRESS.md 만들어줘.
Phase별로 나누고, 각 기능마다 체크박스로 진행 상황 추적할 수 있게 해줘.
```

Claude Code가 기획 문서를 읽고 Phase별 체크리스트를 자동 생성하며, 기능이 완성될 때마다 체크박스가 업데이트되어 전체 진행 상황을 한눈에 볼 수 있다.
