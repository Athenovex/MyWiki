# 업무별 AI 툴 지형도

> 하나의 AI 도구로 모든 업무를 통일하기보다, 업무 성격에 맞춰 도구를 갈아 끼우는 것이 유리하다는 관점에서 정리한 2026년 시점의 업무별 AI 도구 지도.

## 개요

한 도구가 모든 작업을 가장 잘 처리하지는 않는다는 전제 아래, 글쓰기·회의기록·PPT·이미지·기획·디자인·영상·코딩·자동화 9개 업무 영역별로 실무에서 실제 쓰이는 도구를 매칭한 표다. 각 도구의 상세 사용법보다는 "이 업무엔 이 도구"라는 매핑 자체가 핵심 정보다.

## 업무별 대표 도구

| 분야 | 도구 | 한줄 요약 | 사용 목적 |
|---|---|---|---|
| 글쓰기/수정 | [[Claude]] | 자연스러운 문체·장문 일관성이 강점 | 보고서, 글 다듬기, 긴 문서 작업 |
| 회의 기록 | Alt | 무료·무제한 온디바이스 AI 노트 | 강의·회의 녹음, 자동 회의록 |
| PPT | SnapDeck | 대화하듯 만들고 피그마처럼 편집 | 제안서·발표 슬라이드 빠르게 제작 |
| 이미지 생성 | GPT Image 2 | 대화하듯 그림 수정, 글자도 정확하게 렌더링 | 썸네일, 포스터, 이미지 편집 |
| 서비스 기획 | 매니패스트 | 아이디어 한 줄로 기획안 완성 | 서비스 기획, 사용자 동선, 화면 설계 |
| UX/UI 디자인 | Pencil.dev | 화면 디자인 → 바로 코드 변환 | 앱·웹 UI 디자인 + 개발 |
| 영상 제작 | Remotion | 코드로 영상 자동·대량 생성 | 데이터 기반·개인화 영상 제작 ([[Claude 에이전트 스킬]] 참고) |
| 코딩 | [[Codex]] | 코드 작성·수정·업무 자동화 | 기능 개발, 버그 수정, 업무 자동화 |
| 자동화 | Hermes | 쓸수록 똑똑해지는 실행형 AI 비서 | 반복 업무 자동 실행 |
