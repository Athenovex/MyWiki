# 웹 접근성 QA 커리어

> 장애가 있는 사용자도 웹을 쓸 수 있게 만드는 "웹 접근성"과 "제대로 작동하는지 검증하는" QA가 만나는 자리. 국내는 법·자격 제도의 벽 때문에 개인 프리랜서로 바로 독립하기 어렵지만, 해외 원격 수주(Upwork 등)와 기업 대상 교육·컨설팅으로는 개인 진입이 가능한 틈새 직무다.

## 개요

웹 접근성 QA는 [[WCAG]] 같은 국제 표준을 기준으로 "마우스 없이 키보드만으로 쓸 수 있는가", "스크린리더가 버튼 이름을 제대로 읽어주는가" 같은 항목을 실제로 검증하는 일이다. 일반 QA(Manual/자동화)가 AI 자동화 압력을 크게 받는 것과 달리, 접근성 QA는 "이 안내 문구가 시각장애인에게 이해되는가"처럼 기계가 판단할 수 없는 사용성 검증이 핵심이라 상대적으로 안전한 틈새로 꼽힌다.

## 왜 지금 수요가 느는가

한국·미국·유럽이 동시에 관련 법을 강화하고 있다.

| 지역 | 상황 |
|---|---|
| 한국 | 2026-01-28부터 장애인차별금지법상 정당한 편의 제공 의무 전면 시행(키오스크 포함), 웹 접근성 기준 KWCAG 2.2 |
| 미국 | 2025년 웹 접근성 소송 5,000건 초과(연방법원만 3,117건, 전년대비 +27%), 46%가 재차 피소 |
| 유럽 | 유럽접근성법(EAA)이 2025-06-28 27개국 동시 시행, 독일은 위반당 최대 10만 유로 과징금 |

## 7가지 직무와 진입 난이도

| 직무 | 하는 일 | 필요 역량 |
|---|---|---|
| 접근성 컨설턴트 | 여러 회사를 진단하고 보고서로 정리 | 법규 지식, 보고서 작성, 설득력 |
| 접근성 엔지니어 | 개발팀 안에서 직접 코드를 고침 | HTML/CSS/JS, ARIA |
| 접근성 심사원 | 인증기관 소속으로 공식 심사 | KWCAG 정통, 기관 소속 필수 |
| 접근성 QA 테스터 | 일반 QA에 접근성 검사를 섞음 (진입 난이도 최저) | 스크린리더, 테스트 설계 |
| 당사자 테스터 | 실제 장애 당사자가 보조기기로 직접 사용해보고 피드백 | 보조기술 실사용 경험 |
| 인클루시브 디자이너 | 디자인 단계에서 색 대비·포커스 표시 등을 미리 반영 | UI/UX 디자인 |
| 접근성 프로그램 매니저 | 조직 전체 접근성 정책·교육·로드맵 총괄 (연봉 최고) | 기획, 조직 관리 |

비전공·문과 출신은 ①접근성 QA 테스터 → ②접근성 컨설턴트 → ③프로그램 매니저 순으로 진입하기 쉽다. 이 트랙은 코딩보다 법규 이해·문서화·커뮤니케이션이 핵심이기 때문이다. 반대로 접근성 엔지니어는 프론트엔드 개발 역량이 실질 요건이라 진입 난이도가 높다.

자동 검사 도구(axe DevTools, WAVE, Lighthouse)는 전체 접근성 오류의 20~40%만 잡아낸다(Deque 2020년 연구 약 32%). 나머지는 키보드 Tab 이동, NVDA/VoiceOver를 이용한 스크린리더 실사용 검증처럼 사람이 직접 확인해야 하는 영역이다.

## 국내: 제도적 벽과 그 틈

**개인은 인증을 발급할 수 없다** — 한국의 공식 웹 접근성 품질인증은 디지털포용법 제21조에 근거해 과기정통부가 지정한 기관(웹와치, 한국디지털접근성진흥원 등)만 발급한다. 심사는 서면→전문가→사용자 3단계, 통과 기준은 전문가 심사 준수율 95%↑ + 사용자 심사 과업 성공률 100%, 유효기간 1년(매년 갱신 수요 발생).

개인이 파고들 수 있는 틈:
- **사전 진단** — 정식 인증 심사 전 모의고사 역할
- **리메디에이션 자문** — 발견된 문제를 실제로 어떻게 고칠지 자문
- **웹에이전시 하도급** — 공공기관 사이트 제작사가 접근성 부분만 외주
- **교육/강의** — 기업 개발팀·디자이너 대상, 마진 최고
- **문서 접근성** — PDF·한글 문서를 스크린리더가 읽을 수 있게 변환, 공공기관 수요 꾸준

국내 QA 직무 연봉은 공고 기준 대략 3,200만~5,200만원 구간이며, "접근성 전담" 공고는 아직 소수라 "QA로 취업 후 접근성을 특기로 키우는" 경로가 현실적이다.

## 해외: 진짜 시장

한국에 거주하면서 Upwork 등으로 해외 클라이언트 일을 받을 수 있고 단가가 국내와 비교되지 않는다.

| 일감 유형 | 단가 |
|---|---|
| 표준 사이트 진단(10~20페이지) | $2,000~$8,000 |
| 페이지 단위 진단 | 페이지당 $150~$400 |
| 집중 진단·수정 | $500~$1,500 |
| 개발까지 하는 경우 | 시급 $100~$250 |
| 기업용 풀 감사(전문 회사 기준) | $10,000~$30,000+ |

시급 $30 미만은 업계에서 "자동 도구만 돌리고 결과 복붙"하는 신호로 간주되므로 피해야 한다. 크라우드 테스팅 플랫폼(uTest 사이클당 $10~$50, Testlio 시급 $15~$30)은 포트폴리오용일 뿐 주 수입원이 되기 어렵다. Fable(시급 £34)은 실제 장애 당사자만 참여 가능해 일반 지원자는 참여 불가.

연봉 벤치마크(WebAIM 글로벌 접근성 연봉조사 2회차, 2026-01 발표, 응답 300명): 미국 정규직 평균 $121,083(중위 $119,500), 전 세계 평균 $101,688. 원격 55.0%+하이브리드 35.9%=90.9%가 원격/하이브리드로 근무하며, 사무실 전일 출근자 평균 연봉이 오히려 전일 원격 근무자보다 31% 낮다 — 한국 거주 원격 근무에 구조적으로 유리한 직종.

1인 사업 상품 형태: ①정액 진단 리포트 패키지 ②정기 모니터링 구독(자동 스캔+리포트, 반복매출) ③VPAT 작성 대행(해외 대상, 고단가) ④교육 콘텐츠/워크숍.

## 필요 역량과 자격증

**필수**: WCAG 2.1/2.2, KWCAG 2.2(4원칙·14지침·33개 검사항목), 시맨틱 HTML, ARIA, 스크린리더 실사용(NVDA/VoiceOver), 키보드 접근성, 관련 법규(장애인차별금지법 제21조·디지털포용법, 미국 ADA·Section 508, 유럽 EN 301 549), QA 기본기(테스트 시나리오, Jira, 회귀 테스트).

**자격증 전략**: IAAP CPACC(비회원 $485, 코딩 없이 장애 이해·법규·정책 중심, 한국에서 Pearson VUE 온라인 원격 응시 가능)를 가장 먼저 딴다. WAS(기술 자격, 코드 수준)는 실무 3년 정도 쌓은 뒤 도전. CPACC+WAS를 모두 합격하면 CPWA가 자동 부여된다.

## AI가 이 직업을 없애는가

QA 업계 전반은 생성형 AI 도입이 빠르지만(World Quality Report 2025: 조직 89%가 도입/시험 중, 완전 도입은 15%뿐), 접근성 QA는 세 가지 이유로 상대적으로 안전하다.

1. 자동 검사가 일부(20~40%)만 잡아낸다 — 나머지는 사람이 확인해야 한다.
2. "이 이름이 시각장애인에게 말이 되는가" 같은 사용성 판단은 기계가 못 한다.
3. 소송 방어와 인증 심사에서 자동 도구 결과만으로는 법적으로 부족하다.

WebAIM Million 2026: 세계 상위 100만 개 홈페이지 중 95.9%가 자동 검출 가능한 접근성 오류를 갖고 있고 페이지당 평균 56.1개 — 시장이 포화될 걱정보다 처리할 일감이 산더미인 상황.

## 12개월 진입 로드맵 (일반화 버전)

1. **0~2개월**: W3C WAI 튜토리얼로 WCAG 2.2, NVDA 설치해 매일 30분 눈 감고 웹 사용, KWCAG 2.2 33개 검사항목 정독
2. **2~4개월**: Deque University 수강, axe DevTools/WAVE로 실제 사이트 스캔, 샘플 진단 보고서 2건 작성
3. **4~6개월**: CPACC 준비 후 응시, 지인·소상공인 사이트 3곳 무료 진단 → 공개 사례화
4. **6~9개월**: Playwright + axe-core 자동 검사 파이프라인 구축, VPAT 작성 연습
5. **9~12개월**: Upwork 소형 건 수주, 정액 진단 패키지 또는 교육 상품 출시

판단 기준: 6개월 유료 수주 0건 → 국내 취업 우선 검토. 월 300만원 3개월 연속 유지 → 1인 사업 전업 검토. WAS 취득 + VPAT 실적 3건 이상 → 해외 시급 $100 이상 협상 구간.

## 리스크 4가지

- **법적 책임**: 계약서에 "완전 준수를 보증한다"는 표현 금지, "점검 시점 기준 발견 사항"으로 한정
- **오버레이 위젯 추천 금지**: 사이트에 붙이면 자동 개선된다는 플러그인, 실효성 논란 크고 소송당한 기업 다수 — 코드 직접 수정만이 실질적 방어
- **단가 하락 압력**: 자동 스캔만 돌리는 저가 경쟁자가 많아 수동 검증·사용자 관점으로 차별화 필요
- **세금·계약**: 해외 수주 시 W-8BEN 제출, 국내 종합소득세 신고 필요
