# 이미지·영상 생성 프롬프트

> 텍스트만으로 상업용 품질의 이미지·영상을 생성하기 위한, 일반 LLM 프롬프트보다 구체적인 시각 요소(구도·조명·카메라·무드) 중심의 프롬프트 설계 방식.

## 개요

일반 텍스트 프롬프트와 달리 촬영 감독처럼 장소·조명·구도·스타일을 구체적인 "촬영 용어"로 지시해야 일관된 결과를 얻는다.

## 좋은 프롬프트의 4요소

1. **대상/주체**: 누구·무엇을 담을지
2. **목적/맥락**: 어디에·왜 쓸지
3. **스타일/디테일**: 톤·색·구도·질감
4. **출력 형식**: 비율·길이·품질

공식: `[주체] + [행동/상황] + [스타일·디테일] + [출력형식]`

## 이미지 프롬프트 6줄 구조

```
[피사체] {제품명}, 중앙 배치
[배경] {대리석/우드/야외}, 미니멀
[조명] {아침 자연광/골든아워}
[구도] {45도 부감/아이레벨}, 여백
[스타일] {감성 광고컷}, {파스텔} 톤
[출력] {1:1}, 고해상도, 텍스트 없음
```

원치 않는 요소는 "없음"(네거티브)으로 명시한다. 잘 나온 프롬프트는 저장해 재사용한다.

## 나쁜 프롬프트 vs 좋은 프롬프트

| 나쁜 예 | 좋은 예 |
|---|---|
| "텀블러 사진 예쁘게 만들어줘" | "파스텔 텀블러, 우드 카페 테이블, 아침 햇살, 45도 구도, 미니멀·따뜻한 톤" |

## 영상 프롬프트 구조 (샷·카메라·무드)

```
[장면] {무엇이 일어나는가}
[피사체] {제품/인물}, {동작}
[카메라] 천천히 줌인 / 좌→우 팬
[무드] 따뜻한, 미니멀, 시네마틱
[조명] 자연광, 골든아워
[출력] 9:16 세로, 15초, 부드러운 모션
```

카메라 '움직임'을 지정하면 생동감이 살고, 무드 형용사는 2~3개로 톤을 고정한다. 한 컷에 동작 하나만 담는다.

## 이미지 속 텍스트 렌더링

짧게 지정(3~5단어), 위치 지정("상단 중앙"), 폰트 무드 지시("굵은 산세리프"), 배경-글자 대비 확보, 생성 후 오타 점검 필수.

## 일관성(Consistency) 유지 디렉팅

같은 스타일 키워드 세트를 모든 컷에 반복 적용하는 것이 핵심. 스타일 시트(무드·색·카메라 규칙 문서화), 고정 키워드, 동일 조명, 주체 고정, 출력 스펙 통일.

## 촬영·조명 용어 (프롬프트에 바로 쓰는 어휘)

부감/앙각, 클로즈업, 골든아워, 줌인/팬, 보케, 시네마틱.

## AI 비주얼 주의사항

실제 제품과 다르지 않게(과장광고 주의), 타인의 얼굴·상표 주의, 생성 이미지 사용 정책 확인, 사람 손·글자 왜곡 점검(AI가 자주 틀리는 부분), "AI스러움" 다듬기(너무 완벽하면 신뢰도 하락).
