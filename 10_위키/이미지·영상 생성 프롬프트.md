# 이미지·영상 생성 프롬프트

> 텍스트만으로 상업용 품질의 이미지·영상을 생성하기 위한, 일반 LLM 프롬프트보다 구체적인 시각 요소(구도·조명·카메라·무드) 중심의 프롬프트 설계 방식.

## 개요

일반 텍스트 프롬프트와 달리 촬영 감독처럼 장소·조명·구도·스타일을 구체적인 "촬영 용어"로 지시해야 일관된 결과를 얻는다.

## 좋은 프롬프트의 4요소

[[AI미디어콘텐츠_크리에이터과정_교안]] p.25는 이 4가지를 갖추면 결과물 적중률이 크게 올라간다고 설명한다.

1. **대상/주체**: 누구·무엇을 담을지
2. **목적/맥락**: 어디에·왜 쓸지 — 상세페이지용인지 SNS 피드용인지에 따라 요구되는 톤이 달라진다
3. **스타일/디테일**: 톤·색·구도·질감 — 형용사보다 "촬영 용어"로 표현할수록 정확도가 올라간다
4. **출력 형식**: 비율·길이·품질 — 플랫폼 규격(9:16, 1:1 등)을 미리 지정해야 재작업이 줄어든다

공식: `[주체] + [행동/상황] + [스타일·디테일] + [출력형식]` 순서로 적으면 재현 가능한 품질이 나온다.

### 프롬프트 작성 체크포인트

p.27이 제시하는 6가지 습관이다: 목적 먼저(어디에 쓸 콘텐츠인지 먼저 정의), 시각 언어(구도·조명·색·질감을 단어로 묘사), 레퍼런스(원하는 느낌의 예시를 함께 제시), 출력 스펙(비율·길이·해상도 명시), 반복 수정(한 번에 끝내지 말고 조금씩 조정), 기록(잘된 프롬프트는 템플릿으로 저장).

## 이미지 프롬프트 6줄 구조

```
[피사체] {제품명}, 중앙 배치
[배경] {대리석/우드/야외}, 미니멀
[조명] {아침 자연광/골든아워}
[구도] {45도 부감/아이레벨}, 여백
[스타일] {감성 광고컷}, {파스텔} 톤
[출력] {1:1}, 고해상도, 텍스트 없음
```

원치 않는 요소는 "없음"(네거티브)으로 명시한다. 잘 나온 프롬프트는 저장해 재사용한다.

## 나쁜 프롬프트 vs 좋은 프롬프트

같은 요청이라도 시각 요소(장소·조명·구도)를 구체적으로 지시했는지에 따라 결과가 크게 갈린다. [[AI마케팅_이커머스_전문가과정]] p.55는 "텀블러 사진 예쁘게 만들어줘"가 아쉬운 이유를 "장소가 없다 / 조명·분위기가 없다 / 구도 지시가 없다 → 결과가 매번 제각각"으로 짚고, [[AI미디어콘텐츠_크리에이터과정_교안]] p.26은 같은 문제를 다른 소재(영상·음악 포함)로 5개 예시로 보여준다.

| 나쁜 예 | 좋은 예 | 출처 |
|---|---|---|
| "제품 사진 만들어줘" | "흰 대리석 위 화장품, 아침 자연광, 45도 부감" | 미디어콘텐츠 p.26 |
| "예쁘게 해줘" | "미니멀 감성, 파스텔 톤, 여백 충분히" | 미디어콘텐츠 p.26 |
| "영상 하나 뽑아줘" | "15초 세로 영상, 부드러운 카메라 이동" | 미디어콘텐츠 p.26 |
| "음악 넣어줘" | "잔잔한 로파이 BGM, 60~80 BPM" | 미디어콘텐츠 p.26 |
| "느낌 있게 해줘" | "정사각 1:1, 고해상도, 텍스트 없음" | 미디어콘텐츠 p.26 |
| "텀블러 사진 예쁘게 만들어줘" | "파스텔 텀블러, 우드 카페 테이블, 아침 햇살, 45도 구도, 미니멀·따뜻한 톤" | AI마케팅 p.55, p.118 |

AI마케팅 p.118은 이 텀블러 예시를 "1차(아쉬움) → 2차(개선)"의 프롬프트 진화 과정으로 제시한다: 1차는 배경·분위기 지정이 없어 결과가 매번 달라졌고, 2차에서 장소·조명·구도·톤을 명시하자 일관된 고퀄리티 결과를 얻었다고 설명한다.

## 영상 프롬프트 구조 (샷·카메라·무드)

```
[장면] {무엇이 일어나는가}
[피사체] {제품/인물}, {동작}
[카메라] 천천히 줌인 / 좌→우 팬
[무드] 따뜻한, 미니멀, 시네마틱
[조명] 자연광, 골든아워
[출력] 9:16 세로, 15초, 부드러운 모션
```

카메라 '움직임'을 지정하면 생동감이 살고, 무드 형용사는 2~3개로 톤을 고정한다. 한 컷에 동작 하나만 담는다.

## 이미지 속 텍스트 렌더링

AI 이미지 생성 모델은 사람 손이나 글자를 정확히 그리지 못하는 경우가 잦아, 이미지 안에 글자를 넣을 때는 별도 요령이 필요하다 ([[AI미디어콘텐츠_크리에이터과정_교안]] p.41). 짧게 지정(긴 문장보다 3~5단어가 정확도가 높다), 위치 지정("상단 중앙", "좌하단" 등 배치 명시), 폰트 무드 지시("굵은 산세리프", "손글씨풍" 등 분위기로 지시), 배경-글자 대비 확보(가독성을 위해 배경과 글자색 대비를 요청), 여백 설계(텍스트 자리를 비워 배치 공간 확보), 생성 후 오타 점검(철자 확인·필요 시 재생성)이 핵심이다.

실제 텍스트 렌더링 지시 예시는 [[나노바나나 PRO]] p.15에 실려 있다:

```
상단에 'URBAN EXPLORER' 제목을 굵은 흰색 산세리프 글꼴로 렌더링.
```

이 한 줄에 위치("상단")·문구("URBAN EXPLORER")·폰트 무드("굵은")·색상("흰색")·글꼴 종류("산세리프")가 모두 담겨 있어, 위 체크리스트를 그대로 적용한 예로 볼 수 있다.

## 일관성(Consistency) 유지 디렉팅

여러 컷을 이어 붙여 하나의 결과물(영상 클립 세트, 상세페이지 연출컷 시리즈 등)을 만들 때는 "일관성 = 스타일 키워드의 반복"이 핵심이다 ([[AI미디어콘텐츠_크리에이터과정_교안]] p.52). 구체적으로는 스타일 시트(무드·색·카메라 규칙을 한 곳에 문서화해 재사용), 고정 키워드(모든 컷 프롬프트에 같은 스타일 키워드를 삽입), 동일 조명(조명·시간대를 컷마다 통일), 주체 고정(제품·인물 묘사를 동일하게 반복), 비율·화질 통일(출력 스펙을 전 컷 동일하게), 교차 점검(이어 붙였을 때 튀는 컷은 재생성)의 6가지 방법을 쓴다.

> 아래 스타일 시트 예시는 이해를 돕기 위해 위키 편집 과정에서 작성한 것으로, 원본 자료에 실린 문구가 아니라 위 6가지 방법을 적용한 편집자 작성 예시다.

```
[스타일 시트 — 텀블러 브랜드 숏폼 예시]
무드 키워드: 미니멀, 따뜻한, 파스텔
색감: 우드톤 + 파스텔, 웜톤 보정
카메라: 항상 45도 부감, 느린 줌인만 사용
조명: 아침 자연광 / 골든아워로 고정
주체: 파스텔 텀블러, 동일 각도로 등장
출력 스펙: 9:16, 15초, 고해상도
```

## 촬영·조명 용어 (프롬프트에 바로 쓰는 어휘)

프롬프트에 이 단어들을 쓰면 "느낌"이 아니라 "결과"로 통제할 수 있다는 것이 강조된다 ([[AI미디어콘텐츠_크리에이터과정_교안]] p.42).

| 용어 | 뜻 |
|---|---|
| 부감 / 앙각 | 위에서 내려다봄 / 아래서 올려다봄 |
| 클로즈업 | 피사체를 꽉 채운 근접 구도 |
| 골든아워 | 해 뜰·질 무렵의 따뜻한 빛 |
| 줌인 / 팬 | 확대 / 좌우로 훑는 카메라 이동 |
| 보케 | 배경이 부드럽게 흐려지는 효과 |
| 시네마틱 | 영화 같은 색감과 넓은 화면비 |

## AI 비주얼 주의사항

[[AI미디어콘텐츠_크리에이터과정_교안]] p.82(저작권·윤리)와 [[AI마케팅_이커머스_전문가과정]] p.65(AI 비주얼 주의사항)가 공통으로 강조하는 5가지다.

- **실제 제품과 다르지 않게**: AI가 실제로 없는 기능·모양을 그리면 과장광고가 될 수 있다. 실물을 기준으로 검수한다.
- **타인의 얼굴·상표 주의**: 특정 인물의 얼굴이나 타 브랜드 로고가 섞여 나오지 않았는지 확인한다. 실존 인물을 무단으로 합성·도용하는 것은 초상권 침해다.
- **생성 이미지 사용 정책 확인**: 도구마다 상업적 사용 조건이 다르므로 미리 확인한다.
- **사람 손·글자 왜곡 점검**: AI가 가장 자주 틀리는 부분이므로, 어색하면 재생성하거나 보정한다.
- **"AI스러움" 다듬기**: 너무 완벽하거나 비현실적으로 보이면 오히려 신뢰도가 떨어지므로 자연스럽게 다듬는다.
- **플랫폼 표기 정책 준수**: 사용하는 플랫폼의 AI 생성 콘텐츠 표기 규정을 따른다.
