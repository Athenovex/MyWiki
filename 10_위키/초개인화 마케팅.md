# 초개인화 마케팅 (AI 커머스)

> 매스마케팅(한 메시지를 모두에게)과 달리, 고객 한 명 한 명에게 다른 메시지를 보내는 AI 기반 마케팅 방식. AI가 데이터로 누구에게 무엇을 보낼지 결정한다.

> 아래 데이터 분석 프롬프트, 구매 퍼널 수치, 데이터 분석 함정의 "아이스크림-익사 사고" 예시는 [[AI마케팅_이커머스_전문가과정]] 원본 슬라이드(p.9-33)에 실제로 등장하는 프롬프트·수치를 그대로 인용했다. 다만 그 프롬프트를 실행했을 때 나오는 AI의 실제 응답 내용, 세그먼트별 맞춤 메시지 문구는 원본에 없어 형식·계산 방식을 보여주기 위해 편집자가 작성한 가상의 예시다 — 해당 부분은 표시해 두었다.

## 매스마케팅 vs 초개인화

매스마케팅은 "가장 평균적인 고객"을 상정하고 하나의 메시지를 대량으로 뿌리는 방식이라 제작·집행이 빠른 대신, 관심 없는 사람에게도 노출되어 낭비가 크고 누가 실제로 반응했는지 파악하기 어렵다. 초개인화 마케팅은 반대로 각 고객의 구매이력·관심사 데이터를 기반으로 메시지 자체를 고객마다 다르게 만들며, AI가 그 판단(누구에게 무엇을 보낼지)을 데이터로 내린다. (원본 슬라이드 p.9 대조표 그대로)

| 매스마케팅 | 초개인화 마케팅 |
|---|---|
| 평균적인 고객을 겨냥 | 구매이력·관심사 기반 맞춤 제안 |
| 관심 없는 사람에게도 노출 | 관심 있는 사람에게만 노출 |
| 누가 반응했는지 파악 어려움 | AI가 데이터로 결정 |

## AI 커머스가 바꾸는 것

AI가 커머스 운영에 들어오면서 바뀌는 지점은 크게 세 갈래다: 24시간 쉬지 않는 응대·추천, 세그먼트가 아니라 고객 1인 단위의 맞춤 제안, 실시간 데이터 기반 의사결정. 구체적으로는 상품 추천, 고객 응대, 콘텐츠 생성(상세페이지·광고문구·이미지 대량 생성), 수요 예측 4개 영역에서 활용된다. (원본 슬라이드 p.10 4항목 그대로)

## 데이터 분석 워크플로우

데이터 확인(누가·언제·무엇을 샀는지) → 패턴 발견(잘 팔리는 상품·시간대·고객층) → 타깃 결정 → 제작·집행의 4단계 순서를 따른다. "감이 아니라 데이터로 방향을 잡는다"가 핵심 원칙이며, 이 순서를 거꾸로 하면(먼저 캠페인을 만들고 나중에 데이터로 정당화하면) 확증편향에 빠지기 쉽다. (원본 슬라이드 p.14)

### 데이터 분석 프롬프트 공식

`역할 + 데이터 + 요청 + 형식` 네 요소를 갖추면 AI가 막연한 감상 대신 실행 가능한 분석을 내놓는다.

원본 실습 슬라이드(p.18)에 실제로 실린 프롬프트(그대로 인용):

```
너는 이커머스 데이터 분석가야.
아래는 우리 3개월 매출 데이터야. (표)
1) 매출 top5 상품
2) 요일·시간대 패턴
3) 재구매 많은 상품
을 표로 정리하고,
마지막에 실행 제안 3가지를 알려줘.
```

원본은 이 프롬프트를 실행했을 때 AI가 실제로 무엇을 답했는지는 싣지 않는다. 아래는 결과 형식을 보여주기 위한 편집자의 가상 시연이며 실제 분석 결과가 아니다:

```
| 순위 | 상품 | 매출액 | 추정 요인 |
|---|---|---|---|
| 1 | 텀블러 세이지그린 | (가상) | 인스타 릴스 노출 이후 급증 |
| 2 | 텀블러 화이트 | (가상) | 스테디셀러, 재구매 비중 높음 |
...
실행 제안: ① 세이지그린 재고 확보 ② 화이트 재구매 쿠폰 발송 ③ 하위권 상품 세트할인
```

## 타깃 세그먼트

충성고객, 잠재이탈고객, 신규고객, 가격민감고객으로 나누어 각기 다른 메시지를 전달한다. (세그먼트 4종 구분은 원본 슬라이드 p.19 그대로) 같은 할인 문구라도 세그먼트에 따라 받아들이는 맥락이 다르므로, 세그먼트별로 메시지의 톤과 소구점을 바꿔야 효과가 커진다. 아래 메시지 예시는 원본에 없어 편집자가 작성했다:

```
충성고객    : "항상 함께해주셔서 감사해요. VIP 전용 신제품 먼저 보여드릴게요."
잠재이탈고객 : "오랜만이에요! 놓치신 사이 달라진 점, 지금 확인해보세요."
신규고객    : "처음이시라면 이 조합부터. 첫 구매 혜택 안내드려요."
가격민감고객 : "지금이 가장 쌉니다. 이번 주 특가만 보고 가세요."
```

## 핵심 KPI

원본 슬라이드(p.21)에 실린 6개 지표 정의 그대로:

| 지표 | 의미 |
|---|---|
| 전환율 | 방문자 중 실제 구매한 비율 |
| 객단가 | 1인당 평균 구매 금액 |
| 재구매율 | 다시 구매한 고객의 비율 |
| 장바구니 이탈률 | 담아놓고 안 산 비율 |
| ROAS | 광고비 1원당 매출 |
| LTV | 한 고객이 평생 안겨줄 총 매출 |

각 지표는 단독으로 보면 오해하기 쉽다. 전환율만 오르고 객단가가 떨어지면 전체 매출은 그대로일 수 있고, ROAS가 높아도 LTV가 낮은 고객만 모으고 있다면 장기적으로는 손해다.

### 구매 퍼널 실제 예시

원본 슬라이드(p.29)에 실제로 실린 퍼널 수치(그대로 인용) — 전환율(=구매완료÷방문)을 계산하는 실제 근거로 쓸 수 있다:

```
방문           10,000명
상품 조회       4,200명
장바구니         1,500명
결제 시작          780명
구매 완료          520명

→ 전환율 = 520 / 10,000 = 5.2%
→ 가장 크게 새는 구간(예: 장바구니 → 결제 시작)을 먼저 개선하면 전체 매출이 오른다
```

## 데이터 분석 함정

표본이 너무 작아 우연을 패턴으로 착각하는 경우, 상관관계를 인과관계로 오해하는 경우, 보고 싶은 결과만 확인하는 확증편향, 평균만 보고 분포를 보지 않는 함정(평균 객단가가 높아도 소수의 고액 구매자가 평균을 끌어올렸을 수 있음)이 대표적이다. (원본 슬라이드 p.23, 4가지 함정 그대로)

상관관계≠인과관계 함정에 대해 원본이 실제로 드는 예시: "아이스크림과 익사 사고가 같이 늘어도 서로 원인은 아니다(둘 다 여름 탓)."

데이터를 볼 때는 표본 크기와 분포를 함께 확인하는 습관이 필요하다.

## 판매 채널 선택

스마트스토어(검색 유입에 강함, 초기 진입 쉬움), 쿠팡(빠른 배송·리뷰 신뢰로 구매 전환이 쉬움), 자사몰(브랜드가 고객 데이터를 직접 소유, 팬을 만들기 좋음), SNS 마켓(인스타·스레드에서 발견→구매, 감성·스토리가 무기)으로 채널마다 유입 경로와 고객 성향이 다르다. (원본 슬라이드 p.12 정의 그대로) 여러 채널을 동시에 얕게 운영하기보다, 한 채널에서 확실히 1등을 노리는 편이 데이터도 쌓이고 운영 리소스도 아낄 수 있어 유리하다.
