# 초개인화 마케팅 (AI 커머스)

> 매스마케팅(한 메시지를 모두에게)과 달리, 고객 한 명 한 명에게 다른 메시지를 보내는 AI 기반 마케팅 방식. AI가 데이터로 누구에게 무엇을 보낼지 결정한다.

## 매스마케팅 vs 초개인화

| 매스마케팅 | 초개인화 마케팅 |
|---|---|
| 평균적인 고객을 겨냥 | 구매이력·관심사 기반 맞춤 제안 |
| 관심 없는 사람에게도 노출 | 관심 있는 사람에게만 노출 |
| 누가 반응했는지 파악 어려움 | AI가 데이터로 결정 |

## AI 커머스가 바꾸는 것

24시간 응대·추천(챗봇), 1:1 고객별 맞춤 제안, 실시간 데이터 기반 의사결정. 상품 추천, 고객 응대, 콘텐츠 생성(상세페이지·광고문구 대량 생성), 수요 예측.

## 데이터 분석 워크플로우

데이터 확인(누가·언제·무엇을 샀는지) → 패턴 발견(잘 팔리는 상품·시간·고객층) → 타깃 결정 → 제작·집행. "감이 아니라 데이터로 방향을 잡는다"가 핵심 원칙.

### 데이터 분석 프롬프트 공식

`역할 + 데이터 + 요청 + 형식` — 예: "너는 이커머스 데이터 분석가야 / [매출 데이터] / top5 상품과 이유를 분석해줘 / 표로 정리하고 실행 제안 3가지를 줘"

## 타깃 세그먼트

충성고객, 잠재이탈고객, 신규고객, 가격민감고객으로 나누어 각기 다른 메시지를 전달한다.

## 핵심 KPI

| 지표 | 의미 |
|---|---|
| 전환율 | 방문자 중 실제 구매한 비율 |
| 객단가 | 1인당 평균 구매 금액 |
| 재구매율 | 다시 구매한 고객의 비율 |
| 장바구니 이탈률 | 담아놓고 안 산 비율 |
| ROAS | 광고비 1원당 매출 |
| LTV | 한 고객이 평생 안겨줄 총 매출 |

## 데이터 분석 함정

표본이 너무 작음, 상관≠인과, 보고 싶은 것만 보는 확증편향, 평균의 함정(분포를 함께 봐야 함).

## 판매 채널 선택

스마트스토어(검색 유입), 쿠팡(빠른 배송·리뷰 신뢰), 자사몰(브랜드 데이터 소유), SNS 마켓(발견형 구매). 여러 채널을 얕게 보다 한 채널에서 1등을 노리는 편이 유리하다.
