## 자료 개요

Google의 이미지 생성 모델 "나노바나나 PRO"(Gemini 계열) 활용 강의자료. 기능 소개, 프롬프트 구성요소, 실전 사례(이미지 편집·합성·만화 생성 등), 제품 촬영("스튜디오 컷") 프롬프트 키워드 40개, API 활용까지 포함.

## 핵심 내용

p.1-20 기능 소개(향상된 추론/텍스트 출력/비주얼 기능, 프롬프트 구성요소·세부지침), p.21-45 실전 사례(이미지 합성·편집·만화 생성 등, 프롬프트 예시 다수), p.46-53 스튜디오 컷(제품 촬영 프롬프트 키워드 40개), p.54-64 API 활용(검색 그라운딩·추론·텍스트 렌더링·일관성 유지).
