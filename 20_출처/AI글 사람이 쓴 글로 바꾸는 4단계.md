# AI글 사람이 쓴 글로 바꾸는 4단계

## 원본

- 파일: [[_원본/AI글 사람이 쓴 글로 바꾸는 4단계.md]]
- URL: https://jasper-tartan-fcc.notion.site/AI-4-28800b4db8dc8046b4aecbd16296a933

## 자료 개요

LLM API 생성 파라미터(temperature, top_p, frequency_penalty, presence_penalty)를 조절해 AI 글의 "감정 온도"를 높이는 방법을 설명하는 자료. 용도별 추천 세팅표와 프롬프트 예시 포함.

## 핵심 내용

4개 파라미터 각각의 정의·효과·주의사항, 용도별(공식문서/블로그/창작) 종합 세팅 추천표, 세팅값을 텍스트로 지시하는 프롬프트 예시 3종.

## 위키 반영

- [[프롬프트 엔지니어링]] 업데이트 — "생성 파라미터로 AI 티 줄이기" 섹션 반영

## 참고

도서(『AI 전략 수업』) 및 자기계발 커뮤니티 홍보 포함. 파라미터 설명 자체는 일반적으로 알려진 LLM 샘플링 원리와 부합하나, 정확한 수치는 실험적 권장값으로 모델별 차이가 있을 수 있음.
