# Claude Code .claude 폴더 완전 정리

## 자료 개요

`.claude` 폴더 안의 모든 파일·폴더(CLAUDE.md, settings.json, skills/, commands/, agents/, hooks/ 등)의 역할을 비개발자 눈높이로 설명하는 안내서. 설치법은 다루지 않고 "이게 뭔지" 이해에 집중.

## 핵심 내용

`.claude` 폴더를 "설명서/규칙·권한/도구·기능" 3종류로 분류. CLAUDE.md, CLAUDE.local.md, settings.json 등 12개 항목을 비유와 함께 설명.

## 위키 반영

- [[Claude Code]] 신규 생성 — `.claude` 폴더 구조 섹션 전체 반영
