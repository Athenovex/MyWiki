# DM 자료 - 포니테일 설치법

## 자료 개요

Claude Code·Codex용 코드 절감 플러그인 "Ponytail" 설치기. 저자가 직접 겪은 시행착오를 그대로 정리한 실전 가이드.

## 핵심 내용

Claude Code/Codex 설치 명령 전체, 강도 조절(lite/full/ultra), 효과 측정법, 보안 주의사항, 저자가 직접 측정한 코드 절감률(51%, 공식 홍보 수치 80~94%와 차이).

## 위키 반영

- [[Ponytail]] 신규 생성 — 전체 내용 반영

## 참고

저자가 공식 벤치마크 수치(80~94%)를 그대로 믿지 말라고 직접 검증 결과(51%)를 공개한 점이 신뢰도를 높이는 요소 — 위키에도 이 차이를 명시함. 서드파티 플러그인 보안 주의사항 원문 그대로 반영.
