# Higgsfield Seedance 2.0 4K + FPV 드론 영상 만드는 프롬프트 템플릿

## 원본

- 파일: [[_원본/Higgsfield Seedance 2.0 4K + FPV 드론 영상 만드는 프롬프트 템플릿.md]]
- URL: https://fuzzy-license-6eb.notion.site/Higgsfield-Seedance-2-0-4K-FPV-37fd12a493f580d9ba70c29e744ce025

## 자료 개요

Higgsfield Seedance 2.0 4K로 FPV 드론 비행 영상을 만드는 프롬프트 템플릿. 자유의여신상·경복궁·N서울타워 3개 실전 예시(초장문 영문 프롬프트)와 재사용 가능한 스탠다드 템플릿.

## 핵심 내용

이미지 위에 빨간 선으로 카메라 경로를 그리는 기법, 노드(1/2/3) 번호 규칙, 3개 실전 프롬프트 전문(각 300줄 이상의 영문 프롬프트+네거티브 프롬프트), 빈칸 작성 가이드용 스탠다드 프롬프트.

## 위키 반영

- [[Higgsfield]] 업데이트 — "Seedance 2.0 — FPV 드론 영상 프롬프트" 섹션 반영 (기법 요약 + 스탠다드 템플릿 골격만 반영, 3개 장문 예시는 원본 참고로 남김)

## 참고

실전 예시 3개는 각각 매우 긴 영문 프롬프트(300줄+)로, 위키에는 재사용 가능한 기법과 스탠다드 템플릿만 요약 반영하고 전문은 원본 파일 참고로 안내함(제2의 원문화 방지).
