# How to Meet WCAG (Quickref Reference)

## 원본

- 파일: [[_원본/How to Meet WCAG (Quickref Reference).md]]
- URL: https://www.w3.org/WAI/WCAG22/quickref/?versions=2.1

## 자료 개요

W3C 공식 WCAG(웹 콘텐츠 접근성 지침) Quickref 참고서. 4대 원칙(Perceivable/Operable/Understandable/Robust)과 13개 가이드라인 아래, 모든 성공 기준(Success Criteria)·충분한 기법(Sufficient Techniques)·실패 사례(Failures)를 필터링 가능한 형태로 제공하는 대화형 웹 도구를 클리핑한 것. WCAG 2.1 필터 기준 1,591줄 분량.

## 핵심 내용

Principle 1~4 아래 Guideline 1.1~4.1(총 13개), 각 가이드라인 아래 개별 성공 기준의 정의문·충분한 기법 목록·실패 사례가 방대하게 수록됨.

## 위키 반영

- [[WCAG]] 신규 생성 — 4대 원칙·13개 가이드라인 구조, 준수 수준(A/AA/AAA) 개념, 문서 활용법을 한국어로 새로 정리해 반영

## 참고

**번역·전재하지 않음**: 개별 성공 기준의 정의 문구와 수백 개의 기법(Technique) 목록은 W3C의 저작물 원문이라, 전체를 한국어로 옮기면 사실상 원문 전체를 복제하는 것과 다르지 않아 반영하지 않았다. [[WCAG]] 노트는 이 문서의 구조·개념을 바탕으로 편집자가 자신의 지식으로 새로 서술한 것이며, 정확한 기준 문구나 최신 기법 목록이 필요하면 이 원본 파일 또는 W3C 공식 사이트를 직접 참고해야 한다. 원본은 `Clippings/` 폴더(Obsidian Web Clipper 기본 저장 경로)에 저장되어 있었음 — 이 Vault의 관례상 신규 웹 자료는 `01_수집`에 저장되어야 하므로, Web Clipper 확장 설정의 저장 경로를 `01_수집`으로 재확인할 것을 권장.
