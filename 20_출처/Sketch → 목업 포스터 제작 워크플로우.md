## 자료 개요

손그림 스케치를 하이엔드 목업 포스터·광고 영상으로 만드는 Claude+Higgsfield MCP 파이프라인. 구도(스케치)와 무드(별도 생성)를 분리하는 것이 핵심 설계.

## 핵심 내용

MCP 세팅 → 스케치 라벨링 → Claude 업로드+시작 프롬프트(전문) → Soul 2 무드 탐색 → GPT Image 2 합성 → Seedance 영상화. 6단계 전체 실행 절차와 프롬프트 원문.

## 위키 반영

- [[Higgsfield]] 신규 생성 — "실전 워크플로우: 손스케치 → 목업 포스터" 섹션 및 MCP 연결법 반영

## 참고

실무 파이프라인 공유 자료. Higgsfield 특정 모델명(Soul 2, GPT Image 2, Seedance)은 원문 그대로 인용.
