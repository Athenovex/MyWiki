# Sketch → 목업 포스터 제작 워크플로우

손그림 스케치 한 장만 있으면, 어떤 제품·어떤 구도든 하이엔드 목업 포스터와 광고 영상까지 만들 수 있는 범용 파이프라인입니다. Claude + Higgsfield MCP 조합으로 작동합니다.

> **파이프라인 한눈에 보기**
> 
> `① MCP 세팅` → 
> `② 스케치 라벨링` → 
> `③ Claude 업로드 + 프롬프트` → 
> `④ Soul 2 무드 탐색 (3종 × 4장)` → 
> `⑤ GPT Image 2 구도 × 무드 합성` → 
> `⑥ Seedance 영상화`

> 💡 
> 
> → **<u>핵심 설계 철학: 구도와 무드를 분리한다.
> </u>**
> 스케치는 “무엇이 어디에 놓이는가”(구도)만 담당하고, 분위기(색감·조명·질감)는 별도 단계에서 탐색합니다. 이 둘을 마지막에 합치면, 어떤 스케치를 넣어도 일관된 품질이 나옵니다.

---

### 1️⃣ 클로드 - 힉스필드 MCP 세팅

[Higgsfield MCP | AI Image & Video Generation for Any Agent](https://higgsfield.ai/favicon.ico?d4bb6dd8ccb5053d)

1. Claude(claude.ai) → **설정 > 커넥터(Connectors)**

1. **커스텀 커넥터 추가** → Higgsfield URL 직접 입력: `https://mcp.higgsfield.ai/mcp`

1. Higgsfield 계정으로 OAuth 로그인 → 권한 승인

1. 대화창에 “힉스필드 크레딧 잔액 알려줘”라고 입력해 연결 및 크레딧 확인

> 💡 
> 
> **💡 MCP가 뭔가요?**
> 
> MCP(Model Context Protocol)는 Claude 같은 AI를 외부 서비스와 연결해주는 표준 규격입니다. 쉽게 말해 **AI용 USB 포트** — 어떤 서비스든 MCP 규격만 지원하면 Claude에 꽂아서 쓸 수 있습니다.
> 
> MCP를 연결하면 Claude가 대화만 하는 게 아니라, 그 서비스의 기능을 **직접 실행**할 수 있게 됩니다. Higgsfield MCP를 연결하면 Claude가 대화 중에 직접 이미지·영상 생성을 시켜주고, 결과를 받아 다음 단계까지 이어가는 식이죠. 우리가 이 워크플로우에서 "무드 4장 뽑아줘" 한마디로 생성→셀렉→합성→영상화를 대화 흐름 안에서 처리할 수 있는 이유입니다.
> 
> **💡 팁**
> - 이미지·영상 생성은 크레딧을 소모합니다. 단계별 생성 수량을 미리 정하고 시작하세요.
> - 고해상도(4K) 옵션은 크레딧 소모가 크므로 **최종 셀렉본에만** 사용.

### 2️⃣ 스케치 준비 — 구성요소 라벨링

AI가 스케치를 정확히 읽게 하는 가장 중요한 단계입니다. **각 도형이 무엇인지 텍스트로 라벨링**하세요.

![IMG_6502.HEIC](attachment:f0eed0c7-8d85-4ee7-939f-57468d2eacb7:IMG_6502.heic)

![스크린샷 2026-07-08 오후 8.14.52.png](attachment:434dd6cc-c144-414a-b10f-1abf94a851c8:스크린샷_2026-07-08_오후_8.14.52.png)

1. 종이·태블릿에 원하는 구도를 스케치합니다. 잘 그릴 필요 없습니다 — **위치, 크기 비율, 겹침 관계**만 전달되면 충분합니다.

1. 스케치를 촬영/캡처한 뒤 피그마, 그림판, 아이패드 마크업 등에서 각 도형 위에 **눈에 띄는 색(빨강 추천)으로 이름 텍스트**를 답니다.
    - 예: `제품명`, `과일`, `소품A`, `배경 오브제`

1. 같은 오브제가 여러 개라면 **하나하나 전부** 라벨링합니다. (같은 소품 4개 → 4곳 모두 표기)

**라벨링 품질 체크리스트**

- [ ] 모든 도형에 라벨이 있는가?

- [ ] 라벨이 어느 도형 소속인지 헷갈리지 않는가? (도형 안쪽 또는 바로 옆)

- [ ] 손글씨가 아니라 **디지털 텍스트**인가? (인식률이 훨씬 높음)

### 3️⃣ Claude에 업로드 + 시작 프롬프트

라벨링된 스케치를 Claude에 업로드하고 아래처럼 요청합니다.

**사용자 시작 프롬프트 템플릿**

```
힉스필드 MCP 사용해서 이 스케치 구도로 하이퀄리티 뷰티 목업 포스터 제작해줘. 프로세스는 이렇게 진행하자: 

1. 먼저 스케치에 라벨링된 구성요소들을 파악해줘. 

2. Soul 2로 무드 이미지를 3가지 방향, 각 4장씩 생성해줘. 
- 스케치의 배치(구도)는 따라하지 말고, 파악한 구성요소들(제품 + 주요 소품)은 이미지 안에 자연스럽게 등장시켜줘. 
- 무드 프롬프트는 감각적으로 써줘: 구체적인 조명(빛의 방향·성질), 재질과 질감 (광택, 이슬, 벨벳 등), 색 팔레트, 렌즈 느낌(매크로, 얕은 심도)까지 묘사하고, "high-end editorial", "campaign still life" 같은 하이엔드 광고 사진 키워드를 포함해줘. 
- 3가지 방향은 조명·배경·톤이 서로 확실히 구분되게 잡아줘. 

3. 내가 무드를 고르면, GPT Image 2에 스케치(구도) + 고른 무드 이미지를 함께 넣어서 스케치 구도 그대로 + 그 무드로 최종 포스터를 만들어줘. (무드 이미지를 먼저, 스케치를 뒤에 넣고 quality는 high로)
```

이 프롬프트를 받으면 Claude가 자동으로:
- 스케치를 Higgsfield 스토리지에 업로드하고
- 스케치의 구도를 **언어로 재기술**합니다 (예: “하단에 A가 베이스, 좌측에 B, 그 위에 C가 대각선으로…”)

**⚠️ 확인 포인트**: Claude가 재기술한 구도 설명이 내 의도와 맞는지 검수하세요. 내 의도와 다른 결과물을 내놓는다면, 클로드에게 원하는 포인트를 수정 요청하세요.
