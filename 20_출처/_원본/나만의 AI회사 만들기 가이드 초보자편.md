# 나만의 AI회사 만들기_가이드_초보자편

## 🏢 나만의 AI 콘텐츠 회사 만들기

> 혼자 다 하지 말고, AI 직원 12명한테 나눠서 시키는 법
> 갓생맘이 실제로 쓰는 구조 그대로 정리했어요. 복붙해서 오늘 당장 시작하시면 됩니다.

---

### 시작 전에 · 이 자료로 얻는 것

- 내 콘텐츠 일을 **12개 부서로 쪼개는 기준**

- 부서마다 뭘 시킬지 적는 **양식 1장**

- 그 문서를 **Claude Code에 던져서 굴리는 복붙 프롬프트 4개**

- 사고 안 나게 막아주는 **안전 규칙 6줄**

준비물은 딱 2개예요. **메모장 1개, Claude(또는 Claude Code) 1개.** 코딩 몰라도 됩니다.

---

### 1. 왜 ’한 명의 AI’가 아니라 ’12명의 회사’인가

AI한테 “인스타 콘텐츠 만들어줘”라고 하면 결과가 늘 애매하죠. 이유는 하나예요.
**한 명한테 조사·기획·검수·글쓰기·제작을 다 시켰기 때문이에요.**

사람 회사도 똑같잖아요. 혼자 다 하는 회사는 품질이 안 나와요.
그래서 저는 AI를 **역할별로 쪼갰어요.** 바뀐 건 이거예요.

| 쪼개기 전 | 쪼갠 후 |
| --- | --- |
| “콘텐츠 만들어줘” → 뭉뚱그린 결과 | “시장조사팀으로 일해줘” → 출처까지 붙은 후보 5개 |
| 내가 매번 처음부터 설명 | 부서 문서에 이미 기준이 적혀 있음 |
| 잘 나온 이유를 모름 | 어느 단계에서 좋아졌는지 보임 |
| 내가 다 검수 | 검수 담당 부서가 먼저 걸러냄 |

핵심은 하나예요. **AI는 비서고, 결정은 내가 합니다.**

### 2. 내 일을 12개 부서로 쪼개기

제가 나눈 기준은 **“콘텐츠 1개가 세상에 나오기까지 거치는 단계”**예요.
그대로 쓰셔도 되고, 안 쓰는 부서는 지우셔도 됩니다. **처음엔 5개만 있어도 굴러가요.**

#### 🔎 만드는 단계

| # | 부서 | 이 부서가 하는 일 | 없으면 생기는 일 |
| --- | --- | --- | --- |
| 1 | 시장조사팀 | 오늘의 AI 뉴스·트렌드 수집, 공식 출처 확인 | 남들 다 아는 소재만 반복 |
| 2 | 브랜드 분석팀 | 내 계정 흐름·저장률·페르소나 점검 | 감으로 만들고 감으로 망함 |
| 3 | 기획 1팀 | 매일 아이디어 10개 생산, 점수 매겨 TOP 3 | 소재 고갈, 매번 백지에서 시작 |
| 4 | 브랜드 검수팀(QA) | 내 톤·금칙어·중복·근거 검사 | AI 말투가 그대로 나감 |
| 5 | 기획 2팀 | 승인된 안만 대본으로 작성 | 안 쓸 대본까지 쓰느라 시간 낭비 |

> 70%만 채우고 시작하는 게, 12개 완벽하게 준비하다 안 하는 것보다 100배 낫습니다.

### 3. 부서 카드 쓰는 법 (이게 전부예요)

부서 하나당 이 5줄만 적으면 끝나요.

```
부서 이름:
오늘 할 일:
지켜야 할 기준: (3개)
결과물 형태:
넘겨줄 다음 부서:
```

#### 실제 예시 · 브랜드 검수팀

```
부서 이름: 브랜드 검수팀(QA)
오늘 할 일: 기획팀이 낸 아이디어 10개를 내 브랜드 기준으로 검사
지켜야 할 기준:
  ① 금칙어가 있으면 탈락 (예: "여정", "마법 같은", "함께 알아볼까요?")
  ② 근거 링크 없으면 탈락
  ③ 최근 7일 콘텐츠와 40% 이상 겹치면 각도 변경
결과물 형태: 통과 O / 반려 X + 반려 사유 한 줄
넘겨줄 다음 부서: 기획 2팀(대본)
```

**여기서 제일 중요한 건 ‘지켜야 할 기준’ 3줄이에요.**
이 3줄이 없으면 AI는 그냥 착한 말만 합니다. 반려 기준을 적어야 진짜 걸러내요.

### 4. Claude Code에 던져서 굴리는 법

여기부터가 진짜예요. 위에서 만든 문서를 **AI가 매번 읽는 사규**로 만드는 겁니다.

#### STEP 1. 파일 하나 만들기

컴퓨터에 폴더 하나 만들고, 그 안에 `**AI_COMPANY.md**` 파일을 넣으세요. ← 제가 드릴거에용
(같이 받으신 템플릿 파일을 그대로 쓰시면 됩니다. 빈칸만 채우세요.)

#### STEP 2. Claude Code 열고 첫 지시

```
AI_COMPANY.md를 읽어줘.
지금부터 너는 이 회사의 직원들이야.
읽고 나서, 내가 채워야 할 빈칸이 어디인지 먼저 알려줘.
```

#### STEP 3. 부서 채우기 (AI한테 시켜도 됩니다)

```
AI_COMPANY.md의 부서 12개를 내 채널 기준으로 채워줘.
내 채널은 [주제]를 다루고, 주 시청자는 [타깃]이야.
부서마다 '지켜야 할 기준' 3줄은 반드시 반려 기준으로 써줘.
```

#### STEP 4. 매일 아침 이 한 줄

```
오늘 업무 시작. 시장조사팀 → 기획 1팀 → 검수팀 순서로 진행하고,
TOP 3만 뽑아서 나한테 보고해줘. 내가 고르면 그때 대본 써.
```

**포인트는 마지막 줄이에요.** “내가 고르면 그때”라고 못 박아야 AI가 혼자 끝까지 달리지 않아요.

#### STEP 5. 부서 하나만 부르고 싶을 때

```
브랜드 검수팀으로만 일해줘. 이 원고 검사하고 반려 사유만 말해줘.
[원고 붙여넣기]
```

> 💡 **Claude 앱만 쓰시는 분**
> Claude Code 없어도 됩니다. 대화창에 `AI_COMPANY.md` 내용을 그대로 붙여넣고
> “지금부터 이 회사 규칙대로 일해줘”라고 하면 똑같이 굴러가요.
> 매번 붙여넣기 귀찮으면 그때 Claude Code로 넘어가시면 됩니다.

### 6. 안전 규칙 6줄 (이거 꼭 넣으세요)

AI한테 자율권을 주면 사고가 납니다. 문서 맨 위에 이 6줄을 박아두세요.

```
① 메일 실제 발송 금지 — 초안까지만
② SNS 실제 게시 금지 — 예약·업로드는 사람이
③ 결제·구독 금지
④ 원본 파일 삭제·덮어쓰기 금지 — 복제본에만 작업
⑤ 연결 안 된 서비스를 '완료'라고 보고 금지
⑥ 확인 안 된 정보를 사실처럼 쓰기 금지 — 출처 없으면 '미확인'이라고 표시
```

**⑤번이 진짜 중요해요.** 이거 없으면 AI가 “인스타 업로드 완료했습니다”라고 말합니다. 안 했는데요.

### 7. 자주 나오는 질문 5개

**Q. 부서를 12개나 만들면 헷갈리지 않나요?**
A. 헷갈려요. 그래서 12번 비서실이 있는 거예요. 나는 비서실 보고만 봅니다.

**Q. 유료 결제해야 하나요?**
A. 무료 Claude로도 되지만 클로드 코드를 쓰시는거면 유료로 쓰시면 좋아요. 빌드하시고 부서를 하나씩 불러서 쓰시면 돼요. 하루 종일 자동으로 돌리고 싶어지면 그때 고민하세요.

**Q. AI가 제 말투를 못 따라 해요.**
A. 검수팀 기준에 **금칙어**를 적으세요. “이렇게 써줘”보다 “이건 쓰지 마”가 훨씬 잘 먹혀요.

**Q. 부서를 몇 개까지 늘려도 되나요?**
A. 늘리는 것보다 **비우는 게** 어려워요. 2주 동안 한 번도 안 부른 부서는 지우세요.

**Q. 이거 만드는 데 얼마나 걸려요?**
A. 처음 문서 1장 쓰는 데 30분. 그날부터 씁니다. 나머지는 쓰면서 고쳐요.
