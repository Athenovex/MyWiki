### 🔑 1. 열쇠 발급 — 네이버 클라우드 API HUB

검색 API는 지금 네이버 클라우드의 'API HUB'에서 제공됩니다. 신청하면 아이디(Client ID)와 비밀키(Client Secret) 두 줄이 나오고, 이 두 줄이 뉴스 창구를 여는 열쇠에요.

[**네이버 API HUB에서 검색 API 신청하기**](https://www.ncloud.com/product/applicationService/naverApiHub)

### 🧪 2. 첫 실행 — 클로드에 열쇠 주고 시키기

발급받은 두 줄을 클로드 채팅에 붙여넣고 이렇게 시켜보세요. 호출 코드는 클로드가 알아서 짜고, 기사 제목과 링크가 채팅에 도착합니다.

```
네이버 검색 API 열쇠야.
Client ID: [여기 붙여넣기]
Client Secret: [여기 붙여넣기]
이 키로 '[이 키워드]' 최신 뉴스 10건을 모아서 제목·언론사·링크로 정리해줘.
```

키워드는 뭐든 됩니다 — 브랜드명, 경쟁사, 관심 산업, 좋아하는 주제까지. 여기까지 되면 재료 준비는 끝입니다.

---

### ⏰ 3. 예약 걸기 — 매일 아침 자동으로

테스트가 되면 이제 손을 뗄 차례에요. 코워크의 예약 작업으로 걸어두면 매일·평일·매주 주기로 알아서 돌아갑니다. [**예약 작업 공식 도움말**](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)

```
방금 그 뉴스 수집을 예약 작업으로 만들어줘.
매일 아침 8시, 키워드는 [내 키워드].
결과는 노션 '데일리 뉴스' 페이지에 날짜별로 쌓아줘.
```

- ****만드는 방법 A — 말로 시키기 (초보 추천)****

- ****만드는 방법 B — 직접 설정****

---

### 📚 4. 노션 적재 — 목록 말고 브리핑으로

그냥 기사 목록만 받으면 결국 다시 읽어야 합니다. 정리 규칙을 한 줄 얹어서 요약 브리핑까지 시키세요. 클로드는 노션 페이지를 직접 만들고 고칠 수 있어서(공식 커넥터 기준 읽기·쓰기 모두 지원), 날짜별로 차곡차곡 쌓이는 아카이브가 됩니다. [**클로드 노션 커넥터**](https://claude.com/connectors/notion)

```
정리 규칙 추가해줘.
겹치는 기사는 하나로 묶고, 기사마다 세 줄 요약을 붙여줘.
중요한 순서대로 정렬하고, 맨 위에 '오늘의 한 줄 총평'을 달아줘.
```

키워드만 바꾸면 쓰임새도 바뀝니다 — 경쟁사 동향 감시, 내 브랜드 언급 모니터링, 투자 종목 뉴스까지 같은 틀로 무한 복제가 됩니다.
