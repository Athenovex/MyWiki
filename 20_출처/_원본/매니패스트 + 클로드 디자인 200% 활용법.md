# 매니패스트 + 클로드 디자인 200% 활용법

## 1️⃣ 매니패스트로 PRD→기능명세서→유저플로우→와이어프레임을 정교하게 제작합니다.

[매니패스트 ― PRD부터 와이어프레임까지, 소프트웨어 기획 AI](https://manyfast.io/favicons/android-icon-192x192.png)

### 매니패스트란?

매니페스트는 **에디터 기반의 AI 기획 에이전트(AI Planning Agent)** 서비스입니다. 앱·웹 서비스를 만들 때, 아이디어만 있으면 **PRD(요구사항 정의서)부터 기능명세서, 유저플로우, 와이어프레임까지** 순서대로 만들어갈 수 있습니다.

> 코딩과 디자인 속도가 아무리 빨라져도 **초기 기획이 구조화되어 있지 않으면 이후 모든 단계가 흔들립니다.** 이 기획 단계의 비효율을 해결하기 위해 매니패스트를 사용합니다.

---

### 사용 흐름

#### 1-1. 주제 작성

만들고 싶은 주제를 채팅창에 간단히 작성합니다.

> 💡 **Tip.** 목적·타겟·핵심 기능 등을 구체적으로 입력할수록 더 정확하고 완성도 높은 초안을 얻을 수 있습니다.

![스크린샷 2026-06-18 오후 12.03.14.png](attachment:6233ca09-dfc0-4bd2-8d72-f21b0491213a:스크린샷_2026-06-18_오후_12.03.14.png)

#### 1-2. PRD 문서 & 기능명세서 제작

AI와 질문을 주고받으며 **PRD 문서**와 **기능명세서**를 제작합니다. AI가 기획 문서의 구조 안에서 입력된 정보를 정리·보완하고, 초기에 발생할 수 있는 **논리적 오류나 누락 사항을 검토해 개선점을 제안**합니다.

> **PRD(Product Requirements Document)란?**
> 서비스를 만들 때 어떤 문제를 해결하고, 어떤 기능을 제공하며, 어떻게 운영할지를 정리한 문서입니다. 제품의 목적·타겟·핵심 기능·성공 기준을 정의해 팀 전체가 같은 방향을 바라보게 하는 '나침반' 역할을 합니다.

#### 1-3. 유저 플로우 제작

사용자가 서비스를 이용하며 거치는 일련의 단계와 분기를 시각적으로 표현한 유저 플로우(플로우차트)를 제작합니다. 서비스 전체 구조를 한눈에 파악할 수 있습니다.

#### 1-4. 와이어프레임 제작

원하는 화면의 **와이어프레임**을 제작합니다. 색상·타이포그래피보다 레이아웃, 정보 계층, 요소 간 상호작용에 집중한 화면 설계도로, 디자인·개발로 넘어가기 전 토대를 잡아줍니다.

#### ✅ 매니패스트 → 클로드 디자인 워크플로우

매니페스트에서 제작한 **기획 문서를 모두 클로드 디자인(Claude Design)에 넣고 디자인을 진행**하시면 됩니다. 기획의 맥락(목적·기능·플로우·화면 구조)을 그대로 디자인 단계로 넘겨, 처음부터 새로 설명할 필요 없이 일관된 결과물을 만들 수 있습니다.

#### 진행 순서

1. **기획 문서 내보내기**
매니페스트에서 PRD·기능명세서는 마크다운으로, 와이어프레임은 피그마에서 열고 Save Local Copy를 통해 피그마 파일로 다운받습니다.

1. **클로드 디자인에 전달**
내보낸 문서를 클로드 디자인에 모두 첨부합니다. PRD·기능명세서로 **무엇을·왜 만드는지**, 유저 플로우·와이어프레임으로 **어떤 화면·흐름인지**를 한 번에 전달합니다.

1. **(권장) 디자인 시스템 먼저 적용**
아래 '추가 팁'처럼 디자인 시스템을 먼저 만들어두면, 클로드 디자인이 그 컴포넌트·스타일에 맞춰 화면을 디자인해 **통일감 있는 결과물**이 나옵니다.

1. **화면 디자인 생성 & 반복**
와이어프레임을 토대로 실제 화면 디자인을 생성하고, 채팅으로 수정·보완하며 완성도를 높입니다.

### 💡 중요한 추가 팁) 디자인 시스템 활용하기

피그마 커뮤니티에서 검증된 디자인 시스템(피그마파일)을 **클로드 디자인(Claude Design)** 에게 전달해, 디자인 시스템을 먼저 제작해보세요. 일관된 컴포넌트와 스타일을 미리 잡아두면 이후 화면 디자인이 훨씬 빠르고 통일감 있게 진행됩니다.

### 💡 정말 중요한 추가 팁) 매니패스트 MCP로 기획 문서 바로 Claude Code에 연결하기

매니패스트는 **MCP(Model Context Protocol)** 를 지원합니다. Claude Code, Cursor 같은 AI 코딩 도구에 연결하면, AI가 **매니페스트 기획 문서를 직접 읽고 기획 내용대로 바로 구현**합니다. 별도로 문서를 가공해 붙여넣을 필요 없이 기획 맥락이 그대로 개발 단계로 이어지고, 개발 중 변경된 내용을 문서에 다시 반영하는 **양방향 동기화**도 가능합니다.

> 📖 **연동 설정 방법**은 매니페스트 **공식 가이드 문서**를 참고하세요. (MCP 연결은 보통 Claude Code 터미널에서 `claude mcp add` 명령으로 매니페스트 서버 URL을 등록하고, 브라우저에서 OAuth 인증을 완료하면 됩니다.)

#### ➡️ 개발 시작하기

다음 조건이 모두 충족되면 바로 개발을 시작할 수 있습니다.

1. 매니패스트 사이트에서 **기획을 완료**했고,

1. **매니패스트 – Claude Code MCP 연결**이 되어 있다면,

1. Claude Code 입력창에 아래 내용을 붙여넣어 개발을 시작해보세요.

**① 프로젝트 목록 확인**

```
매니패스트에서 프로젝트 리스트 보여줘.
```

**② 기획 읽고 진행 체크리스트 자동 생성**

```
매니패스트에서 [프로젝트 이름] 기획 전체 읽고,
기능 목록을 우선순위별로 정리해서 레포에 PROGRESS.md 만들어줘.
Phase별로 나누고, 각 기능마다 체크박스로 진행 상황 추적할 수 있게 해줘.
```

이렇게 하면 Claude Code가 매니패스트 기획을 읽고 **체크리스트를 자동으로 만들어줍니다.** 이후 기능이 완성될 때마다 체크박스가 업데이트되면서 **전체 진행 상황을 한눈에** 볼 수 있습니다.
