# 새 프롬프트 공식

프롬프트 공식 정리

목표 / 대상 / 컨텍스트 / 평가 기준 / 작업 순서 / 출력 형식 / 검토 요청

### 1. 프롬프트 구성 요소

| 항목 | 작성 내용 |
| --- | --- |
| 목표 | 이 결과물을 통해 사용자가 어떤 행동을 하게 만들고 싶은지 |
| 대상 | 누가 읽거나 사용할 것인지 |
| 컨텍스트 | 현재 상황, 배경, 자료, 제약 조건 |
| 평가 기준 | 좋은 결과물의 기준 |
| 작업 순서 | 먼저 무엇을 판단하고, 그다음 무엇을 만들지 |
| 출력 형식 | 표, 단계별, 문구안, 보고서, 체크리스트 등 |
| 검토 요청 | 초안 작성 후 약점을 찾고 개선안까지 제시 |

### 2. 복사용 완성 프롬프트

```javascript
아래 내용을 바탕으로 결과물을 만들어줘.

### [목표]

이 결과물을 본 사람이 [원하는 행동]을 하게 만드는 것.

### [대상]

[타깃 고객 / 독자 / 의사결정자]

### [컨텍스트]

- 현재 상황:
- 제공할 자료:
- 고객의 고민:
- 반드시 반영할 조건:
- 피해야 할 표현:

평가

- 이해하기 쉬운가
- 문제와 해결책이 명확한가
- 선택해야 할 이유가 충분한가
- 과장 표현은 없는가
- 다음 단계가 자연스러운가

### [작업 방식]

먼저 이 결과물을 잘 만들기 위한 기준을 정리해줘.

그다음 초안을 작성해줘.

마지막으로 개선본을 제시해줘.

### [출력 형식]

- 기준 정리
- 초안
- 문제점
- 개선본
- 바로 사용할 최종본
```

## 1인사업가를 위한 업종별 인스타 콘텐츠 기획 프롬프트 10개

1. 동네 카페 / 디저트샵

```
[목표]
동네 고객을 위한 인스타 콘텐츠를 기획해줘.

[대상]
지역 고객, 근처 직장인, 3050 여성.

[컨텍스트]
카페의 메뉴, 공간, 분위기, 고객 경험을 콘텐츠 소재로 활용한다.

[평가 기준]
- 이해하기 쉬운가
- 카페의 차별점이 보이는가
- 사진과 영상으로 표현하기 쉬운가

[작업 순서]
고객의 선택 기준을 정리한 뒤 릴스와 캐러셀 주제를 제안한다.

[출력 형식]
릴스 주제 10개, 캐러셀 주제 10개, 후킹 문구 10개.

[검토 요청]
초안의 약점을 정리하고 개선안을 제시한다.
```

2. 식당 / 외식업

```
[목표]
지역 고객을 위한 인스타 콘텐츠를 기획해줘.

[대상]
근처 직장인, 가족 단위 고객, 3050 지역 고객.

[컨텍스트]
메뉴, 가격, 분위기, 주차, 지역성, 고객 경험을 콘텐츠 소재로 활용한다.

[평가 기준]
1. 메뉴의 매력이 보이는가
2. 지역 고객이 공감할 수 있는가
3. 방문 이유가 분명한가
4. 릴스와 캐러셀로 표현하기 쉬운가

[작업 순서]
고객이 식당을 선택하는 기준을 정리한 뒤, 릴스와 캐러셀 주제를 제안해줘.

[출력 형식]
1. 고객 기준 5개
2. 릴스 주제 10개
3. 캐러셀 주제 10개
4. 후킹 문구 10개
5. 연결 문구 5개

[검토 요청]
초안의 약점을 정리하고 개선안을 제시해줘.
```

3. 뷰티샵 / 네일 / 속눈썹 / 피부관리

```
[목표]
첫 방문 고객이 불안을 줄이고 상담이나 예약을 고려할 수 있는 인스타 콘텐츠를 기획해줘.

[대상]
외모 관리에 관심은 있지만 가격, 효과, 유지 기간, 어울리는 스타일을 고민하는 3050 여성 고객.

[컨텍스트]
고객은 나에게 어울릴지, 부담스럽지 않을지, 가격 대비 만족할지, 첫 방문이 어색하지 않을지 걱정한다.
전후 변화만 강조하기보다 고객의 고민, 선택 기준, 관리 과정을 쉽게 보여준다.

[평가 기준]
1. 고객의 불안을 정확히 짚는가
2. 서비스 과정이 쉽게 이해되는가
3. 과장 없이 신뢰를 주는가
4. 상담이나 예약 흐름이 자연스러운가
5. 첫 방문 고객의 부담을 낮추는가

[작업 순서]
첫 방문 고객이 걱정하는 요소를 정리한 뒤, 불안을 낮추는 릴스와 캐러셀 주제를 제안해줘.

[출력 형식]
1. 첫 방문 고객의 불안 요소 5개
2. 릴스 주제 10개
3. 캐러셀 주제 10개
4. 불안 해소형 콘텐츠 5개
5. 후킹 문구 10개
6. 예약 연결 문구 5개

[검토 요청]
초안의 약점을 정리하고 신뢰 중심으로 개선해줘.
```

4. 필라테스 / 요가 / 운동 스튜디오

```
[목표]
운동을 망설이는 초보 고객이 나도 시작할 수 있겠다고 느끼는 인스타 콘텐츠를 기획해줘.

[대상]
운동 경험이 적고, 체형, 통증, 자세, 유연성 문제로 고민하는 3050 여성.

[컨텍스트]
고객은 운동 효과보다 먼저 내가 해도 될까를 걱정한다.
전문적인 운동 설명보다 초보자의 부담을 낮추고 작은 변화부터 보여줘야 한다.

[평가 기준]
1. 초보자의 부담을 낮추는가
2. 운동 효과를 현실적으로 보여주는가
3. 강사와 공간에 대한 신뢰가 생기는가
4. 체험 수업 흐름이 자연스러운가
5. 건강한 변화에 집중하는가

[작업 순서]
운동 초보자가 망설이는 이유를 정리한 뒤, 그 고민을 해결하는 릴스와 캐러셀 주제를 제안해줘.

[출력 형식]
1. 초보 고객의 고민 5개
2. 릴스 주제 10개
3. 캐러셀 주제 10개
4. 초보자 공감 후킹 10개
5. 체험 수업 연결 문구 5개
6. 7장 캐러셀 구성 예시 1개

[검토 요청]
운동을 잘하는 사람만 대상처럼 보이는 부분을 찾고, 초보자도 부담 없이 시작할 수 있게 개선해줘.
```

5. 공방 / 원데이클래스

```
[목표]
원데이클래스에 관심 있는 고객을 위한 인스타 콘텐츠를 기획해줘.

[대상]
새로운 취미를 찾는 20~50대 고객, 친구나 가족과 체험할 공간을 찾는 사람.

[컨텍스트]
고객은 결과물, 난이도, 소요 시간, 가격, 준비물, 혼자 참여 가능 여부를 궁금해한다.
작품 사진뿐 아니라 과정과 분위기를 함께 보여준다.

[평가 기준]
1. 체험 매력이 보이는가
2. 결과물이 매력적으로 보이는가
3. 초보자도 가능하다는 느낌을 주는가
4. 공간 분위기가 드러나는가

[작업 순서]
고객 질문을 정리한 뒤 과정, 결과물, 분위기, 고객 경험별 콘텐츠를 제안해줘.

[출력 형식]
1. 고객 질문 5개
2. 릴스 주제 10개
3. 캐러셀 주제 10개
4. 과정 소개 콘텐츠 5개
5. 결과물 콘텐츠 5개
6. 문의 연결 문구 5개

[검토 요청]
단순 작품 소개처럼 보이는 부분을 찾고 경험 중심으로 개선해줘.
```

6. 온라인 셀러 / 스마트스토어

```
[목표]
온라인 고객이 상품의 필요성과 활용 장면을 이해할 수 있는 인스타 콘텐츠를 기획해줘.

[대상]
인스타그램에서 상품을 발견하고 비교 중인 잠재 고객.

[컨텍스트]
상품 사진만으로는 충분하지 않다.
고객은 이 상품이 왜 필요한지, 무엇이 다른지, 어떻게 쓰는지 알고 싶어한다.
문제 해결과 사용 장면 중심으로 구성한다.

[평가 기준]
1. 상품의 필요성이 분명한가
2. 사용 장면이 구체적인가
3. 차별점이 드러나는가
4. 신뢰가 생기는가

[작업 순서]
고객의 문제와 욕구를 정리한 뒤 문제 해결형, 사용법형, 비교형, 후기형 콘텐츠로 나눠줘.

[출력 형식]
1. 고객 고민 5개
2. 릴스 주제 10개
3. 캐러셀 주제 10개
4. 사용법 콘텐츠 5개
5. 후킹 문구 10개
6. 연결 문구 5개

[검토 요청]
너무 판매 글처럼 보이는 부분을 찾고, 고객이 필요성을 쉽게 이해하도록 개선해줘.
```

1. 패션 / 잡화 셀러

```javascript
[목표]
이 결과물을 통해 고객이 상품을 자신의 일상에 적용해보고 싶다고 느끼고, 저장하거나 구매하게 만드는 인스타 콘텐츠를 기획해줘.

[대상]
옷, 가방, 액세서리, 잡화를 인스타그램에서 보고 구매를 고민하는 20~50대 고객.

[컨텍스트]
패션·잡화 고객은 상품 자체보다 “나에게 어울릴까?”, “어떻게 코디할까?”, “어떤 상황에 쓰면 좋을까?”를 궁금해한다.
상품 소개보다 스타일링 제안, 상황별 활용, 전후 분위기 변화가 중요하다.

[평가 기준]
1. 고객이 자신의 일상에 적용해보고 싶어지는가
2. 스타일링 아이디어가 저장 가치 있는가
3. 상품의 장점이 자연스럽게 드러나는가
4. 구매 욕구를 자극하는가
5. 과한 판매 문구 없이 감각적으로 보이는가

[작업 순서]
먼저 고객이 패션·잡화 상품을 구매하기 전 고민하는 요소를 정리해줘.
그다음 코디형, 상황별 추천형, 비교형, 고객 후기형 콘텐츠로 나눠줘.
마지막으로 릴스와 캐러셀 기획안을 제안해줘.

[출력 형식]
1. 고객의 구매 전 고민 5개
2. 릴스 주제 10개
3. 캐러셀 주제 10개
4. 상황별 스타일링 콘텐츠 5개
5. 저장 유도형 코디 콘텐츠 5개
6. 첫 문장 후킹 10개
7. 구매 CTA 문구 5개

[검토 요청]
초안을 작성한 뒤, 단순 상품 나열처럼 보이는 부분을 찾아줘.
그리고 고객이 실제 착용 장면을 상상할 수 있도록 스타일링 중심으로 개선해줘.
```

1. 핸드메이드 / 수제 브랜드

```javascript
[목표]
이 결과물을 통해 고객이 수제 상품의 가치와 차별점을 이해하고, 구매하거나 선물용으로 고려하게 만드는 인스타 콘텐츠를 기획해줘.

[대상]
감성적인 제품, 특별한 선물, 나만의 취향을 담은 상품을 찾는 고객.

[컨텍스트]
수제 상품은 가격이 저렴한 대량 생산 제품과 비교될 수 있다.
따라서 제작 과정, 소재, 만든 사람의 철학, 사용 장면, 선물 가치가 콘텐츠에 드러나야 한다.
단순 제품 사진보다 “왜 이 상품이 특별한지”를 보여줘야 한다.

[평가 기준]
1. 수제 상품의 가치가 느껴지는가
2. 제작 과정과 정성이 보이는가
3. 선물 또는 소장 욕구가 생기는가
4. 브랜드 감성이 일관되게 드러나는가
5. 구매로 이어질 이유가 충분한가

[작업 순서]
먼저 고객이 수제 상품을 구매하는 이유를 정리해줘.
그다음 제작 과정, 소재, 사용 장면, 선물 상황을 콘텐츠 주제로 나눠줘.
마지막으로 구매 전환을 위한 릴스와 캐러셀 기획안을 제안해줘.

[출력 형식]
1. 고객이 수제 상품을 선택하는 이유 5개
2. 릴스 주제 10개
3. 캐러셀 주제 10개
4. 제작 과정 콘텐츠 5개
5. 선물 추천 콘텐츠 5개
6. 브랜드 감성 후킹 문구 10개
7. 구매 CTA 문구 5개

[검토 요청]
초안을 작성한 뒤, 단순 제품 홍보처럼 보이는 부분을 찾아줘.
그리고 수제 상품의 정성, 스토리, 선물 가치가 더 잘 보이도록 개선해줘.
```

1. 지식창업 / 강사 / 컨설턴트

```javascript
[목표]
이 결과물을 통해 1인 지식창업자 또는 강사가 인스타그램에서 전문성을 보여주고, 무료자료 신청·강의 신청·컨설팅 문의로 연결할 수 있는 콘텐츠를 기획해줘.

[대상]
자신의 전문성을 콘텐츠로 수익화하고 싶은 3050 1인사업가, 예비 강사, 프리랜서, 컨설턴트.
```
