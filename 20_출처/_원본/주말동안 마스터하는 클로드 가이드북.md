# 주말동안 마스터하는 클로드 가이드북

> 비개발자를 위한 Claude Code 실전 가이드 · 코딩 지식 필요 없음
> 딱 2일이면 충분합니다. 하루 2~3시간, 그대로 따라 하기만 하세요.
> — @3dragon_pd (용피디)

---

### 이 가이드북은 누구를 위한 건가요?

- 클로드를 브라우저 채팅으로만 쓰고 있는 분

- "AI로 자동화한다"는 말은 들었지만 어디서 시작할지 모르는 분

- 콘텐츠·마케팅·1인 사업·비서 업무를 클로드에게 진짜로 맡기고 싶은 분

**목표:** 주말 이틀 동안, 클로드를 "질문하는 챗봇"에서 "내 일을 대신 하는 팀원"으로 바꾸는 것.

> 💡 이 가이드의 핵심 원칙
> **"터미널·코딩 안 합니다."** 클로드 데스크톱 앱을 깔고, 그 안의 **Code 탭**에서 클로드한테 한국어로 시키기만 하면 돼요. 파일 만드는 것도 전부 클로드가 대신 합니다.

---

### 준비물 (시작 전 5분)

| 필요한 것 | 설명 |
| --- | --- |
| 클로드 유료 플랜 | Claude Pro / Max / Team 중 하나 (필수) |
| 컴퓨터 | 윈도우 / 맥 모두 가능 |
| 앱 다운로드 | `claude.com/download` (또는 공식 문서 `code.claude.com/docs/en/desktop-quickstart` 의 Download 버튼) |
| (윈도우만) Git | `git-scm.com/downloads/win` 에서 **Git for Windows** 먼저 설치 → 없으면 Code 탭 로컬 작업이 안 됩니다 |

---

## DAY 1 — 기초 세팅 (STEP 1~5)

### STEP 01 · 클로드 앱 깔고 Code 탭 열기

예전엔 Claude Code를 쓰려면 터미널에 명령어를 쳐야 했어요. 어렵죠. **이제 안 그래도 됩니다.클로드 데스크톱 앱**만 깔면, 그 안에서 클릭 몇 번으로 똑같이 쓸 수 있어요.

#### 따라 하기

1. `claude.com/download` 접속 → 내 OS(윈도우/맥) Download 버튼으로 앱 설치
(**윈도우는** 준비물의 **Git for Windows를 먼저** 설치하고 앱을 재시작하세요)

1. 앱 실행 → 클로드 계정으로 로그인

1. 앱 상단 가운데 탭 3개(**Chat / Cowork / Code**) 중 `**Code**` 탭을 클릭. 여기가 Claude Code입니다.
(유료 플랜이 아니면 업그레이드 안내가 떠요)

1. **Local** 선택 → **Select folder(폴더 선택)** 로 작업할 폴더를 고릅니다.
(없으면 바탕화면에 `클로드작업` 폴더 새로 만들어 선택)

1. 모델을 고르고, 아래 입력창에 **한국어로 말만 걸면** 됩니다. 터미널도, 코딩도 없어요.

> 💡 기본은 **Manual 모드**예요. 클로드가 파일을 바꾸기 전에 **미리 보여주고 물어봅니다.** 확인 후 **Accept(수락)** 를 누르면 적용돼요. 안전하니 걱정 마세요.

> ✅ STEP 1 체크: Code 탭에서 폴더를 열고 클로드와 대화가 시작된다.

---

### STEP 02 · 3개 탭 뭐가 다른가요?

앱을 열면 탭이 3개예요. 뭐가 뭔지만 알면 됩니다.

| 탭 | 언제 쓰나 |
| --- | --- |
| 💬 **Chat** | 그냥 물어볼 때. 간단한 질문용 |
| 🤝 **Cowork** | 클로드가 혼자 백그라운드로 작업을 돌릴 때 |
| ⚡ **Code** | **진짜 작업은 여기서 다.** 명령어·스킬·앱 연결·자동화 |

**결론:** 이 가이드는 **Code 탭**만 씁니다. 나머지는 나중에 천천히.
다들 Chat만 쓸 때, 고수는 Code 탭에서 일합니다.

> 참고: 브라우저([claude.ai](http://claude.ai/))에도 채팅·프로젝트가 있지만, 진짜 힘은 앱의 Code 탭에 있어요.

---

### STEP 03 · 같은 프롬프트 그만 치기 (나만의 명령어)

똑같은 프롬프트를 매주 열 번씩 치고 있다면 AI를 잘못 쓰는 거예요.
**한 번만 만들어두고**, 다음부턴 `/이름` 한 번으로 부릅니다.

#### 비개발자용 초간단 방법 — 클로드한테 만들어달라고 하기

Code 탭 입력창에 이렇게 그대로 쳐보세요:

```
숏폼 대본을 써주는 명령어를 만들어줘.
이름은 /대본 으로 하고,
규칙: 첫 3초 훅 → 핵심 3가지 → 저장 유도 CTA.
주제는 내가 뒤에 붙여서 넘길 거야.
```

→ 클로드가 `.claude/skills/대본/SKILL.md` 파일을 만들어줍니다. 보여주는 파일에 **Accept(수락)** 만 누르면 끝. (파일 직접 안 건드려도 돼요!)

#### 이제 이렇게 씁니다

```
/대본 클로드로 돈 버는 3가지 방법
```

→ 저장해둔 규칙대로 대본이 뚝딱 나옵니다.

> 💡 맥 사용자 팁: 시스템 설정 → 키보드 → 텍스트 대치에 자주 쓰는 문장을 등록하면, 몇 글자만 쳐도 전체 문장이 나와요.

> ✅ STEP 3 체크: `/대본 ...` 한 줄로 매번 쓰던 프롬프트가 자동 실행된다.

---

### STEP 04 · 나 없이도 굴러가게 (자동화·예약)

한 번 세팅하면 클로드가 알아서 정해진 시간에 일하게 만들 수 있어요.

#### 방법 A — 앱의 예약 작업(Routines) 쓰기

앱에 **예약 작업(Routines)** 화면이 있어요. **New routine(새 루틴)** 을 누르고 채우면 끝:

- 작업: "오늘 확인할 이메일과 일정 요약해서 정리해줘"

- 주기: "평일 매일 오전 9시"

두 종류 중 고릅니다:

- **클라우드(Remote)**: Anthropic 서버에서 실행 → **내 컴퓨터를 꺼놔도** 돌아감 (최소 1시간 간격)

- **로컬**: 내 컴퓨터에서 실행 → **앱이 켜져 있어야** 함 (최소 1분 간격)

#### 방법 B — 잠깐 지켜보게 하기 (`/loop`)

입력창에:

```
/loop 15m 배포 상태 확인하고 문제 있으면 알려줘
```

→ 내 컴퓨터에서 최대 3일간 반복. 급하게 뭔가를 감시할 때 좋아요.

> 참고: 터미널(CLI)을 쓰는 분은 `/schedule` 명령으로도 클라우드 예약을 만들 수 있어요. 앱에서는 위 **Routines 화면**을 쓰면 됩니다.

> ✅ STEP 4 체크: 예약 작업(Routines)으로 반복 작업 하나를 등록했다.
> 이쯤이면 클로드는 도구가 아니라 잠들지 않는 팀원입니다.

---

### STEP 05 · 첫 스킬(Skill) 장착하기

스킬은 **"내가 이 일을 어떻게 하는지"** 를 클로드에게 알려주는 작은 설명서예요.
한 번 만들어두면, 필요할 때 클로드가 알아서 꺼내 씁니다.

#### 클로드한테 스킬 만들어달라고 하기

Code 탭에:

```
'brand-voice'라는 스킬을 만들어줘.
내 브랜드 말투 규칙이야:
- 딱딱한 회사말 대신 친구처럼 "~해요"체
- 어려운 영어 용어 금지, 한글로 풀어서
- 마지막은 항상 행동 유도 한 문장으로
이 규칙으로 글을 다듬을 때 자동으로 쓰이게 해줘.
```

→ 클로드가 스킬 파일을 만들어줍니다. 보여주는 파일에 **Accept(수락)** 누르면 완성.

#### 이렇게 씁니다

```
/brand-voice 이 고객 응대 메일 좀 더 친근하게 바꿔줘
```

- 내 요청이 스킬 설명과 맞으면 클로드가 **자동으로** 불러오기도 해요.

- 안 쓸 땐 자리를 차지하지 않아 "공짜"입니다.

> 💡 스킬 만들기를 도와주는 **skill-creator 플러그인**도 있어요. (명령어가 아니라 설치형 플러그인 — 설치법은 STEP 6)

> ✅ STEP 5 체크: `/brand-voice` 로 내 말투가 입혀진 글이 나온다.
> 플러그인이 연장통이라면, 스킬은 그 안의 나만의 사용설명서예요.

---

## DAY 2 — 파워 유저 세팅 (STEP 6~9)

### STEP 06 · 플러그인은 딱 하나만

스토어엔 플러그인이 수백 개예요. **다 깔지 마세요.** 내가 매주 하는 일에 맞는 하나면 충분합니다.

#### 설치법

Code 탭에서 `**+**`** 버튼 → Plugins** (또는 입력창에 `/plugin`).
→ 마켓플레이스가 열려요. 원하는 플러그인 선택 → 설치.

#### 직업별 추천 조합 (하나만)

| 유형 | 조합 |
| --- | --- |
| 📣 콘텐츠 크리에이터 | brand-voice + 대본 스킬 + 카드뉴스 스킬 |
| 💼 1인 사업가 | 인박스 정리 + 회계/영수증 + 고객 온보딩 |
| 📊 데이터 다루는 분 | 대시보드 빌더 + 리포트 자동화 |

> 플러그인 = 스킬·자동화·앱 연결을 한 묶음으로 담은 패키지예요. 스킬 하나만 필요하면 굳이 여기까지 안 가도 돼요.

> ✅ STEP 6 체크: 실제로 쓸 플러그인 1개를 설치했다.
> 하나만 제대로 써도 클로드가 달라집니다.

---

### STEP 07 · MCP로 내 앱 연결하기

MCP를 연결하면 클로드가 **내 앱을 직접 다룹니다** — 슬랙, 지메일, 노션, 힉스필드 등.
말 한마디면 실제 작업까지 끝나요.

#### 앱에서 연결하기 (터미널 필요 없음)

Code 탭에:

```
/mcp
```

→ 연결할 서비스(슬랙·노션·구글 등) 선택 → **Authenticate(로그인)** 누르면 브라우저가 열려요 → 평소처럼 로그인하면 연결 끝.

#### 실전 예시

> "지난주 일정 정리해서 슬랙 #팀 채널에 올려줘"
> → 탭 왔다 갔다 없이 몇 초 만에 끝.

> "힉스필드로 UGC 광고 영상 만들어줘"
> → 3분 만에 광고 영상 한 편이 뚝딱.

> ⚠️ 안전 팁: 처음 연결할 때 승인 창이 뜨면, 내가 추가한 게 맞을 때만 승인하세요. 비밀번호·토큰을 채팅창에 그대로 적지는 마세요.

> ✅ STEP 7 체크: `/mcp` 로 내 앱 1개가 연결됐다.
> 원하는 모든 걸 연결해서 지능을 높이세요.

---

### STEP 08 · 내 AI를 굴리는 파일, [CLAUDE.md](http://claude.md/)

이 파일 하나만 있으면, 클로드가 **내 정보를 정확히 인식해서 맞춤형으로 답합니다.**
내가 누구인지, 무슨 일을 하는지, 어떤 말투를 쓰는지 기억하는 "메모장"이에요.

#### 자동으로 만들기

Code 탭에:

```
/init
```

→ 폴더를 살펴보고 [CLAUDE.md](http://claude.md/) 초안을 자동으로 만들어줍니다. 여기에 내 정보만 채우면 끝.

#### 클로드한테 채워달라고 해도 됩니다

```
CLAUDE.md에 내 정보 정리해줘.
- 나는 인스타 카드뉴스로 AI 정보를 알리는 크리에이터
- 타깃: AI 처음 접하는 자영업자·1인 사업가
- 말투: "~해요"체, 친근하게
- 절대 쓰지 말 것: "혁신적인", "여러분의 성장을 돕는" 같은 뻔한 표현
```

> 📌 별도 "anti-style" 파일 같은 건 없어요.
> 대신 CLAUDE.md에 **"이런 표현은 피해줘"** 라고 적어두면 클로드가 대체로 지킵니다.
> (100% 차단은 아니에요. 완전히 막고 싶으면 나중에 '훅(hook)'이라는 고급 기능을 쓰면 되지만, 지금은 여기까지면 충분합니다.)

> 💡 팁: 짧고 구체적으로(200줄 이내). 길수록 클로드가 덜 지켜요.

> ✅ STEP 8 체크: `/init` 로 CLAUDE.md를 만들고 내 정보를 채웠다.
> 딱 2개(내 소개 + 말투 규칙)면 충분합니다.

---

### STEP 09 · 직원한테 인수인계 가능하게

혼자 쓰면 그냥 도구지만, **폴더째 넘기면** 직원도 나와 똑같이 일할 수 있어요.

#### 폴더에 담겨 전달되는 것

내가 만든 [CLAUDE.md](http://claude.md/), 스킬(`/대본`, `/brand-voice`), 설정, 앱 연결 목록이
전부 **작업 폴더 안 **`**.claude**`** 폴더**에 저장돼 있어요.

#### 인수인계 방법 (제일 쉬운 버전)

1. 작업 폴더를 통째로 압축하거나 공유 드라이브(구글 드라이브 등)에 올린다

1. 직원이 그 폴더를 받아 자기 앱의 Code 탭에서 **폴더 열기**

1. 첫 실행 때 앱 연결(MCP) 로그인만 하면 → **나와 똑같은 판단, 똑같은 결과물.**
다시 안 가르쳐도 됩니다.

> ⚠️ 앱 로그인 정보(토큰·비밀번호)는 폴더에 안 담겨요. 그건 각자 STEP 7처럼 `/mcp` 로 로그인하면 됩니다. (보안상 당연한 거예요.)

> ✅ STEP 9 체크: 폴더만 넘기면 다른 사람이 내 세팅 그대로 쓸 수 있다.
> 혼자 쓰는 클로드는 도구, 팀과 공유하는 Claude Code는 확실한 무기가 됩니다.

### 자주 쓰는 명령어 치트시트 (전부 Code 탭에 입력)

| 명령 | 하는 일 |
| --- | --- |
| `/init` | [CLAUDE.md](http://claude.md/) 자동 생성 |
| 예약 작업(Routines) | 앱 화면에서 반복 작업 예약 (터미널은 `/schedule`) |
| `/loop 15m ...` | 최대 3일간 반복 감시 |
| `/mcp` | 앱 연결·로그인 |

### 막힐 때

- 로그인이 안 됨 → 유료 플랜(Pro/Max/Team)인지 확인

- Code 탭이 안 보임 → 앱을 최신 버전으로 업데이트

- 명령어(`/이름`)가 안 뜸 → 스킬을 만든 그 폴더를 열었는지 확인

- 앱 연결이 "로그인 필요" → `/mcp` → Authenticate

- 클로드가 규칙을 안 지킴 → CLAUDE.md를 더 짧고 구체적으로 (200줄 이내)
