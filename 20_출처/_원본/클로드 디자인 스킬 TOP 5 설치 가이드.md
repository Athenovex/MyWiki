# 클로드 디자인 스킬 TOP 5 설치 가이드

밋밋한 그라데이션, 알약 모양 태그, 싸구려 느낌 모션, 이걸 고쳐주는 스킬들이 누구나 쓸 수 있게 깃허브에 공개되어 있습니다.

에트 매거진이 전부 검토해서, 바로 효과 보실 수 있는 다섯 개만 추렸어요.

### 🧰 STEP 0. 터미널 열기

이번 가이드의 명령어는 전부 '터미널(명령어 창)'에 붙여넣어요. 먼저 터미널부터 열어볼게요.

**맥 :** cmd + 스페이스바 → "터미널" 입력 → 엔터|

**윈도우 : **시작 버튼 → "PowerShell" 입력 → 엔터

글자만 있는 창이 하나 뜨면 그게 터미널이에요.

---

### 1️⃣ STEP 1. 클로드 코드가 있는지 확인

이 스킬들은 '클로드 코드(Claude Code)' 위에 얹어 쓰는 부품이에요. 이미 컴퓨터에 설치돼 있을 수도 있으니, 먼저 확인부터 해볼게요.

터미널에 아래 한 줄을 붙여넣고 엔터:

```bash
claude --version
```

> ✅ **버전 숫자가 나온다면** → 이미 설치돼 있어요. STEP 2는 건너뛰고 바로 **STEP 3**으로 가세요.

> ❌ **"command not found" 같은 오류가 난다면** → 아직 설치되지 않은 거예요. 바로 아래 **STEP 2**를 따라 설치해 주세요.

---

### 2️⃣ STEP 2. 클로드 코드 설치 — 없는 분만

> 💳 **터미널 자체는 무료**예요 — 컴퓨터에 기본으로 들어 있는 프로그램이라 돈이 들지 않아요.
> 
> 유료인 건 그 안에서 돌리는 **'클로드 코드'**입니다. 무료 클로드 계정으로는 쓸 수 없고, **Pro 이상 유료 구독** 또는 API 크레딧 계정으로 로그인해야 해요.
> 
> 무료로 스킬만 써보고 싶다면 맨 아래 📎 부록(웹/앱에서 쓰는 법)을 참고하세요.

내 컴퓨터에 맞는 한 줄을 터미널에 붙여넣고 엔터를 누르면, 설치가 자동으로 진행됩니다.

**맥** :

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**윈도우 (PowerShell)** :

```powershell
irm https://claude.ai/install.ps1 | iex
```

> ⏳ 설치가 끝나면 터미널에 **claude** 라고 입력해 보세요. 처음 한 번은 브라우저가 열리며 로그인을 요청하는데, 클로드 계정으로 로그인하면 됩니다.

마지막으로 **claude --version** 을 다시 입력해서 버전 숫자가 나오면 설치 성공이에요.

---

### 3️⃣ STEP 3. 스킬 설치 — 한 줄씩 복붙하고 엔터

다섯 개를 전부 깔 필요는 없어요. 뭐부터 깔지 모르겠다면 **①번과 ③번**, 딱 두 개만 깔아도 차이가 확 납니다.

> ⚙️ **시작 전 30초 준비 — Node.js 확인
> **아래 스킬 설치 명령어(npx로 시작하는 것들)는 'Node.js'라는 무료 프로그램이 있어야 작동해요. 터미널에 아래 한 줄을 붙여넣고 엔터:

```bash
node --version
```

숫자가 나오면 준비 완료. "command not found" 오류가 나오면 [nodejs.org](https://nodejs.org/ko) 에서 초록색 버튼(LTS)을 눌러 설치하고, 터미널을 껐다 켠 뒤 다시 확인해 주세요. (무료입니다)

> ❓ **설치 중 영어 질문이 나오면 이렇게 하세요
> **· "Ok to proceed? (y)" → **y** 입력 후 엔터
> · 어디에 설치할지 고르는 목록(Claude Code, Cursor 등)이 나오면 → **Claude Code**에 스페이스바로 체크하고 엔터
> · 명령어 끝의 **-g**는 "내 컴퓨터 전체에서 쓰기" 옵션이에요. 이게 있어야 어느 폴더에서 클로드 코드를 켜도 스킬이 적용됩니다.

---

#### ① frontend-design — 뻔한 디자인 탈출의 기본기

Anthropic이 직접 만든 공식 스킬입니다. 클로드는 원래 시키면 바로 코드부터 짜기 시작하는데, 이 스킬을 깔면 색·글꼴·여백·분위기 같은 미적 방향을 먼저 정한 뒤에 코딩을 시작해요.
그래서 "어디서 본 듯한" 보라색 그라데이션 템플릿이 아니라, 방향이 분명한 디자인이 나옵니다.

```bash
npx skills add anthropics/skills --skill frontend-design -g
```

#### ② taste-skill — 디자인 취향을 다이얼처럼 조절

결과물의 분위기를 과감함·모션·밀도 세 가지 다이얼로 조절하는 스킬입니다. "너무 심심하다" 싶으면 과감함을 올리고, "너무 정신없다" 싶으면 밀도를 내리는 식으로, 말로 설명하기 어려운 '느낌'을 단계로 지시할 수 있어요.
깃허브 별 5만 5천 개를 받은 검증된 스킬입니다.

```bash
npx skills add Leonxlnx/taste-skill --skill design-taste-frontend -g
```

#### ③ playwright-mcp — 클로드에게 "눈" 달아주기

마이크로소프트가 만든 도구입니다. 클로드는 원래 자기가 짠 화면이 실제로 어떻게 보이는지 못 보는데, 이걸 달아주면 브라우저를 직접 열어 눈으로 확인할 수 있게 돼요.
어긋난 정렬이나 깨진 버튼을 스스로 발견하고 고치는 "만들고 → 보고 → 고치는" 순환이 생겨서, 다섯 개 중 체감 효과가 가장 큽니다.

```bash
claude mcp add playwright -s user -- npx @playwright/mcp@latest
```

#### ④ animate — 싸구려 느낌 모션 교정

AI가 만든 애니메이션이 값싸 보이는 이유는 대부분 속도와 타이밍 때문인데, 이 스킬이 그 감각을 잡아줍니다.
유명 UI 디자이너 Emil Kowalski의 모션 강의를 기반으로 만들어져서, 과하게 튕기는 움직임 대신 짧고 절제된 고급스러운 모션을 넣어줘요.

```bash
npx skills add delphi-ai/animate-skill --skill animate -g
```

#### ⑤ Figma MCP — 피그마 시안을 그대로 코드로

피그마 시안의 색상값·간격·글꼴 정보를 클로드가 직접 읽어오게 해주는 연결 도구입니다. 스크린샷을 보고 눈대중으로 흉내 내는 게 아니라 수치를 그대로 가져오기 때문에, 시안과 거의 똑같은 코드가 나와요.
디자이너와 협업하거나 피그마로 시안을 먼저 그리는 분께 필수입니다.

> 🔑 ⑤번만 준비물이 하나 더 필요해요: 피그마 개인 액세스 토큰. **피그마 무료 계정으로도 발급할 수 있어요.
> **
> 피그마 → 프로필 → Settings → Security → "Personal access tokens"에서 발급 → 아래 명령어의 [피그마토큰] 자리에 붙여넣고 실행하세요.

```bash
claude mcp add figma -s user -- npx figma-developer-mcp --figma-api-key=[피그마토큰] --stdio
```

### 4️⃣ STEP 4. 잘 깔렸는지 확인

터미널에 **claude** 라고 입력해 클로드 코드를 켠 다음, 이렇게 물어보세요.

```
지금 내가 쓸 수 있는 디자인 스킬이나 도구, 뭐가 있어?
```

방금 설치한 스킬 이름이 답에 나오면 성공이에요.

> 🔄 **이름이 안 나온다면?** 터미널을 완전히 껐다가 새로 열고, claude를 다시 켜서 한 번 더 물어보세요. 새로 설치한 스킬은 클로드 코드를 재시작해야 인식되는 경우가 있어요.

---

### 5️⃣ STEP 5. 실전 사용법 — 이렇게 시키면 됩니다

스킬을 발동시키는 방법은 두 가지예요.
**① 자동** — 그냥 "랜딩페이지 만들어줘"라고 하면, 클로드가 요청을 보고 관련 스킬을 알아서 적용해요. 다만 요청이 애매하면 스킬 없이 만들어버릴 때도 있어요.

**② 직접 호출 (추천)** — 문장에 스킬 이름을 넣거나, /frontend-design 처럼 슬래시(/) 뒤에 스킬 이름을 붙여 부르면 100% 발동돼요.

> 💎 **보너스 — 나만의 명령어 만들기
> **긴 스킬 이름을 외울 필요 없어요. 클로드 코드에 아래처럼 시키면, 나만의 단축 명령어를 클로드가 알아서 만들어줍니다:

```
내가 /디자인 이라고 치면 frontend-design 스킬과 animate 스킬을 같이 적용해서 작업하도록, 나만의 명령어로 만들어줘
```

#### 아래 예시는 스킬 이름을 넣은 버전으로 준비했어요. 그대로 복붙해서 시작해 보세요.

**frontend-design** — 화면을 만들어달라고만 하면 자동 적용

```
frontend-design 스킬 써서 우리 브랜드 소개 랜딩페이지 만들어줘. 뻔한 템플릿 느낌 말고, 방향을 과감하게 잡아서.
```

**taste-skill** — 결과물이 애매할 때 다이얼을 돌리듯 지시

```
design-taste-frontend 스킬 써서, 지금 디자인에서 밀도는 그대로 두고 과감함만 한 단계 올려줘.
```

**playwright-mcp** — 만들고 나서 셀프 검수를 시키는 게 핵심

```
방금 만든 페이지를 브라우저로 직접 열어서 확인하고, 어색한 부분을 스스로 찾아서 고쳐줘.
```

**animate** — 움직임이 필요한 요소를 지목

```
animate 스킬 써서 버튼이랑 카드에 자연스러운 등장 애니메이션 넣어줘. 과하지 않게.
```

**Figma MCP** — 피그마 파일 링크를 복사해서 함께 전달

```
[피그마 파일 링크] 이 시안 그대로 코드로 만들어줘. 간격이랑 색상 최대한 똑같이.
```

> 🧩 **③·⑤는 왜 이름을 안 넣나요?** 이 둘은 스킬이 아니라 '도구'라서 슬래시 호출이 없어요. 대신 "브라우저로 직접 열어서 확인해줘", "이 피그마 시안 그대로 만들어줘"처럼 그 도구가 필요한 일을 시키면 클로드가 알아서 집어 듭니다.

이제 다음부터는 **/design** 한 번이면 스킬들이 세트로 발동돼요. 자주 쓰는 조합이 생기면 이렇게 묶어두세요.

### 📎 부록. 클로드 웹/앱에서 쓰는 법 — ①·②·④ 스킬만

터미널 없이 claude.ai 웹이나 데스크톱 앱만 쓰는 분들을 위한 방법이에요. 스킬 기능은 무료 플랜 포함 전 플랜에서 쓸 수 있습니다.

**1) ZIP 내려받기****
**스킬이 있는 깃허브 페이지에 접속해서, 초록색 "Code" 버튼 → "Download ZIP"을 누르세요.

· frontend-design → [github.com/anthropics/skills](https://github.com/anthropics/skills)
· taste-skill → [github.com/Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)
· animate → [github.com/delphi-ai/animate-skill](https://github.com/delphi-ai/animate-skill)

**2) 스킬 폴더만 다시 압축****
**내려받은 ZIP의 압축을 풀면 폴더가 여러 개 나오는데, 그중 안에 SKILL.md 파일이 들어 있는 폴더가 스킬 본체예요 (예: frontend-design 폴더).
그 폴더 하나만 우클릭 → "압축"(맥) / "ZIP 파일로 압축"(윈도우)으로 새 ZIP을 만드세요.

**3) 클로드에 업로드****
**claude.ai 접속 → 설정(Settings) → Customize → Skills → "+" → "Upload a skill" → 방금 만든 ZIP 선택.

**4) 켜져 있는지 확인****
**설정에서 코드 실행(Code execution) 기능이 켜져 있어야 스킬이 작동해요. 업로드 후 채팅에서 "랜딩페이지 하나 만들어줘"라고 시키면, 올린 스킬이 자동으로 적용됩니다.

③ playwright-mcp와 ⑤ Figma MCP는 웹(claude.ai)에서는 쓸 수 없어요. 클로드 데스크톱 앱에 '확장 기능(Extensions)'으로 붙이는 방법이 있긴 하지만 설정이 꽤 복잡해서, 이 가이드는 가장 간단한 클로드 코드 기준으로 작성되었어요.

이 두 개가 궁금해지셨다면, 그게 클로드 코드를 시작할 타이밍이라는 뜻 😉
