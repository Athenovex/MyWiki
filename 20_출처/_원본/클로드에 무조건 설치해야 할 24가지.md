# [후피디] 클로드에 무조건 설치해야 할 24가지

![이미지](https://opengraph.githubassets.com/whopd-claude-24/anthropics/claude-code)

> 💡 후피디 팔로워 여러분!
> 
> 클로드를 그냥 질문 답변용 챗봇으로만 쓰면 너무 아깝습니다.
> 
> 진짜 차이는 **무슨 MCP와 스킬을 붙여두느냐**에서 납니다.
> 파일을 읽고, 웹을 뒤지고, GitHub를 만지고, Figma·Notion·Slack까지 연결되면 클로드는 답변하는 AI가 아니라 **일을 끝내는 AI 비서**가 됩니다.
> 
> 이 가이드는 클로드 파워유저 세팅에 넣어두면 좋은 24가지를
> 바로 써먹을 수 있게 정리한 자료입니다.

---

### 🔥 이거 다 배우면? 이렇게!

| 상황 | 그냥 클로드만 쓰면 | 설치 후 달라지는 점 |
| --- | --- | --- |
| 자료 조사 | 답은 빠른데 출처 확인이 번거로움 | Perplexity, Exa, Firecrawl로 근거를 같이 가져옴 |
| 웹 작업 | 사이트를 직접 열고 복붙해야 함 | Playwright와 Chrome으로 클릭, 입력, 캡처까지 맡김 |
| 코딩 | 코드 조각만 도와줌 | Claude Code, GitHub, Git으로 실제 저장소를 고침 |
| 업무 정리 | 문서를 매번 붙여넣어야 함 | Drive, Slack, Notion, Linear에서 맥락을 바로 읽음 |
| 데이터 분석 | CSV를 올려야 시작됨 | Postgres와 SQLite에 직접 물어보고 표로 정리함 |

### 🧩 핵심 원리

클로드 확장 세팅은 어렵게 생각할 필요 없습니다.

**MCP는 클로드에게 손과 눈을 달아주는 장치**입니다.

```
일반 클로드 = 대화만 잘하는 사람
MCP 붙인 클로드 = 파일 읽고, 웹 열고, 앱 만지고, 결과까지 정리하는 사람
```

중요한 건 24개를 한 번에 다 켜는 게 아닙니다.

내 일에 맞는 조합을 고르는 겁니다.

- 리서치를 많이 하면: Perplexity, Exa, Firecrawl, Fetch

- 코딩을 많이 하면: Claude Code, GitHub, Git, Context7, Playwright

- 회사 업무가 많으면: Drive, Slack, Notion, Linear, Figma

- 자동화를 많이 하면: Chrome MCP, Playwright, Docker, Claude Code Action

### 🧠 시작! 클로드에 무조건 설치해야 할 24가지

#### 1. Claude Code

[https://github.com/anthropics/claude-code](https://github.com/anthropics/claude-code)

![이미지](https://opengraph.githubassets.com/whopd-claude-24-01/anthropics/claude-code)

- 역할: 터미널에서 Claude가 파일을 읽고, 코드를 수정하고, 명령을 실행하게 해줍니다.

- 이렇게 씁니다: 저장소 전체를 읽고 버그 수정, 리팩토링, 문서화, 테스트 작성까지 맡깁니다.

- 클로드를 진짜 직원처럼 쓰고 싶으면 제일 먼저 깔아야 하는 기본 엔진입니다.

#### 2. Chrome MCP

- 역할: Claude Code에서 브라우저를 직접 열고 클릭, 입력, 확인을 하게 해줍니다.

- 웹사이트 QA, 로그인 후 화면 확인, 폼 입력, 결과 캡처에 씁니다.

- 웹을 보는 눈과 마우스를 클로드에게 주는 기능입니다. 별도 설치보다 Claude Code 내장 기능부터 확인하세요.

#### 3. Filesystem MCP

[https://github.com/modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers)

![이미지](https://opengraph.githubassets.com/whopd-claude-24-03/modelcontextprotocol/servers)

- 역할: 클로드가 허용된 폴더 안의 파일을 읽고 정리할 수 있게 합니다.

- PDF, 기획서, 회의록, CSV, 텍스트 파일을 폴더째 분석시킵니다.

- 주의: 전체 컴퓨터를 열지 말고 작업 폴더만 허용하세요.

#### 4. Memory MCP

[https://github.com/modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers)

![이미지](https://opengraph.githubassets.com/whopd-claude-24-04/modelcontextprotocol/servers)

- 매번 처음부터 설명하는 시간을 줄여주는 장기 기억장치입니다.

### 🛠️ 가장 쉬운 설치 방법

Claude Code를 쓰는 분들은 처음부터 명령어를 외우려 하지 말고, Claude에게 설치 과정을 맡기세요.

```
이 MCP 서버를 내 Claude Code에 설치해줘.
GitHub 링크: [여기에 링크 붙여넣기]

1. 필요한 API 키가 있는지 먼저 알려줘.
2. 설치 명령어를 운영체제별로 나눠줘.
3. 설치 후 테스트 질문까지 만들어줘.
4. 보안상 조심해야 할 권한도 같이 알려줘.
```

Claude Desktop에 넣는 경우에는 보통 설정 파일에 MCP 서버를 추가합니다.

```json
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    }
  }
}
```

중요한 건 한 번에 24개를 다 붙이는 게 아니라, 아래 순서대로 붙이는 겁니다.

1. 먼저 기본 세팅: Claude Code, Filesystem, Memory, Sequential Thinking

1. 그다음 리서치: Perplexity, Firecrawl, Playwright, Exa

1. 그다음 업무앱: Drive, Slack, Notion, Linear, Figma

1. 마지막으로 개발 자동화: GitHub, Git, Docker, Claude Code Action

### 🛡️ 설치할 때 꼭 지킬 것

MCP는 편하지만, 권한을 잘못 주면 위험합니다.

아래 다섯 개는 꼭 지켜주세요.

1. **파일 권한은 폴더 단위로 제한하기**
    - 전체 컴퓨터가 아니라 프로젝트 폴더만 열어주세요.

1. **API 키는 환경변수로 관리하기**
    - 채팅창, Notion, 문서에 키를 그대로 붙여넣지 마세요.

1. **GitHub 토큰은 최소 권한으로 만들기**
    - 처음에는 읽기 권한부터 시작하세요.

1. **처음 보는 MCP는 바로 설치하지 않기**
    - 최근 커밋, 이슈, README, 설치 스크립트를 확인하세요.

1. **쓰기 권한은 마지막에 켜기**
    - DB, GitHub, 파일시스템은 읽기 전용으로 먼저 테스트한 뒤 쓰기 권한을 주는 게 안전합니다.
