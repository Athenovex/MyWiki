# 동국대_교육자료1

## 원본

- 파일: [[_원본/동국대_교육자료1.pdf]] (20페이지, "Google Cloud & Vertex AI 기반 스타트업 AI 비서 서비스 개발 실전" 교육자료)

## 자료 개요

GCP/Vertex AI 환경 세팅부터 RAG·LangChain 기반 지식베이스 구축, 실무 프롬프트 엔지니어링, Streamlit UI, Cloud Run 배포까지 하루 커리큘럼(09:00~18:00)을 다루는 실습형 교육자료. 대부분 인포그래픽 슬라이드로 구성되어 텍스트 레이어가 거의 없고, 이미지 기반 다이어그램이 정보의 핵심.

## 핵심 내용

p.2 커리큘럼 표(GCP 세팅→RAG→프롬프트엔지니어링→Streamlit→Cloud Run→데모데이), p.4 Gemini API 구조, p.5 Vertex AI, p.6 Google Cloud Storage, p.7 실무 프롬프트엔지니어링(페르소나/톤앤매너/환각방지), p.8 API 없이 교차검증, p.9-10 RAG, p.11-12 LangChain, p.13 FAISS, p.16 Streamlit, p.19-20 임베딩·유사도 계산, p.20 Cloud Run.

## 위키 반영

10개 Canonical Note에 반영 (신규 생성: Gemini, Vertex AI, Google Cloud Storage, RAG, LangChain, FAISS, 임베딩, Streamlit, Cloud Run / 기존 갱신: 프롬프트 엔지니어링).

## 참고

p.17에 "피타고라스 정리" 슬라이드가 포함되어 있으나 본 교육자료의 주제와 무관한 것으로 판단해 위키에 반영하지 않음 (아마도 템플릿 재사용 과정의 오류로 추정, 원본은 수정하지 않고 그대로 보존).
