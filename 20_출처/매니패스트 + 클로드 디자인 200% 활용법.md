# 매니패스트 + 클로드 디자인 200% 활용법

## 원본

- 파일: [[_원본/매니패스트 + 클로드 디자인 200% 활용법.md]]
- URL: https://gelatinous-sphere-b13.notion.site/200-383c6c88e2988080b32ed0ccae19556e

## 자료 개요

AI 기획 에이전트 매니페스트로 PRD~와이어프레임을 만들고 Claude Design으로 넘겨 디자인하는 워크플로우, MCP로 Claude Code와 연동하는 방법까지 포함한 가이드.

## 핵심 내용

매니페스트 사용흐름 5단계, 매니페스트→Claude Design 워크플로우, 디자인 시스템 활용 팁, 매니페스트 MCP로 Claude Code 연동(양방향 동기화).

## 위키 반영

- [[매니페스트]] 신규 생성 — 전체 내용 반영
- [[Claude Design]] 신규 생성 — 디자인 시스템 워크플로우, 매니페스트 연계 섹션 반영

## 참고

실무 워크플로우 공유 자료. 툴 이름 표기가 "매니패스트"(본문)와 "Manyfast"(공식 링크 텍스트)로 혼용되어 있어 위키에서는 "매니페스트"로 표기하고 별칭에 두 표기를 모두 기록함.
