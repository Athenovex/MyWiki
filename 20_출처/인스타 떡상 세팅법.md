# 인스타 떡상 세팅법

## 원본

- 파일: [[_원본/인스타 떡상 세팅법.md]]
- URL: https://app.notion.com/p/38b7d0f198f680c7bfb7c10c5673889c

## 자료 개요

인스타그램 계정 설정 화면을 캡처해 순서대로 보여주는 도달률 최적화 체크리스트. 13단계 스크린샷으로 구성(텍스트는 각 단계 제목만).

## 핵심 내용

검토 플래그 OFF, 계정 공개범위, 검색엔진 노출 ON, 추천게시물 숨기기 OFF, 공유·리포스트 ON, 웹사이트 퍼가기 ON, 고화질 업로드 ON, 프로페셔널 계정 확인 등 설정 항목 8개.

## 위키 반영

- [[SNS 콘텐츠 마케팅]] 업데이트 — "인스타그램 계정 노출 최적화 설정" 섹션 반영

## 참고

이미지(스크린샷) 기반 자료라 텍스트는 각 단계 제목만 확인 가능. "도달률 개선" 효과는 사용자 경험 기반 주장으로 인스타그램 공식 발표는 아님 — 위키에도 신뢰성 caveat 명시함.
