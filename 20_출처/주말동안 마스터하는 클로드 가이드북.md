## 자료 개요

비개발자가 이틀(주말)간 Claude Code를 익히는 9단계 가이드. Code 탭 사용법부터 나만의 명령어·예약 작업·스킬·플러그인·MCP 연결·CLAUDE.md 작성·인수인계까지 다룸.

## 핵심 내용

DAY1(STEP1~5): 앱 설치, 3탭 비교, 커스텀 명령어, 예약 작업(Routines/`/loop`), 첫 스킬 만들기. DAY2(STEP6~9): 플러그인, MCP 연결(`/mcp`), CLAUDE.md(`/init`), 폴더 인수인계.

## 위키 반영

- [[Claude Code]] 신규 생성 — Code 탭 사용법, 예약 작업, 플러그인, CLAUDE.md, 인수인계 섹션 반영
- [[Claude]] 신규 생성 — 3탭(Chat/Cowork/Code) 비교표 반영
- [[MCP]] 신규 생성 — `/mcp` 연결 방법 반영
