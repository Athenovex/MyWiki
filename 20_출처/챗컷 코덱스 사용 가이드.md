# 챗컷 코덱스 사용 가이드

## 원본

- 파일: [[_원본/챗컷 코덱스 사용 가이드.md]]
- URL: https://app.notion.com/p/3a4c601852d180e38158e641d8c57d27

## 자료 개요

Codex 데스크톱 플러그인 "챗컷(Chatcut)" AI 영상 편집기 소개. 원본이 토글(아코디언) 구조라 세부 섹션 본문이 대부분 소실됨.

## 핵심 내용

챗컷 개요 한 줄과 전체 흐름(업로드→프롬프트편집→보정→자막/모션/에셋→내보내기)만 확인 가능. "1분만에 시작하기", "편집 프롬프트 예시" 등 세부 섹션은 제목만 남고 본문 없음.

## 위키 반영

- [[Codex]] 신규 생성 — 챗컷 섹션에 확인 가능한 내용만 반영, 정보 손실 명시

## 참고

**정보 손실 있음**: 원본 Notion의 토글 섹션이 클리핑 시 비어서 수집됨. 상세 사용법(프롬프트 예시, 크레딧 정책 등)은 원본 링크 재확인 필요.
