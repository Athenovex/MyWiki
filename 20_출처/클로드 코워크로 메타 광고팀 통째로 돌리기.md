# 클로드 코워크로 메타 광고팀 통째로 돌리기

## 원본

- 파일: [[_원본/클로드 코워크로 메타 광고팀 통째로 돌리기.md]]
- URL: https://first-cycle-f53.notion.site/0-5-38a8db89774880ebad9ed883f0def996

## 자료 개요

`meta-ads-team.skill` 파일 하나로 메타(페이스북·인스타) 광고 대행 업무를 명령어 5개로 대체하는 사례 가이드. Claude Cowork 기준.

## 핵심 내용

설치법(.skill 파일 → Save skill), 메타 광고 커넥터 연결(선택), 명령어 5개(`/spy`, `/competitive-ads-extractor`, `/bulk-creative`, `/ads-score`, `/ads meta`) 각각의 기능과 사용 순서.

## 위키 반영

- [[Claude]] 신규 생성 — 활용 사례(메타 광고팀 스킬) 섹션 반영

## 참고

특정 스킬 배포자의 홍보성 실무 가이드. 스킬 파일 자체(`meta-ads-team.skill`)는 원본 첨부 파일이라 위키에는 명령어 기능 설명만 반영.
